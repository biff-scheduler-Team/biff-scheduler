# 我的观影浮动面板

右下角的「我的观影」按钮打开面板，面板内通过「我的选片」和「我的行程」切换内容。顶部提供排片表、影片库、我的选片与我的行程四个独立页面入口。浮动面板仅作为排片表中的快速查看入口，面板内可打开完整页面。

- 面板固定于右下角，不挤压排片表，不改变影厅宽度或横向位置。
- 选择场次更新已选状态与按钮数量，不自动打开面板。
- 收起后再次打开，恢复本次会话最后使用的选片或行程视图。
- 点击场次或日期定位时收起面板，显示目标日期并突出场次。
- 桌面面板保留原 `biff.pickerw.v1` 宽度偏好；手机使用接近屏幕宽度的底部面板。
- 长内容在面板内滚动；高度受视口限制，顶部全局操作保持可用。
- 收起按钮与 Escape 返回浮动按钮焦点。面板非模态，排片表仍可操作；影片资料、设置等弹窗保持原有模态行为。

数据格式及 `/legacy/` 均未变更。

验证：203 项单元测试通过；218 项 E2E 场景经全量运行及失败项所在套件复测全部通过，复测 30 项通过。
