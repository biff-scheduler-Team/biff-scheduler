# 我的观影面板（桌面分栏 + 窄屏浮层）

右下角的「我的观影」按钮打开面板，面板内通过「我的选片」和「我的行程」切换内容。顶部提供排片表、影片库、我的选片与我的行程四个独立页面入口。

## 桌面（≥1100px）

- **真实 1:3 挤压分栏**：选片/行程侧 : 排片表侧 ≈ 1 : 3（不再用 fixed 浮层盖住排片）。
- 工作台 `max-width: 1600px` 居中，超宽屏左右留白。
- 打开面板后排片表几何变窄；关闭后恢复。
- `?quick=1` 仍是同屏入口；窄屏策略见下。

## 窄屏（≤1099px）

- 面板回到右下角浮层，不要求 1:3。
- 手机使用接近屏幕宽度的底部面板。

## 其它行为

- 选择场次更新已选状态与按钮数量，不自动打开面板。
- 收起后再次打开，恢复本次会话最后使用的选片或行程视图。
- 点击场次或日期定位时收起面板，显示目标日期并突出场次。
- 收起按钮与 Escape 返回浮动按钮焦点。面板非模态，排片表仍可操作；影片资料、设置等弹窗保持原有模态行为。

数据格式未变更；`/legacy/` 另有薄账号桥（见 `docs/account-integration.md`）。

口径变更见 `PLAN-20260914003600`。
