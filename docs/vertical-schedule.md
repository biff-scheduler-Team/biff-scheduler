# 纵向排片表

时间沿纵轴排列，影厅沿横轴排列。桌面与手机使用同一套排片表，默认每分钟 2px，每个影厅至少占 260px；缩放沿用原有 `biff.settings.v1.zoom`。

排片表高度由完整时间范围决定，不设置内部纵向滚动区域。页面负责纵向滚动，排片表负责横向滚动。影厅表头独立固定在页面顶部，与排片表同步横向位置；左侧时间刻度保持可见。

电影与映后谈分别以高度表示时长。同一影厅时间重叠的场次分栏呈现，避免互相遮挡。选片、冲突、转场提示、整点筛选、场次定位及映后时长编辑沿用现有业务逻辑与数据格式。

缩放前记录页面中心对应的时间与横向影厅位置，缩放后恢复。适应按钮按可见宽度安排完整影厅列，并回到最左侧。

`/legacy/` 保留提交 `fe82988` 中的原版实现。

验证覆盖页面滚动、横向表头同步、缩放位置、重叠场次分栏、跨午夜、GV 时长及刷新后保留。Chromium 使用真实滚轮输入；Playwright 不支持手机 WebKit 的滚轮或滑动注入，WebKit 检查页面滚动几何与滚动归属。
