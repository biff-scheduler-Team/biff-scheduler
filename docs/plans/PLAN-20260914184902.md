## 方案取舍

| 备选 | 结论 | 理由 |
|---|---|---|
| 官网为骨架 + 册子补缺（采纳） | 采纳 | 官网是活数据（改时间 / 加场 / 事件场次 / 中文名），册子是付印快照；反过来会把 9/10 之后的变更打回去（831 Special Talk 60′→120′ 就是实例） |
| 册子为骨架 + 官网覆盖 | 否决 | 官网缺 79 场，且 `title_zh` 桥接、事件场次都在官网侧，做骨架要补更多东西 |
| 官网片长一律胜 | 否决 | 002 / 731–735 官网是 `FALLBACK_DURATION_MIN = 120` 兜底（`scrape_biff_web.py:138`），册子印了真实片长 |
| 册子片长一律胜 | 否决 | 831 是官网更新（20:00~21:00 → 20:00~22:00），册子已过期 |
| 通用「两源片长取大/取小」 | 否决 | 无口径依据，等于猜；改用**显式覆盖清单 + 逐条理由** |
| `br` 保持不动 | 否决 | 全仓口径是「id = 官方代码小写」（`docs/CONVENTIONS.md:359`），2026 官方代码是 `BT`；`br` 是抓取脚本自造 |
| 影片简介用 `pdftotext` 纯文本切 | 否决 | 版面是多栏杂志式（p22–96），文本流顺序与版面顺序不一致（p24 实测乱序），必须走 block/bbox 分组 |

## 修正(2026-09-14 晚):BD / C7 是 P&I 场次,不得进公开排期

**触发**:用户核对影片《The Day After Sunday》的册页 047,发现介绍页只列 `007 / 084 / 224 / 538`,
质疑合成的 `X0902` 从哪来 ——「只用官方号做索引 重新检查一次」。

**查证**(三重,互相独立):

1. **版面上有整列的粉底标题**:册子排期页 BD(Indieplus)/ C7(CGV 7) 两列上方印着
   `P&I(Press & Industry) Screenings`,两列底色是与其余排期区不同的粉色
   (渲染 p9 右缘核对,`/tmp/crop9.png`)。
2. **官网完全不列**这两个厅(`date.asp?day1=6..15` 十天分组标题里都没有),影片介绍页
   (p22–96)的场次索引里出现 24 个厅,**也没有 BD / C7**(实测)。
3. **同页 Community BIFF(MEGABOX 1–4)是免费·现场先到先得,却印了官方编号 901–942** ——
   所以「不印编号」不是排版疏忽,是有意区分公开 / 非公开。**编号本身就是判据。**

**结论**:`X<页2位><序2位>` 合成号方案**作废**。`extract_schedule.py` 对无编号格子直接跳过
(`stats['skipped_no_code']` = 39 = 37 P&I + Forum BIFF 论坛 + BAFA 毕展),不再产出任何 `X` 号。
