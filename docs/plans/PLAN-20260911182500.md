# PLAN 2026-09-11 18:25:00 — 定位落点:卡片必须落在**显示区正中**

> 需求(用户原话):「定位的地方 需要让影片的场次卡片处于显示的中点 现在定位应该有点问题」。

## 1. 根因(两个,叠在一起)

### ① 两次 `scrollTo` 互相取消 → 有一个轴停在动画中途

旧写法 `jumpToScreening` 里:

```ts
centerCardX(scroll, card);   // scrollTo({ left, behavior: "smooth" })
centerCardY(card);           // scrollTo({ top,  behavior: "smooth" })
```

同一元素上的第二次 `scrollTo` 会**取消**第一次正在进行的平滑滚动 —— 横向停在动画中途
(或反之)。症状正是「定位后卡片不在中间,但看起来又滚了一点」。

`jumpToDate` 同类:`scrollGridTop()`(滚 top 0)+ `afterLayout` 里的 `centerCardX` ——
第二次把第一次的纵向回顶取消,于是「在网格中查看这一天」也停不到顶。

**修**:两个轴合并成**一次** `scrollTo({ left, top, behavior: "smooth" })`
(`main.ts::scrollTargetFor` 一次算全 + `centerCard` 一次滚全)。

### ② 纵向按 `clientHeight / 2` 居中 → 卡片整体偏上

`#grid-scroll` 顶部有一条**吸顶标尺**(`sticky top-0`,≈36px)。按容器几何中点居中时,
卡片中心落在「含标尺那一条」的中点 —— 视觉上被标尺压着、整体偏上。

**修**:纵向净区扣掉标尺高度(`netH = clientHeight - rulerH`),
卡片中心落在**标尺下缘到容器底部**这段的中点。`grid.ts` 给标尺补 `data-grid-ruler` 锚点,
`main.ts::scrollTargetFor` 读它(读不到则退化为旧行为,不炸)。

## 2. 改动

| 文件 | 改动 |
|---|---|
| `src/main.ts` | 新增 `scrollTargetFor(scroll, card) → {left, top}`(一次算全,纵向扣标尺净高);新增 `centerCard()`(一次 `scrollTo` 双轴);`centerCardX()` 改为 `scrollTargetFor(...).left` 的单轴包装(仍供 `ensureCardVisibleX` 用);**删 `centerCardY()`**(其纵向口径并入 `scrollTargetFor`) |
| `src/main.ts::jumpToScreening` | `centerCardX + centerCardY` → `centerCard` |
| `src/main.ts::jumpToDate` | 去掉提前的 `scrollGridTop()`(换日期会重建容器,旧节点上滚等于没滚);纵向 `top: 0` 与横向居中合并成 afterLayout 里的**一次** `scrollTo`;当天无行程场次时走 `afterLayout(scrollGridTop)` 兜底 |
| `src/grid.ts` | 标尺加 `data-grid-ruler="1"` 锚点 |

## 3. 口径说明(刻意不同,勿统一)

* **单场定位**(`jumpToScreening` / 「定位 ▸」):纵向**居中**到该影厅行 —— 目标行上下留上下文。
* **整天定位**(`jumpToDate` / 「在网格中查看这一天」):纵向**贴顶**(top 0,标尺吸顶处)——
  要展示的是当天全部场次,停在顶部才读得全;横向仍居中到当天最早一场。
