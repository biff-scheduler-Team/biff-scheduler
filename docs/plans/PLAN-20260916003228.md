# PLAN-20260916003228 — 测试职责交给云端:删掉本地门禁

## 目标

用户原话（逐字保留）：

> 请你修改一下 Plan 或者 Rule 我记得应该在 GitHub 上面去跑这些测试和 E2E 就可以了不用这么复杂的

### 核实到的现状（代码事实，不是推测）

规范文档与仓库实际配置**互相矛盾**：

| 落点 | 现状 |
|---|---|
| `.github/workflows/ci.yml` | **已存在**。PR → `verify:quick` + 受影响 spec(chromium)；`push main` → **全量三浏览器 E2E** |
| Cloudflare Workers Builds | push `main` 后跑 `npm run build` = typecheck → lint → 单测 → 构建，**失败即不上线** |
| `docs/DEVELOPMENT-STANDARDS.md` §0 | 却写着「本项目**没有 CI 兜底** —— 测试必须在开发阶段跑完」 |
| `scripts/git-hooks/pre-push` | 本地强制跑 `verify:quick`（约 40s） |

⇒ 实际职责早已是「云端跑 typecheck / lint / 单测（**部署前**）+ GitHub 跑 E2E」，
但规范仍在要求本地把同一批测试再跑一遍，并且 `pre-push` 机械拦住每个人。

## 范围

**做：**

1. **口径改写**（三份文档 + 一处脚本注释 + 一个钩子）：
   - `docs/DEVELOPMENT-STANDARDS.md`（权威）：§0 总纲、§1 工作流第 3 步、§2 整节重写、§3.2 证据条、
     §4.3（钩子表）、§8 红线 1、§10 变更记录加 v9。
   - `AGENTS.md`（受版本控制的主入口）：§0、§1、§2、§4 钩子行、§8 红线 1。
   - `.github/workflows/ci.yml` 头部注释 —— 「CI 不改变本地门禁的职责划分」已与事实相反。
   - 本机 `.codebuddy/rules/biff-development-standards/RULE.mdc`（gitignore，手动同步）。
2. **删掉本地门禁**：删 `scripts/git-hooks/pre-push`；`scripts/install-git-hooks.mjs` 增加
   「清理已下线的托管钩子」逻辑（只删它自己装过的名字，不碰用户其它钩子）。
3. `PLAN.md` 只更新文档头一行。

**不做（与「做」同等重要）：**

- **不改 CI 的触发条件与覆盖面** —— PR 快档 + `main` 全量本来就够。
- **不改 `verify` / `verify:quick` / `verify:ui` / `verify:full` 脚本本身** —— 它们仍是**按需可用**的工具，
  只是从「必跑」变成「要跑随时跑」。
- **不删 `commit-msg` 钩子** —— 它即时（<10ms），且提交格式**没有**云端门禁兜底。
- **不改 `check:repo` / `check:test-map`** —— 已串进 CI 的 gate job，本地那份随之不再强制。
- **不动 `E2E` 断言 / 测试内容** —— 本轮只改「谁在什么时候跑」。

## 方案取舍

| 备选 | 结论 | 理由 |
|---|---|---|
| 本地测试要求整体取消，写明由 Cloudflare + GitHub CI 负责 | **采纳** | 与用户诉求一致；两条云端管线已实际覆盖 typecheck / lint / 单测 / E2E |
| 本地保留「单测必须跑」，只把 E2E 交给 CI | 否决 | 单测也在 Cloudflare 的 `npm run build` 里，失败同样不上线 —— 本地再跑是第三次跑同一批 |
| 保留 `pre-push` 但降级为秒级检查 | 否决 | 用户明确要「不用这么复杂」；`check:repo` / `check:test-map` 已在 CI gate 里 |
| 连 `commit-msg` 一起删 | 否决 | 提交格式没有云端兜底，而它零成本 |
| 把 CI 从 `push main` 改成只在 PR 上跑 | 否决 | 本仓库默认直接 push main，`main` 上的全量 E2E 是唯一的 E2E 覆盖 |
| 靠「自觉跑」而不写清代价 | 否决 | 必须把「E2E 是事后的、不会回滚」写进 §2 —— 否则下一个人会以为 CI 红了会自动回滚 |

## 验收标准

1. 三份文档 + `ci.yml` 注释里，测试归属写清且不再自相矛盾：
   **typecheck / lint / 单测 = Cloudflare 构建（部署前，失败不上线）**；
   **E2E = GitHub CI（事后通知，不回滚）**。
2. `scripts/git-hooks/pre-push` 不存在；`node scripts/install-git-hooks.mjs` 跑完
   `.git/hooks/pre-push` 被清掉、`commit-msg` 仍在。
3. `npm run verify:quick` 仍全绿（脚本本身没动）。
4. 本次 push **不再被 `pre-push` 拦** —— 这条本身就是验收。
