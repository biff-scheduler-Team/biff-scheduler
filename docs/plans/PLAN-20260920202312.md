# PLAN-20260920202312 — 类目名太长：hover 轴标签看完整名字

## 目标

用户原话：

> Y 轴名字太长会被遮挡 然后能不能 hover 展示全名呢

## 现状（代码事实）

`components/charts/bars.tsx` 里两个**横排**图给类目轴设了截断：

- `RankBarChart` 的 `yAxis.axisLabel`
- `StackedBarChart`（`horizontal` 时）的类目轴

都是 `{ width: 130, overflow: "truncate" }` —— 于是「The Sorry Generation」在轴上只剩「The Sorry Gener…」。

这个截断是**故意的**：面板宽度只有 ~460px，标签每宽 50px，柱子就少 50px。
问题不在截断，而在**没有留「看全名」的出口**。

## 范围

**做：**

- 给这两个横排图的**类目轴**加 `tooltip: { show: true }` ——
  ECharts 5.6+ 的 axis tooltip：让轴标签变成可 hover，hover 时弹出完整类目名。
  样式沿用既有的统一 tooltip（`sharedTooltip` 那套 token）。
- E2E 新增一条：hover 某个被截断的轴标签 → 弹出的 tooltip 文本包含**完整**片名。

**不做：**

- **不把标签加宽**：那等于拿柱子换文字（面板就 ~460px）。
- **不改成换行**（`overflow: "break"`）：长片名会占 3~4 行，而横排图的行高是写死的 16~24px ——
  换行会把行撑破、互相重叠，比截断更糟。
- 不动数值轴与竖柱图（竖柱的类目是日期 / 时段，本来就短）。

## 方案取舍

| 备选 | 结论 | 理由 |
|---|---|---|
| 把 `width: 130` 调大 | 否决 | 面板宽度固定，加宽标签 = 挤掉柱子 |
| `overflow: "break"` 换行 | 否决 | 固定行高装不下多行，会重叠 |
| `triggerEvent: true` + 自造 DOM tooltip | 否决 | ECharts 原生就有 axis tooltip，自造等于再维护一套定位 / 隐藏逻辑 |
| **类目轴加 `tooltip: { show: true }`** | **采纳** | 一行配置；与既有 tooltip 的样式同源 |

## 验收标准

1. hover 横排图的类目名 → 弹出 tooltip，文本是**完整**名字（不是截断后的）。
2. 该 tooltip 的样式与站内其它 tooltip 一致（走同一套 token）。
3. `npm run typecheck` / `lint` / 单测 / `build -w @biff/web` 通过；`rush-analysis.spec.ts` 全绿。
4. 回写文档：本 PLAN；`PLAN.md` 文档头一行「最后更新」。

## 实施结果（2026-09-20）

**实测**（`crowd-want` 榜，类目 = 片名）：

- 轴上的文本：`"Tender Loving Care · 温..."` —— 确实被 `width: 130` 截断（ECharts 在末尾追加 `...`）
- hover 该标签后弹出：`"Tender Loving Care · 温柔以待"` —— **完整名字**
- 弹出层的底色是 `rgb(255, 255, 255)`，正是 `--surface`（走同一套 `sharedTooltip` token，不是 ECharts 默认的黑底）

结论：`tooltip: { show: true }` 这一个配置就够 —— 标签保持截断省地方，hover 时看全名。

**踩到的两个坑（都已写进注释）**：

1. 一开始拿 `facet-year`（年份榜）做探针 —— 它的类目是 4 位年份，**根本不会被截断**，等于什么都没测到。
   要测这件事必须用「类目是片名」的图（`crowd-want` / `crowd-votes`）。
2. E2E 里用 `page.locator("body > div").filter({ hasText: 片名 })` 找 tooltip **会匹配到 app 根 div** ——
   SVG 的 `<text>` 文本同样算进 `textContent`。改成「body 下内联 `position: absolute` 且含该文本的 div」。

**验证**：`typecheck` / `lint` 通过；`rush-analysis.spec.ts` **12 passed**
（新增那条先断言「榜单里确实有被截断的片名」—— 否则测试什么都没测到 —— 再断言 hover 出来的 tooltip
不含 `...` 且比截断值更长）。
