## 1. 现状(代码事实)

- `library.ts::showRow`(影片库 / 我的选片共用):
  ```
  [CODE][影院章][日期][时间]  [66min][15][KE][GV][P.43]   →   [定位 ▸][✓ 已加入]
  章组 = grid grid-cols-3 gap-x-[5px]  ←  等宽列 → 短章(15 / KE)只占自身宽度却要占满 1/3 列,
  章与章之间出现大片空隙(用户反馈「图标之间都有空隙」)

  ```
  Row1  [CODE][影院章][日期][时间][66min]  含映后 25′   →   [⏱25′][含映后][A][☆][✕]

  固定 2 行 + 章组拆两处 → 与选片行**完全不同的排版与顺序**

## 2. 改动

### 2.1 新建 `src/row.ts` — 场次行单一构造

骨架(三处完全一致):
```
[CODE][影院章][日期][时间]   [片长 · 等级 · 字幕 · GV · 页码(紧凑流式)]   →→   [操作组]
```

导出:
- `SHOW_ROW_CLS` — 影片库 / 我的选片场次行默认容器(无边框,节内分隔线由调用方按需加)
- `codeChip(code)` — CODE 章(11px 黑块白字,三处同款)
- `metaChipRow(extraCls?)` — 章组容器(`flex flex-wrap items-center gap-x-[4px] gap-y-[3px]`)
- `screeningRow(opts)` — 行唯一构造
  - `acts` 自动 `ml-auto` 贴右
  - `extra` 自动 `basis-full` 独占第二行(行程特有)
  - `rowCls` 可换外框(行程卡片用 `border + rounded + shadow`)
  - `timeText` 可换(行程用「有效结束」)
  - `hideDate` / `withTopBorder` 选片 tab 节内微调

### 2.2 `src/library.ts::showRow` 改为薄壳

只构造右侧 `acts`(定位 ▸ + 加入三态),其余全部走 `screeningRow`。
删除直接 import 的 `codeTip` / `appendMetaRow` / `uniformChipEl` / `venueTip`(已移至 `row.ts`)。

### 2.3 `src/agenda.ts::buildRow` 改为薄壳

调用 `screeningRow` 统一出第一行;行程差异经 opts 注入:
- `acts` = `buildActs(...)`(映后 / 方案 / 档位 / 移出,沿用)
- `extra` = 新增 `buildNote(...)`:片名(13.5px semibold,truncate)+ 冲突 / 转场提示(右对齐,`ml-auto` 贴右)
- `rowCls` = `CARD_BASE` / `CARD_CONF`(`SHOW_ROW_CLS` + 卡片外框)
- `timeText` = `${start}–${fmtEndClock(effEndMin)}`(跨午夜带次日)
- 删除原 Row 1 的「含映后 25′」inline 文字(`✓ 含映后` 按钮已显式表达,删后信息不丢)

删除直接 import 的 `codeTip` / `appendMetaRow` / `uniformChipEl` / `venueTip`。
新增常量 `CARD_BASE` / `CARD_CONF`。
