## 二、根因(已用探针坐实)

排期表格子版式 = `页码 + 片长' + 徽章 + 韩文名 + 英文名 + code + 时间`。
**块格子的「页码」字段是块内各片的介绍页页码列表**,被排版拆成两个 span:

- `161,` —— 落在 **META 行内部**(同一条旋转文本流)→ 被 `parse_meta` 正确吃成 `pages=[161]`;
- `163, 165` —— 自成一行,`x0=101.7`,相对 META 行 `x0=95.5` 偏移 **6.2pt** ——
  恰好落在 `cell_title_lines()` 的「标题行」判据 `(LINE_X_GAP_LO=2, LINE_X_GAP_HI=18]` 内
  (真英文标题的偏移也是 **6.2**,纯属排版巧合)→ 被当成标题 → 流进 `split_title()` 变成前缀。

关键结构事实:该页是 **90° 旋转文本**,`build_lines()` 给出的 line bbox 里
**整格所有行的 `y1` 都相同**(= 旋转后的公共基线,实测 `y1=123.0`),
所以 `abs(l["y1"] - meta_line["y1"]) <= 2.5` 这条判据对本格**全部行恒真** ——
区分「标题行 / 页码续行」只能靠文本形态。

页号与成员片完全对得上(证毕):

| 块 | code | 成员(介绍页印刷页码) | 格子里的页码 token |
|---|---|---|---|
| Midnight Passion 1 | `008` | Exit 8(161) · Honey Don't!(163) · Weapons(165) | `161,` + `163, 165` |
| Midnight Passion 2 | `081` | The Furious(162) · Halabala(162) · Protector(164) | `162, 164` |
| Midnight Passion 3 | `164` | Bride of the Covenant(160) · My Home(115) · The Holy Boy(163) | `115, 160, 163, 164` |
| Midnight Passion 4 | `244` | Exterior Night(161) | (已干净) |

`extract_schedule.py` **早就定义了** `RE_PAGES = ^\d{1,3}(?:\s*,\s*\d{1,3})+$`,
只是它只作用于 META 行内的 span —— 漏网的那一行没有被它看见。

## 四、改动清单

### A. `tools/extract_schedule.py`(根因修复)

1. **页码续行不再污染标题** —— 新增 `pages_only_line()`:文本匹配
   `^\d{1,3}(\s*,\s*\d{1,3})*,?$` **且** 所有数字落在节目册影片页范围 `(40, 230)` 内
   → 判为页码续行,**并入 `meta["pages"]`,不进 `title_en`**。
   (范围守卫是为了排除「片名就是数字」的极端情形,如 `1917`/`2046` 根本匹配不上,
   `9`/`42` 之类被范围挡掉。)
2. **块徽章** —— `TITLE_TAGS` 加 `(("midnight passion",), "midnight")`
   → 4 个块自动带 `tags: ["midnight"]`(**数据驱动,不硬编码 code**)。
3. **成员表** —— 新增 `parse_midnight_blocks(doc)`:扫全册找单元扉页的对照表
   (行形态:`^Midnight Passion \d+$` → 同行右侧成员行 → 下一行 `<code> Sep D / HH:MM / VENUE`),
   按 `|` 切分并剥掉各片韩文名 → `{code: [片名…]}`;写进 4 条块场次的
   `midnight_members`。
4. **自检** —— 若某场 `title_en` 仍以数字列表开头 → `WARN`(防回归哨兵)。
