# PLAN-20261016000441 — 分享要「点一下」「生成图片」才出图；排行榜自己出两张图（各带复制）

## 目标

> 用户原话（2026-10-16，两轮）：
> ①「红黑榜的分享 和排行榜的分享 都要点击确认后再生成图片」
> ②「排行榜的没有复制图片的 点击分享后会跳到红黑榜的分享」
> ③「红黑榜的排行榜两个榜单需要两张图 单独复制按钮吧」
> 澄清题作答：①=「选完再点「生成图片」才出图（打开分享弹层先不出图）」；②=「排行榜自己出图 + 复制图片（弹层里直接生成并提供「复制图片 / 下载 PNG」，不再跳到红黑榜分享图）」。

**现状（代码事实，不是推测）：**

- `RedBlackShareDialog.tsx:157-184` 的出图 effect 依赖 `[model]` —— **一打开就出图**，之后每次改勾选 / 档位 / 单元都**自动重画**；「下载 PNG 图片 / 复制图片」在 `blob` 出来后出现（`:278-295`）。
- `HotBoardShareDialog.tsx:119-145` 与 `:219-236`：热门榜分享图是**逐字同一套**（自动出图 + 两个按钮）。
- `RedBlackRankDialog.tsx:160-171`：排行榜弹层底部只有「生成分享图 / 关闭」，前者是**交接**（`onShare`）—— 由 `RedBlackPage.tsx:384-388` 的 `openShareFromRank()` 关掉排行榜、打开 `RedBlackShareDialog`，并带 `initialTopN = RANK_LIMIT(50)`（`PLAN-20261015170310` 的决定）。用户在排行榜里**拿不到属于排行榜的图**，也没有「复制图片」。
- 出图实现**只有一份**：`redblack-poster.ts`（`buildRbPosterModel` / `rbPosterHeight` / `drawRbPoster`）；它已经支持 `sections`（勾掉哪个榜就不画哪个榜，`:314-330`，单测 `apps/web/tests/redblack-poster.test.ts:289,298` 已覆盖单榜）。
- `.rb-share-preview` / `.hb-share-preview` **没有 `[hidden]` 守卫**（`redblack-parity.css:803`、`hot-board.css:610` 写着 `display: block`），而本仓库没引 Tailwind preflight（只有 `tailwindcss/utilities`）—— 也就是说 `hidden={!blob}` **当前是失效的**（作者样式的 `display:block` 盖过 UA 的 `[hidden]`）。仓库既有写法是显式补一条（`style.css:1121` 的 `.poster-preview[hidden]`）。本轮「先不出图」会把这一段从「一闪而过」变成「一直可见」，必须一起修。

## 范围

**做：**

1. `RedBlackShareDialog`：打开**不出图**；新增主操作「生成图片」；改了任一选项（单元 / 每榜条数 / 头尾 / 长图内容）→ 已出的那张**作废**（预览与「下载 / 复制」一起收起，按钮变「重新生成图片」）。
   - 「这张长图：W × H px」那行**照旧实时**（它只读模型，不读画布）—— 2026-09-22 的原始诉求不变。
   - 删掉只为交接而存在的 `initialTopN` prop（唯一调用方消失）；`TOP_N_CHOICES` 里的「前 50」**保留**（它填的是「前 20」与「全部」之间的空档）。
2. `HotBoardShareDialog`：同一套「点一下才出图」（用户说「都要」；三个分享入口口径必须一致，否则下次又是一条 bug 报告）。
3. `RedBlackRankDialog`：**自己出图** —— 红榜 / 黑榜**各一张**，每张**自己**的「复制图片 / 下载 PNG」；删掉 `onShare` 交接，不再跳分享图弹层。
   - 两张图 = `buildRbPosterModel({ sections: 只留该榜, topN: RANK_LIMIT })` + `drawRbPoster` —— 同一个出图器换了个入参，**不新写第二条出图实现**。
   - 新增 props：`board` / `skins` / `syncedFaces` / `site` / `mine`（与 `RedBlackShareDialog` 同一组原始输入的命名与含义），页面按同一份数据传。
4. `RedBlackPage`：删掉 `openShareFromRank` / `shareTopN` / `RANK_LIMIT` 那三处只服务交接的代码；`RedBlackRankDialog` 改**懒加载**（它现在带上了 `redblack-poster.ts`，≈9KB gz —— 与同页另外 4 个弹层同一处置）。
5. 样式：`rank-board.css` 补出图块的样式；`redblack-parity.css` / `hot-board.css` 各补一条 `[hidden]` 守卫（见上「现状」最后一条）。
6. E2E（`e2e/react/redblack.spec.ts`）：把「打开即出图」的既有用例改成「点一下才出图」；删掉旧的「交接给分享图」用例，换成新的「排行榜自己出两张图 + 各自复制」。

**不做：**

- 不写第二份「排行榜图」的模型 / 绘制（§5 红线 5）：两张图走 `redblack-poster.ts` 那一份。
- 不动分享图的排序 / 门槛 / 单元切分 / 头尾开关 / 默认档 `TOP_N = 10`。
- 不动 `poster.ts` + `ShareDialog`（看片计划海报 / 导出与分享）—— 那是另外两件事，与本次三个「分享图」无关。
- 不给排行榜弹层加「单元 / 条数」之类的出图选项：它就是「我刚看到的这两份 TOP50」，选项只会让它偏离读数。
- 不改 `redblack-rank.ts`（读数模型与分享图同源那套口径一字不动）。

## 方案取舍

| 备选 | 结论 | 理由 |
|---|---|---|
| 排行榜弹层里再写一份「排行榜图」的模型 + 绘制 | 否决 | 正是 `PLAN-20261015170310` 当初否掉内嵌出图的理由（等于把模型 / 预览再实现一遍，§5） |
| 排行榜复用 `buildRbPosterModel(sections = 单个榜)` + `drawRbPoster` | **采纳** | 上一条的否决理由**不再成立**：模型与绘制仍是唯一一份，排行榜只是换了个 `sections` 入参；`sections` 单榜路径已有单测 |
| 排行榜两张图共用一个「复制图片」 | 否决 | 用户：「单独复制按钮」 |
| 排行榜两张图上下堆叠 | 否决 | 弹层高度直接翻倍；并排（断点 720，与 `.rbr-cols` 逐字一致）窄屏自动堆叠 |
| 打开弹层仍自动出图，只加一枚「生成图片」 | 否决 | 用户要的就是「别在我确认前花掉那次开销」；自动出图 + 手动按钮 = 按钮没有意义 |
| 选项改动后**自动重画**（保留旧行为） | 否决 | 等于「确认一次之后就不必再确认」，与①相反；改成作废 + 「重新生成图片」，让「下载 / 复制」只作用于**与当前选项一致**的那张图 |
| 出图失败后按钮留在「生成图片」 | 否决 | 失败之后应当能原地重试，文案「重新生成图片」才说得通 |
| `hidden` 靠 UA 样式（不给 `[hidden]` 补规则） | 否决 | 本仓库没引 preflight，`.rb-share-preview { display: block }` 会盖掉 `[hidden]`（现状最后一行的实测结论）；既有先例是显式补 `.poster-preview[hidden]` |

## 已知风险（写清）

- **弹层变长**：排行榜弹层现在是「读数 + 两张长图预览」。TOP50 的一张图逻辑高 ≈ 5400px，预览给 `max-height: 60vh` + 内滚的框，**上限加在框上而不是画布上**（压画布高度会让它按比例缩到几十像素宽，等于没法看）。
- **懒加载**：`?rank=1`（分享出去的链接）落地时弹层要等一次 chunk 往返。与同页另外 4 个弹层同样的代价（`Suspense fallback={null}`，同源小 chunk，毫秒级）。
- **E2E 改动面**：`redblack.spec.ts` 里凡「打开弹层 → 断言已出图」的用例都要多一步点击，且改完选项要再点一次；尺寸断言（`.rb-share-size`）**不用**改（那行是活的）。

## 验收标准

1. 打开红黑榜 / 热门榜分享弹层：**没有**预览画布、**没有**「下载 PNG 图片 / 复制图片」，只有「生成图片」；点它之后才出现预览 + 两个按钮。
2. 出图后改任一选项：预览与两个按钮消失，按钮变「重新生成图片」，点它重新出图。
3. 排行榜弹层：点「生成图片」→ 出现**两张**预览（`[data-rbr-shot="red"]` / `[data-rbr-shot="black"]`），每张各有自己的「复制图片 / 下载 PNG」；全程**不出现**「红黑榜分享图」弹层；关掉排行榜后 URL 不留 `rank`。
4. 空榜（`boards.length === 0`）→ 「生成图片」禁用。
5. `npm run typecheck`（含 e2e）/ `npm run lint` 0 error；`npm run test -w @biff/web` 全绿；
   `npx playwright test -c playwright.react.config.ts e2e/react/redblack.spec.ts --project=desktop-chromium` 全绿（贴计数）。
