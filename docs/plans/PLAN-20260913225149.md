# PLAN-20260913225149 — 修复 main 上 E2E 大面积失败

## 目标
> CI run https://github.com/biff-scheduler-Team/biff-scheduler/actions/runs/34757140825
> Gate (verify:quick) 通过，E2E 失败：64 failed / 2 flaky / 233 passed。
> 复现并修复导致 desktop/mobile 多浏览器失败的根因，优先修产品/选择器/测试漂移，不削弱断言。

## 范围
**做:**
- 复现 smoke / compatibility / latest-display / workflows 等代表性失败
- 对齐有意 UI 演进后的测试契约；修边界标签零高度导致 Playwright 判 hidden
- 对先前失败的 desktop-chromium 集群复测；开 PR 到 main

**不做:**
- 不直接 push main；不 force-push；不提交密钥 / dist
- 不为变绿削弱业务断言；不全量反复跑三浏览器做二分
- 不借机做无关重构；不回退「三档排片大小 / quick 浮层 / 官方剧照」等产品决策

## 根因（已复现，非假设）
1. **标题可访问名**：`h1` 现为「排片表 2026 年 10 月」，`exact: "排片表"` 全挂（smoke 等）
2. **`iffday.workspace.cache.v1:guest`**：账号 guest 缓存写入 localStorage，深相等全量 dump 失败（compatibility / legacy）
3. **观影浮层**：仅 `?quick=1` 时有 `#viewing-panel`；`/library|/picks|/agenda` 整页时 FAB `hidden`，旧测点「打开我的观影」超时
4. **排片大小**：旧「放大排片表 / 缩放比例 70%·90%」已换「小/默认/大」(0.45/0.55/0.75)；几何断言仍按 zoom=1 → 240/160/144
5. **边界标签**：`.schedule-boundary` `height:0` 使文案溢出可见但对 Playwright `toBeVisible` 为 hidden
6. **日轴裁剪**：10-06 仅 18–20 三格，`time-axis` 仍期望 >12 刻度
7. **GV 点击契约**：未选片时点映后 =「加入并参加」；旧测期望「不选片只关映后」

## 方案取舍
| 备选 | 结论 | 理由 |

| 更新 E2E 跟当前 UI 契约 | 采纳 | schedule-size 等已跟进；其余漏改 |

| 放宽 timeout / 删断言 | 否决 | 掩盖漂移 |
