# PLAN-20260910163000 — AI 排片:无片单模式引导「先选片」,顺带省上下文

## 背景 / 用户诉求

> 引导用户先选片 也能让 AI 少一点上下文
> · 你还没给任何影片打「必看 / 备选 / 随缘」→ 本次把全部 276 部有排期的影片都作为候选

用户贴出的是**无片单模式**里那句现状文案:它只「告知」了候选池有多大,没有「引导」用户去收窄。
276 部有排期的影片一次性送给 LLM,请求又慢又贵 —— 而用户在「影片库」给十来部片打标,
候选池立刻能缩到十分之一。所以要在面板里把「先选片」变成**一眼可见的行动**,而不只是一行小字建议。

## 设计决策

1. **标题改成引导语**:`tagged === 0` 时 `无片单模式:没有打标也能排` →
   **`还没有选片 —— 不打标也能排,但先打标更快更准`**(先安抚「不阻塞」,再给「更划算」)。
2. **第二条 bullet 讲清收益**:`**先选片更划算**:去「影片库」给想看的片点「必看 / 备选 / 随缘」,
   候选池会从 N 部缩到你打标的那几部 —— 请求更快更省,排出来也更贴你的口味`
   (N = `wantedNow().wanted.length`,与同屏其它计数同源)。
3. **直达按钮**(核心改动):`tagged === 0` 时在卡片底部放一个主按钮
   - 从「我的选片」进来 → `去影片库打标 ▸`:先 `closeModal()`(关掉排片弹层、恢复下层),
     再 `openLibrary(ctx)` 压入影片库 —— 打标完 `← 返回` 回到「我的选片」;
   - 从「影片库」进来 → `← 返回影片库打标`:只 `closeModal()`,**不再叠一层重复的影片库**
     (靠 `openEngineDialog(..., fromLibrary)` 参数区分,影片库入口传 `true`)。
   `data-ai="go-tag"` 作无头验收锚点。
4. **强制无片单模式**(`tagged > 0` 且用户手动勾选)不显示该按钮 —— 那条路径是用户**主动**
   要忽略已打标影片,再劝他「去选片」是自相矛盾;改为提示「想更省 token:取消上面的『强制无片单』开关」。
5. **不改**:`wantedNow()` / `buildPayload` / 复检 / 采纳合并一律不动 —— 本次纯提示层 + 一个导航按钮。

## 改动清单

| 文件 | 改动 |
|---|---|
| `src/library.ts` | ① `import { closeModal, openModal }`;② `openEngineDialog` / `aiPanel` 各加 `fromLibrary` 参数(影片库入口传 `true`);③ `modeBar` 重写:标题改引导语 + 第二条 bullet 讲「先选片更划算」+ `tagged === 0` 时给直达打标按钮 |

| `docs/plans/PLAN-20260910163000.md` | 本文件 |

## 边界与风险

- **不阻塞**:引导按钮是**附加**在原有说明之上的,用户仍可直接选日期 → 点「④ 开始 AI 排片」。
- **弹层栈安全**:两个分支都先 `closeModal()` 再决定是否开新层 —— 不会出现「排片弹层还盖着影片库」。
- **`fromLibrary` 默认 `false`**:漏传只会退化成「多叠一层影片库」,不会出错;两个调用点已各就各位。
- **文案里的数字同源**:`wanted.length` 来自 `wantedNow()`,与 `runBar` / `modeBar` 首条 bullet 同一份计算。

## 验收标准

1. `npm run typecheck` 通过;`vite build` 通过。
2. 读代码核对:
   - `library.ts` 的 `openLibrary` 入口调用 `openEngineDialog(filmList, ctx, render, true)`,
     `openMyPicks` 入口不带第 4 参;
   - `modeBar` 在 `taggedCount === 0` 时渲染 `data-ai="go-tag"` 按钮,文案随 `fromLibrary` 切换;
   - 按钮点击 = `closeModal()` + (`fromLibrary ? 无 : openLibrary(ctx)`)。
3. 无头 DOM 断言(playwright-core + 临时 `python -m http.server` 对 `dist/`):
   无任何打标时开「智能排片 ▸」→ 标题含「还没有选片」、存在 `[data-ai="go-tag"]`、
   文案含「候选池会从」;点它 → 排片弹层关闭、影片库弹层出现。
