# PLAN-20260922142922 — 顶部「更多」菜单里「导出与分享」逐字折行

## 目标

用户反馈（原话）：

> 导出与分享 变成每个字一行了

上一轮 `PLAN-20260922105228` 把顶部三个文字按钮收进「更多」菜单后，「导出与分享」这一项被压成
**12px 宽 × 105px 高**（四个字各占一行）；同菜单的「说明」「设置」是正常单行。

## 范围

**做：**

- 修掉这一项的逐字折行。
- 保住它的点击埋点（`click=export`，白名单 slug 见 `packages/contracts/src/telemetry.ts`）。
- 补一条能复现折行的 E2E 断言 + 一条守住埋点不丢的断言。

**不做：**

- 不动「说明」「设置」两项（它们本来就是字符串 children，行为正确）。
- 不改 `ActionMenu` 的替换决策本身（收纳方向是上一轮用户明确要的）。
- 不改埋点白名单 / 服务端统计口径，不新增 slug。

## 根因

S2 `MenuItem`（`node_modules/@react-spectrum/s2/dist/private/Menu.mjs`）对 children 的处理是：

```js
typeof children === 'string' ? <Text slot="label">{children}</Text> : children
```

只有**字符串** children 会被包成 `slot="label"` 的文本盒，从而落进菜单 grid 的 `label` 区
（`grid-template-areas: ". checkmark icon label value keyboard descriptor ."`）。
上一轮为挂埋点写成 `<span data-track="export">导出与分享</span>`，是元素 children → 原样渲染 →
自动放置到 grid 第一列那段 `.5625rem`（9px）留白里。

浏览器实测（本地 dev server，devtools 取值）：

| 菜单项 | 内层元素 | `grid-area` | 宽 × 高 |
|---|---|---|---|
| 导出与分享 | `<span>`（自己写的） | `auto` | 12 × 105 |
| 说明 / 设置 | S2 包的 `<span slot>` | `label` | 28 × 21 |

## 方案取舍

| 备选 | 结论 | 理由 |
|---|---|---|
| children 改回字符串，埋点移进 `openHeaderAction` 里显式 `trackClick("export")` | **采纳** | 布局回到 S2 的正常路径；`onAction` 覆盖鼠标点选与键盘回车，与 DOM 锚点走同一条白名单通道（`trackClick` 自己挡非法 slug） |
| 保留 `<span data-track>`，给它补 `grid-area: label` | 否决 | 依赖 S2 内部 grid 区域命名，升级后**静默**失效，又变回逐字折行且无人发现 |
| 给 `MenuItem` 挂 `data-track` | 否决 | 类型上就不通：`MenuItemProps` 把 `keyof GlobalDOMAttributes` 整个 Omit 掉了，`data-*` 传不进去 |
| 改用 S2 `Text slot="label"` 包一层并挂 `data-track` | 否决 | 同上，S2 的 `Text`（`ContentProps`）同样不接受 `data-*` |
| 自绘菜单 / 退回三个文字按钮 | 否决 | 与上一轮用户拍板的收纳方向冲突，代价远大于收益 |

## 验收标准

1. 打开「更多」：三项都是单行，高度一致（折行那版「导出与分享」实测 111px）。
2. 从菜单打开「导出与分享」时仍上报一次 `click=export`（拦截 `/api/stats/telemetry-ping` 读请求体）。
3. 命令：`npx playwright test -c playwright.react.config.ts e2e/react/share-export.spec.ts --project=desktop-chromium`
   （修复前该 spec 5 条里 2 条红 → 修复后 5 条全绿）。

## 验证结果

- 修复前：新断言红 —— 「更多」菜单项高度 111px（>60 阈值）。
- 修复后：`share-export.spec.ts` 5 passed；回归邻域 `workflows` / `smoke` / `parity-dialogs` 19 passed
  （desktop-chromium）；`npm run typecheck` 通过；`npm run check:test-map` 同步。
