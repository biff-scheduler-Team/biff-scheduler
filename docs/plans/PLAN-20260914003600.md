## 方案取舍

| 备选 | 结论 | 理由 |
|---|---|---|
| A. 仅靠同域 cookie + LS，「legacy 不用登录 UI」 | **否决** | 云端 sync 只挂在 React；legacy 独用时无法登录/上传，不满足「legacy also joins the account system」 |
| B. Legacy 整页跳去新版登录，callback 回 legacy；legacy 内嵌**无 React**的薄同步客户端（复用 `/api/account/*` + 与 `sync-data` 同构的读写） | **采纳（主方案）** | cookie 已 Path=/；避免 React 进 legacy；与「两套前端、一套账号」一致。同步逻辑优先抽到双方都能 import 的模块（或 legacy 复制最小 fetch 层并单测锁行为），禁止第二套 merge 语义 |
| C. 把 `account-sync.ts` 原样 import 进 legacy | **慎用 / 倾向拆分** | 该文件依赖 React 启动路径与 `AccountHost` DOM；宜拆「纯 sync 核心」+「UI 壳」，legacy 只用核心 + 极简按钮 |
| D. 桌面继续浮层，仅用 CSS 视觉「像 1:3」 | **否决** | 浮层不占布局宽度，无法形成真实 1:3；且与用户「split columns」字面不符 |
| E. 桌面 ≥1100：挤压式分栏（选片/行程 \| 排片）≈1:3 + 工作台 max-width；`?quick=1` 浮层改为「桌面分栏的一种入口」或收敛为窄屏专用 | **采纳** | 对齐 legacy 挤压抽屉因果（选片与网格同屏）；超宽用 max-width 回收 CONVENTIONS 曾去掉的上限。**具体 max-width 数值见开放问题**（建议候选 1440 / 1600 / 1680） |
| F. 想看人数：每次读时全表扫描所有 `festival_document` 聚合 | **否决为热路径** | D1 全表扫贵且难缓存；可作为离线批处理兜底，不作为请求时计算 |
| G. 新表 `film_want_stat(edition, film_key, weight_sum, …)` + 登录用户 sync/import 时差分更新；匿名走可选的最小化 `POST`（只报 film_key 集合，权重 0.75） | **采纳（方向）** | 读路径 O(影片)；写路径跟既有 sync 挂钩。匿名上报需用户拍板隐私/同意（开放问题） |
| H. 仅统计已登录用户（权重恒 1.0），匿名 0.75 不做 | **备选兜底** | 若用户拒绝任何匿名上报，则只聚合 `festival_document` 的 `pick:*`，文档标明「匿名暂不计入」 |
| I. 改 `account_id` 迁就本机 wrangler 登录 | **否决** | 用户明确禁止；线上资源在 `62cbe67b…` |

#### P1 — 账号一体（共享 cookie / LS / D1）

**拟改文件：**

- `apps/web/src/account-sync.ts` / `sync-data.ts` / `workspace-storage.ts` — 抽出可被非 React 入口调用的 sync 核心（若拆文件：如 `account-sync-core.ts`）。

- `apps/web/legacy/src/state.ts` — `saveLocal` 等持久化改为触发与 React 同口径的「工作区变更」通知（或调用共享 `writeWorkspaceItem` 等价物），以便已登录时能 schedule sync。

## 验收标准

1. **同一登录**：在新版登录 IFFDAY 后打开 `/legacy/`（或反向），无需二次 OAuth 即显示已登录（或等价：`/api/account/me` 200 + UI 显示显示名）；两边读到同一 `biff.picks.v2` 内容。

3. **桌面分栏**：viewport ≥1100 且选片/行程与排片同屏时，两侧宽度比约 1:3（允许 ±5% 测量公差）；工作台有 max-width，超宽屏左右留白。
4. **想看人数**：接口返回值为加权和四舍五入后的整数；匿名权重 0.75、登录 1.0 的单测绿；UI 至少一处展示该数。
5. **测试**：`npm test` 相关单测绿；桌面相关 E2E：
   `npm run verify:ui -- e2e/react/floating-panel.spec.ts e2e/react/desktop.spec.ts e2e/react/account-integration.spec.ts --project=desktop-chromium`
   （实现阶段按 TEST-MAP 增补 want-counts / legacy）；证据贴测试计数。
6. **部署**：不修改 `account_id`；上线走 `git push origin main`。若必须本机 `wrangler deploy`，操作者先 `wrangler login` 到 **`62cbe67b545f2d12c986729ac7ffcee8`**，不得改配置迁就 `cd649aed…`。
