# PLAN-20261015153233 — 红黑榜加一个「排行榜」：红榜 / 黑榜 TOP50 一屏直读

## 目标

> 用户原话：「红黑榜有直观的榜单吗 在快速投票旁边加一个榜单 简单展示红榜 黑榜 TOP50 因为现在贴纸区
> 只需要显示影片的名称海报 以及红黑贴纸数 只需要样式参考分享图就行」

现状（代码事实）：红黑榜那一页只有**卡片栅格** —— 每张卡左边是海报 + 片名 + 红黑数，右边一大片是
贴纸画布（`RedBlackPage.tsx` 的 `.rb-grid`）。顺序虽然按票数排过（`redblack.ts::sortByVotes`），
但**没有名次、也没有一份「就 50 行、扫一眼看完」的读数**：要看排行就得在近 300 张卡之间滚，
而每张卡的一半面积是贴纸画布。所以这一页确实**没有**直观的榜单。

本轮补上：页头「快速投票」旁边加一枚「排行榜」，打开一个弹层 —— **红榜 / 黑榜各 TOP50 并排**，
一行只回答三件事：**第几名、哪一部（海报 + 片名）、红黑各多少票**。

## 范围

**做**

- 新增 `apps/web/src/redblack-rank.ts`（纯逻辑：`RANK_LIMIT = 50` + `buildRankRows()`）——
  门槛与排序**逐字复用** `redblack.ts::boardHasVotes` / `sortByVotes` / `boardFilms`，
  与分享图同一支（§5 口径单一来源）。
- 新增 `apps/web/src/components/RedBlackRankDialog.tsx` + `apps/web/src/components/rank-board.css`
  （版式参考分享图的行：名次 → 行内海报 → 片名（中 / 英）→ 红 N · 黑 N）。
- `apps/web/src/pages/BoardPage.tsx`：页头「快速投票」旁加「排行榜」按钮（弱按钮），
  开关走 URL `?rank=1`；焦点归还照 `?vote=1` 那套（弹层真正卸载之后再还）。
- `apps/web/src/pages/RedBlackPage.tsx`：读 `?rank=1`，用页面**那一份**修正过的票数
  （`reconciledCrowd`）与 `priorRate` 渲染弹层。
- 单测 `apps/web/tests/redblack-rank.test.ts`；E2E 追加到 `e2e/react/redblack.spec.ts`。
- `scripts/test-map.json`：把三个新路径登记进 `redblack` 那一组（人读版由 `--write-doc` 生成）。

**不做**

- 不动卡片 / 贴纸画布 / 现有排序冻结机制 —— 一行 JSX 都不改。
- 不做「点一行开影片详情」（没要求，且要多引一条导航依赖）。
- 不做单元筛选、不做「每榜几条」档位（那是**分享图**弹层的事，这里固定 TOP50）。
- 不新增页内 tab、不改 `?sort` 的语义（红 / 黑 / 热门三档原样）。
- 不加新依赖、不引 ECharts（榜单页是非 lazy 路由，右侧多一个依赖就拖着首屏一起胖）。
- 不碰工作区里**另一位会话在途**的改动（`apps/web/src/pages/redblack-parity.css` 与
  `e2e/react/redblack.spec.ts` 的窄屏 hero 那 105 行，见 §7「只提交自己的 hunk」）。

## 方案取舍

| 备选 | 结论 | 理由 |
|---|---|---|
| 用 canvas 重画一张分享图当弹层 | 否决 | 那是「出图」的活，已有「生成分享图」；弹层要能滚、能被读屏念、能 Ctrl+F 搜片名 |
| 两列并排（红左黑右） | **采纳** | 「红榜 黑榜 一起看」正是用户那句「简单展示红榜 黑榜」；桌面两列各自成一条滚动区，窄屏自动堆成单列 |
| 一个分段控件，红 / 黑切换着看 | 否决 | 要多一次点击才看得到另一半，而且多一份「当前在看哪一榜」的状态 |
| 颜色照抄分享图（深底海报色） | 否决 | 那张图是 canvas 深底海报（`poster-brush.ts::COLORS`）；弹层活在应用里、要跟亮 / 暗主题走 —— 「参考分享图」参考的是**版式与字阶层级**，颜色仍走 token（§5）；红 / 黑两个数字复用既有 `.rb-tally__*` |
| 榜单行做成可点（开影片详情） | 否决 | 本轮只要「读」，多一条导航依赖就多一份回归面 |
| 弹层懒加载（照 `RedBlackShareDialog` 那几处） | 否决 | 那几处懒加载是因为一条链上带着 poster / qrcode（KB 级）；本弹层只 import 已在页面里的 `redblack.ts`，懒加载只换来一次无谓往返 |

## 验收标准

1. `/redblack?sort=red&rank=1` 打开弹层：`.rbr-col[data-rbr-board=red]` 与 `...[data-rbr-board=black]`
   各最多 50 行，每行含**名次 / 海报 / 片名 / 红 N · 黑 N**。
2. 黑榜里的每一行 `black > 0`、红榜里的每一行 `red > 0`（门槛与分享图同支 `boardHasVotes`）。
3. 单测先红后绿（贴出红色那次的失败值）；E2E 同样先红后绿。
4. `npm run verify:quick` 之外，至少跑 `node scripts/affected-specs.mjs --files <本轮改动>`，
   命中 `redblack` → 按 §4.5 走 PR（**推之前等用户确认**）。
