## 本次改动方案(全部 src/,无新依赖)

### A1+A3 grid.ts
- 删 `AXIS_START/AXIS_END/LAST_TICK_BUMP`;新增 `TRAIL_PAD=60`、`AXIS_FALLBACK`、`AXIS_LEAD_MIN=30`。
- 新增 `axisRangeFor(cat, date)`:遍历当日场次取 [最早开映−30min 取整点, 最晚散场取整点],无排片回退 9-23;返回整点对齐的轴界(分钟)。
- `buildGrid` 按日期算轴 → 宽度/pxPerMin/卡片定位全部基于当日轴。
- ruler 重构为 `buildRulerTicks`:
  - 整点标签 h0..h1 全部画在轨道内;**首根左锚定**(不居中,防左越界),其余居中。
  - 标签文本 `String(h % 24)` 补零 + ":00"(24:00 → 显示 00:00),`tabular-nums font-bold`。
  - 每整点 +6px 短刻度线(bottom-0,与行内整点竖线同 x)。
  - 仍可点=时间筛选(B1),dataset.hour 保留。
- 「现在」:`nowPxFor(axis, pxPerMin)` 基于当日轴判定/定位。

### A2 grid.ts(行内竖线)
- 场馆行背景两段渐变改色:hour = `color-mix(ink 10%)`,half = `color-mix(ink 4%)`,贯穿整行、浮于卡片下层。

### A4(已完成,不改)

### A5 main.ts
- boot 里挂 20s 定时器:nowKey = `今日ISO HH:MM`;变化且仍在看今天 → `renderGrid()`(跨分钟/跨天/进出轴窗口自动刷新,角标补零已就位)。

### C1 agenda.ts + main.ts + style.css
- `AgendaCtx` 增 `slotDate?: string; slotHour?: number|null`。
- `buildRow`:当日且时段命中 → `slot-hit` 高亮;当日且不命中 → `hour-dim` 淡化(与网格同一套降噪语言);其余日期不受影响。
- main.ts:整点点击/取消/切日期/跳日期/jumpToScreening 重置 hourFilter 后补 `renderAgenda()` 同步。
- style.css 新增 `@utility slot-hit`(淡红整行底,!important 覆盖冲突行底色同族)。
