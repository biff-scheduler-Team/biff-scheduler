# PLAN-20260917003630 — 排片表的影片信息改成悬停显示（鼠标点击不再把弹层钉住）

## 目标

用户原话：

> 排片表中的影片信息改成 hover 显示吧 不然点击了之后 还要点击关闭

把症状还原成机制（已核实，非推测）：

- 「排片表中的影片信息」= `apps/web/src/components/ScreeningInfoPopover.tsx` 那个 ⓘ 按钮
  （`SchedulePage.tsx:471` 每个网格块右上角渲染一次，`aria-label="场次 <code> 影片资料"`，
  内容即片名 / 海报 / 影院 / 时长 / 简介 / 相关影片）。
- 它**已经**支持悬停展开（`ScreeningInfoPopover.tsx:50`：`onPointerEnter` 延时 180ms → `mode='hover'`），
  但 `onClick` 会把弹层切成 `pinned`（`:52`），而 `leave()` 只对非 `pinned` 状态收口（`:37`）。
- 于是鼠标点一下 ⓘ（或手抖点到）之后弹层就**钉死**在网格上方，只能点 `×`（`:60`）或 Escape 才收 ——
  这正是用户说的「点击了之后 还要点击关闭」。弹层本身盖住半个网格，钉住后很碍事。
- 另外 `content` 上的 `onFocus → pinned`（`:59`）在 React 里的 focus 是冒泡的，鼠标点弹层里任意位置
  也会把它钉住，同样是「点一下就得点关闭」的来源。

## 范围

**做：**

1. `ScreeningInfoPopover` 的显示口径改成「**悬停即展开、指针移开即收**」：
   - 鼠标进入 ⓘ → 展开（保留 180ms 防误触延时）；鼠标点一下 → **立刻展开**（不等延时），
     但仍然**不钉住**，指针移开即自动收起。
   - `pinned` 只留给**没有 hover 可依赖**的输入：触摸点按、键盘 Enter / 空格激活
     （用 `onPointerDown` 记下 pointerType 区分鼠标与触摸；键盘激活不产生 pointerdown）。
     这两条路径仍可用 `×` / Escape / 再点一次 ⓘ 收起，Escape 与 `×` 依旧归还焦点。
   - 去掉 `content` 的 `onFocus → pinned`：键盘路径由「激活时置 `pinned` + 焦点进内容」保证，
     鼠标点弹层内部不再把它钉住。
2. 回归测试（`e2e/react/screening-popover.spec.ts`）：
   - 改写前两条用例以匹配新口径；
   - **新增断言（先红后绿的那条）**：鼠标点 ⓘ 之后把指针移开 → 弹层自动消失（不需要点 `×`）；
   - 保留「悬停 → 指针跨到弹层里仍保持展开」「键盘 Enter 钉住、Escape 关闭并归还焦点」
     「点『查看完整影片资料』进详情页」等既有覆盖。

**不做：**

- 不动 `ScreeningCard` / `AgendaPage` / 影片库里的 `资料` 按钮（那是打开完整资料弹层，不是本弹层）。
- 不改 `GvDurationPopover`（那是表单，点开点关是对的）。
- 不动弹层内容与样式（`schedule-parity.css` / `style.css` 的 `.screening-info-popover` 一律不改），
  不改 ⓘ 的尺寸 / 位置 / 图标。
- 不动 `biff.*` 数据契约（无迁移）、不引依赖、不动 `legacy/`。

## 方案取舍

| 备选 | 结论 | 理由 |
|---|---|---|
| 保留点击钉住，只是把 `×` 做得更显眼 | 否决 | 用户的痛点就是「不想要钉住这个状态」，不是找不到关闭按钮 |
| 彻底删掉 `pinned`，连键盘 / 触摸也只靠 hover | 否决 | 键盘与触摸没有 hover，删掉就等于这两类输入无法打开弹层 |
| 保留 `pinned` 但**只**给键盘 / 触摸，鼠标一律走 hover（本方案） | 采纳 | 鼠标得到「移开即收」，键盘 / 触摸仍可正常打开，改动面最小 |
| 悬停改挂到整个网格块（`.gantt-slot`） | 否决 | 网格很密，扫一遍鼠标就满屏弹层；入口仍是 ⓘ |

## 验收标准

1. `/schedule?date=2026-10-07`：鼠标移到 `008` 的 ⓘ 上 → 弹层出现；指针移开 → 自动消失。
2. 鼠标点一下 ⓘ → 弹层出现；**把指针移开 → 自动消失**（不再需要点 `×` / Escape）。
3. 键盘：Tab 到 ⓘ 后按 Enter → 弹层出现；Escape → 关闭且焦点回到 ⓘ。
4. 触摸 / 移动端：点 ⓘ → 弹层出现；点 `×`（或弹层外任意处）→ 关闭（无 hover 可用，行为不变）。
5. 命令：`npm run verify:quick` 绿；
   `npx playwright test -c playwright.react.config.ts e2e/react/screening-popover.spec.ts e2e/react/combined-screenings.spec.ts --project=desktop-chromium` 绿。
