# PLAN-20260910135734 — 设置弹层:信息分组 / 排版规范 / 视觉层级优化

## 背景 / 用户诉求

> 整体弹窗的结构很清晰,但细节上的视觉层级和文字密度可以进一步优化。辅助说明文字偏多、
> 标点与空格排版略显拥挤。① 标签与输入框对齐散乱 → 统一左对齐;② 「转场/闹钟」与「GV 映后谈」
> 之间加浅灰分割线分组;③ 盘点中英文空格与标点(30–60 → 30 - 60 分钟;25min,故默认 25 →
> 25 分钟;全角标点),长句精简;④ 分段控件降饱和(不要大红底白字);⑤ 底部「清空」降级为
> 灰色弱化按钮、「保存设置」保持唯一亮色主按钮。

## 现状(读代码定位)

`src/main.ts`:

- `settingsField(label, hint)`(L575)生成 `label > [row(标题 span + 控件)] + hint`。四个字段
  垂直堆叠在 `body = el("div", "grid gap-3")` 里,**无分组**;标签长短不一时,控件紧贴标题
  但整体看上去仍是一片文字。
- f1/f2/f4 的 `<input>` 各自复制一遍 `w-[90px] border … px-2 py-[5px] text-[13px]`(三份重复),
  单位「(分钟)」写在**标题里**,既拉长标签又让输入框右侧留白不齐。
- f3 分段控件 = `rounded-full` + 选中态 `bg-biff text-on-brand`(**品牌红实底白字**),
  在纯白弹层里比「保存设置」还抢眼。
- 底部 `actions = flex gap-[10px]`:「保存设置」(红渐变实底)与「清空全部已排场次(A+B)」
  (红框 + 红字 + 浅红底)同排、同高、同色系 → 视觉权重接近,易误触。

## 设计决策

1. **字段骨架统一**(`settingsField` 重写):`标题 + 控件` 同一行**流式左对齐**(控件紧贴标题,
   不再出现右侧散乱的输入框列);单位改为**框外后缀**(`unit` 参数);说明另起一行
   `text-[12px] text-muted leading-[1.6]`(行高放宽,长句不挤)。
   新增 `tag` 参数:含 `button` 的控件(分段选择器)必须传 `"div"` —— 否则点标题会冒泡到
   `label` 内首个 button,变成误选(现存隐患)。
2. **输入框收口** `settingsInput(value, max)`:`w-[76px]` + `text-center tabular-nums` +
   focus 红描边(与 modal.ts 豆瓣输入框同一口径)。三处重复的类名一并消除。
3. **分组**:`导出 / 转场`(f1+f2)与 `GV 映后谈`(f3+f4)之间一条 `border-t border-line-soft`
   浅灰分割线 + `pt-[16px]`;**不加小标题**(标签已自解释,少一层文字 = 降密度)。
4. **分段控件改 iOS 风** `segmented()`:灰轨道 `bg-raised` + `p-[2px]` + `rounded-[8px]`,
   选中滑块 `bg-card text-ink shadow-[var(--shadow-card)]`,未选 `text-muted hover:text-ink`。
   零品牌红 → 权重回到「次要开关」。
5. **底部重排**:主按钮 `保存设置` 独占一行**右对齐**(`justify-end`,唯一亮色);
   危险操作降级为**无边框/无底色的灰色文字按钮**,移到弹窗**最底部单独区域**,与主按钮之间
   再加一条 `border-line-soft` 分割线 → 误触路径被物理隔开。
6. **文案规范化**(全角标点 / 数字与单位留空 / 长句精简):
   | 原 | 新 |
   |---|---|
   | 导出 .ics 的闹钟,建议 30–60 | 导出 .ics 日历时的闹钟提醒,建议 30 - 60 分钟。 |
   | 跨影院场次按此值判定冲突;同影院不受影响。默认 0 = 仅判时间重叠 | 仅用于判定跨影院场次的冲突,同一影院不受影响(默认 0 为仅判定时间重叠)。 |
   | 仅对未单独设置的 GV 场生效:…(长句) | 新增 GV 场次时默认选中的状态(后续可在具体行程中单独切换)。 |
   | 所有 GV 场次按「正片 + 映后谈 N′」拆两段…官方排期里 GV 场次已含 25min,故默认 25 | 官方排期包含 25 分钟映后谈,设为 0 则不拆分映后段(可逐场覆写)。 |
   (表中逗号/括号/冒号实际落地为全角「,」「(」「)」「:」。)

## 边界与风险

- `settingsField` / `settingsInput` / `segmented` 均为 `main.ts` 模块内私有,调用方只有
  `openSettings` / `openTalkMinModal` → 签名变更无外部影响(`npm run typecheck` 兜底)。
- **并行会话热点文件**:`PLAN-20260910135532`(AI 排片)计划在 `openSettings` 追加
  「AI 排片 Key」只读行 → 该行应接在 **GV 分组之后、`actions` 之前**;本轮先落地新结构,
  提交按 SKILL `parallel-agent-safe-commit` **只带 `src/main.ts` + 本 PLAN**。
- **Tailwind v4 只生成完整字面量类**:本轮新增/复用的类(`bg-raised` / `border-line-soft` /
  `shadow-[var(--shadow-card)]` / `tabular-nums` / `hover:text-conf` / `underline-offset-2` /
  `transition-[background-color,color,box-shadow]`)构建后必须 `grep` 产物 CSS 核对命中。
- 并行会话在途改动(`grid.ts`/`library.ts`/`legend.ts`/`types.ts`/`public/venues.json`)
  → **部署走隔离 worktree**(detached 到本轮 commit + 软链 `node_modules`),不带对方在途改动。

## 验收标准

1. `npm run typecheck` 通过。
2. `vite build` 后 `grep` 产物 CSS:新类全部命中(尤其 `shadow-[var(--shadow-card)]` 在
   设置弹层里的用法与 `border-line-soft`)。
3. 无头 DOM 断言(playwright-core + 缓存 chromium + 临时 `python -m http.server` 对 `dist/`,
   用完 `pkill`;见 SKILL `web-ui-headless-interaction-qa`):
   - 点「设置」→ 弹层可开,`#modal-root` 内 4 个字段 + **2 条分割线**;
   - 每行「标题 + 控件 + 单位」同排(标题与输入框 `getBoundingClientRect().top` 同一水平线);
   - 分段控件:两段文案正确、选中段为白底(`bg-card`)、**不含 `bg-biff`**;
   - 危险按钮:无边框/无底色类(`border-0` + `bg-transparent`),位于主按钮**下方**(top 更大);
   - 改提醒提前量 → 点「保存设置」→ `localStorage["biff.settings.v1"].alarmMin` 生效 + 弹层关闭。
4. 线上核对带 cache-buster:`curl -sL "https://biff-scheduler.pages.dev/?cb=$(date +%s)"`。
