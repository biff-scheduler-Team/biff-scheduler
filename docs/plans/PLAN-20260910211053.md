# PLAN 2026-09-10 21:10:53 — 影片资料弹层:三段 seg → ★ 星标(与行程卡同款)

> 需求(用户原话):「不要在影片资料中标记必看 备选随缘 需要和我的行程里面一样 直接在卡片上标记等级」
> 本文件 = 本需求唯一规划文档。前置:`PLAN-20260910184745` §8(★ 图标化)、`PLAN-20260910192230`(picks tab 去掉 ★)。
> **本文件已实现**(2026-09-10 21:1x)。

## 1. 现状(代码事实)

影片资料弹层 = `modal.ts::showFilmModal` / `showCatalogFilmModal`,两者都渲染 `buildWishRow(key)`:

```
我的选片   [ 必看 | 备选 | 随缘 ]   已选 2 场 · 档位为影片级,改这里全片同步;场次增删在网格 / 影片库
           └─ pick.ts::buildWishSeg:三段文字 seg,当前档实心着色(--pri-*-soft 实底 + 白字)
```

同一份 `store.picks` 的档位入口当时共四处,**控件形态已不统一**:

| 位置 | 控件 |
|---|---|
| 甘特卡标题行前 | 15px ★(`grid.ts`) |
| 「影片库」卡片右上角 | 20px ★(`library.ts::filmRow`,仅 library tab) |
| 「我的行程」行程卡操作组 | ★(`agenda.ts::buildActs`) |
| **影片资料弹层** | **「必看\|备选\|随缘」三段 seg**(本轮要改的) |

## 2. 决策

**影片资料弹层的档位控件改为 `pick.ts::wishIcon`(★),与行程卡完全同款** ——
三档文字收进 hover 提示 + 点击菜单(菜单本就存在,`openWishMenu`):

```
我的选片   ★   已选 2 场 · 档位为影片级,改这里全片同步;场次增删在网格 / 影片库
```

- ★ = 已定档(按档位着色:蓝=必看 / 品红=备选 / 灰蓝=随缘)/ ☆ = 未设;点击弹「必看 / 备选 / 随缘 / 清除档位」。
- **尺寸 `size: "lg"`(26px 盒 / 18px 星)**:弹层里没有卡片底衬托,13px 的星标会显得像装饰、
  不像一个可点的档位控件;`wishIcon` 新增可选 `size`,卡片 / 行程行仍用默认 `md`(20px / 13px)。
- **保留整行**(「我的选片」标签 + ★ + 计数提示):`PLAN-20260910192230` 把 picks tab 卡片的 ★ 去掉了,
  资料弹层是该 tab 内**唯一**的改档入口(见 §4)。

**不动的**:`state.ts` 数据层、菜单 `openWishMenu`、行程卡 ★、影片库卡片 ★、甘特 ★。

## 4. 边界与风险

- **删 `buildWishSeg` 的安全性**:grep 全仓仅 `modal.ts` 一处消费;`PRI_BG_ON` 仅被 `buildWishSeg` 消费。
  删除后 `bg-pri-must` / `bg-pri-maybe` / `bg-pri-wild`(实底)在源码中再无出现 ——
  `PRI_TAG` 用的是 `-soft` 浅底、`PRI_TEXT` 用的是 `text-pri-*`,不受影响。
- **picks tab 的改档入口**:该 tab 卡片自 `PLAN-20260910192230` 起没有 ★,
  故**必须保留弹层里的 ★** —— 否则从「我的选片」tab 改档只能切回影片库 tab。
- **可发现性**:三档文案从常显改为 hover 提示;计数提示补了一句「点 ★ 打标后…」引导。
  `data-tip` 走全站 tooltip,与行程卡 / 影片库卡完全一致。
- **`draw()` 重绘**:档位改后仍就地重画 ★(弹层不在 `renderAll` 重建范围内),口径不变。
