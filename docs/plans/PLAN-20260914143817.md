# PLAN-20260914143817 — 对齐 BIFF 官网口径：修 4 处错 + 补票务信息

## 目标

用户要求「同步官网信息，不要传递错误信息给用户」。对照 BIFF 官网 2026 最新口径
（Newsletter Vol.6–Vol.10、票务页 `page_num=11402`、节目页 11218/11219/11223/11226/11366、
开闭幕式页 11233、排期页 `date.asp?day1=N`、Selection List `prog_all_list.asp?c_idx=N`）
逐条核对项目现有数据，修掉会误导用户的地方。

> 用户原话：「我的意思是当前项目有什么需要增加/修改的 需要同步官网信息 不要传递错误信息给用户」
> 选定范围：「只修错（第 1–4 条）＋ 补票务信息（第 8 条）」

## 范围

**做：**

1. **`festival-extras.json` 混入 2025 年遗留节目**（最严重）
   - `338` "Carte Blanche: Small, Slow But Steady x EUN Huigyeong"（dateText `Sep 22`）
     串到了 2026-10-10《Elephants in the Fog》
   - `408` "Carte Blanche: Eureka (remastered) x BONG Joon-ho"（dateText `Sep 23`）
     串到了 2026-10-11《Nothing Has Happened Yet》
   - 后果：UI 把这两场渲染成「Carte Blanche · 特别对谈」，嘉宾显示殷熙京 / 奉俊昊，
     日期显示**展期外**的 9/22、9/23
   - 根因：`tools/scrape_biff_extras.py:379` 只按「code 是否在 schedule.json 里」过滤，
     而 2026 排期复用了 338 / 408 这两个编号 → 过滤失效
   - 修：数据删两条 + 脚本加**展期校验**（`dateText` 落在本届展期内才保留），防复发

2. **`InfoDialogs.tsx` 影院文案「南浦洞的 MEGABOX 本届未参与」是错的**
   - 官网：Community BIFF 第 9 届在**南浦洞**（BIFF 广场 / MEGABOX Busan Theater /
     Catholic Center Space 101.1），10/8–10/11；票务页明确「Community BIFF 放映**仅可**在
     MEGABOX Busan Theater 4F 票亭预订」
   - 即 MEGABOX 参与了，只是只承接 Community BIFF（本工具未收录该批排期）
   - 修：`InfoDialogs.tsx:293-295` 文案 + `legend.ts:133-134`、`filters.ts:97-99` 两处注释同步

3. **2 部片 `unit` 被 xlsx 覆盖改错（互换）**
   - 官网 prog_view section（`/tmp/biff2026/films-web.json`）：
     - `Spirit Guardians: The Last Secret Of The First Emperor`（大圣崛起）= **A Window on Asian Cinema**
       → 项目标成 `Open Cinema`（4 场 161/316/419/641 全在 BCM / LOTTE，无屋顶剧场场次）
     - `The Violinist` = **Open Cinema** → 项目标成 `亚洲电影之窗`
   - 修正后两边同时归位：亚洲电影之窗 27 部、Open Cinema 5 部，与官网 prog_view 计数一致
   - 根因：`tools/build_films_2026.py:189-192` 用 xlsx 的 `unit` 覆盖官网 section
     （该覆盖**有意保留** —— 官网 `Vision` / `Wide Angle` / `Korean Cinema Today` 是粗单元，
     xlsx 细到 `Vision–Korea` / `广角镜 - 纪录片放映` / `KCT – Panorama`，实测 89 处有价值的细化）
   - 修：加**显式纠正表**（只覆盖这 2 条），不动通用覆盖规则

4. **`ceremony` 时间表与排期页 `001` 场次并列展示会自相矛盾**
   - 官网两页 2026 口径不一致：开闭幕式页（11233）写「20:20–21:40 放映」，
     排期页写 `001` = 10/6 **18:00** 开始（BCC Roof Theater）
   - 项目 `schedule.json` 取排期页（正确），但弹层原样展示 20:20，用户会以为错过
   - 修：弹层加一句口径说明

5. **补票务信息**（官网 `page_num=11402` 有、项目缺）
   - **购票入口 `https://ticket.biff.kr/`** —— 现状 `ticketing.url` 是「官方购票说明页」
     （文档页 11402），却被当作 `buildTicketIcs` 的 `bookingUrl` 写进 `.ics` 描述
     （`InfoDialogs.tsx:120`），等于把说明页标成「购票入口」
   - 线上售票期（9/17–10/15，24 小时）
   - **取消 / 退款政策**（放映前 60 分钟内可取消；6 天以上免费；5–3 天 ₩1,000／开闭幕 ₩3,000；
     2 天–60 分钟 ₩3,000／开闭幕 ₩9,000）
   - 折扣适用条件（65 岁以上 = **1961 年及以前出生**；BCC 付费会员仅限 BCC 一般放映 +
     Open Cinema；轮椅位**不支持线上预订**）
   - 票亭地点清单 + 营业时间、数字弱势群体服务台、客服邮箱 `cs@biff.kr`

**不做：**

- **Community BIFF 整批**（42 节目 / 69 部片 / 10/8–10/11）—— 需要新增一整条抓取管线，
  工作量远超本轮，留待后续 PLAN
- **Talk-to-Talk 15 场**（`page_num=11224`）—— 官网该页未列 Code 与票价，两批开票都不含它，
  极可能免费；贸然抓取会走 `priceOf` 默认档标成 ₩10,000，正是要避免的错误信息
- **Midnight Passion 片单** —— **上一轮误判**：`schedule.json` 已有 `midnight_members`
  （075 = Sapiens / The Chain of Roses / The Spiral；168 = Red Thread / The Scar-Faced Cat / L'Autre；
  269 = Jim Queen / Welcome to Dolly′s House / Angel′s Egg，共 9 部），与官网 Vol.9 完全一致，
  无需改动
- **`491` 安圣基对谈 `guest` 为空** —— 官网节目页 11223 明确嘉宾是影评人 JUNG Sung-il，
  但补 guest 会牵动 `GUEST_ZH` 译名口径（项目「郑圣一」vs Vol.10「郑成日」），单独处理
- **主竞赛 13 部 vs 官网 14 部** —— 需逐片核对，不在本轮
- 不动 `schedule.json` / `venues.json` / `douban*.json`

## 方案取舍

| 备选 | 结论 | 理由 |
|---|---|---|
| extras 过滤：只删 338/408 两条数据 | 否决 | 治标；下次重跑脚本又会写回 |
| extras 过滤：按 `dateText` 落在展期内 | **采纳** | 通用规则，能防住「往届遗留 code 被复用」这一类复发 |
| extras 过滤：按 code 白名单硬编码排除 | 否决 | 每届都要维护，且掩盖真实成因 |
| unit：让官网 section 全量优先 | 否决 | 会丢掉 89 处有价值的细化（`Vision–Korea` 等） |
| unit：显式纠正表（仅 2 条） | **采纳** | 改动面最小、有据可查、重跑可复现 |
| unit：改 `data/films-catalog-2026.json` | 否决 | 那是 xlsx 提取产物，改它下次重跑被覆盖，且丢失「官网为底座」的语义 |
| unit：重跑整条 films 管线 | 否决 | 会带来 id 重排 / 配对结果漂移等大量无关 diff，风险远超收益 |
| 票务新字段：直接改 `FestivalExtras` 必填字段 | 否决 | 旧 JSON 会类型错；`loadExtras` 是静默降级的，必须**只增可选字段** |
| 票务新字段：新增可选字段 + UI 可选链 | **采纳** | 契约只增不改，缺文件时自动隐藏 |
| ceremony：把 slots 改成排期页口径 | 否决 | 会丢掉官网开闭幕式页原文（封路时段等有效信息） |
| ceremony：保留原文 + 加口径说明 | **采纳** | 两个口径都真实存在，说明来源即可 |

## 验收标准

1. `apps/web/public/festival-extras.json` 的 `programs` 里**不含** code `338` / `408`；
   每个节目的 `dateText` 都能解析出落在 2026-10-06 ~ 2026-10-15 的日期
2. `films.json` 中「大圣崛起」`unit = 亚洲电影之窗`、「The Violinist」`unit = Open Cinema`；
   两单元片数分别为 27 / 5，与官网 prog_view 一致
3. `InfoDialogs.tsx` 影院段落不再出现「MEGABOX 本届未参与」这一断言
4. 抢票信息弹层新增「取消与退款」「购票入口」两块；`.ics` 里的购票入口指向 `ticket.biff.kr`
5. 命令：`python tools/scrape_biff_extras.py --offline` 输出与基线一致或显式说明差异；
   `npm run verify`（typecheck → lint → 单测 → vite build）全绿，且新增回归测试**先红后绿**
