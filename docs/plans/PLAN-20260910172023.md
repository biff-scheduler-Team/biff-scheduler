# PLAN 2026-09-10 17:20:23 — 选片界面「交互瘦身」:档位改单枚徽章 + 场次行图标化 + 日期导航栏

> 需求(用户原话):「我的选片 右侧加一个日期导航栏 这里有几个非常干净的解法,可以大幅清爽界面:
> ① 交互瘦身:从"平铺按钮"改为"单选下拉 / 悬浮组"…② 逻辑瘦身:区分"影片级别"与"场次级别"…
> ③ 减少重复:右侧侧边栏只做"结果展示"…优化后: [片名] … [🔴 必看 ▾] [4场 ▾] [ⓘ]」。
> 本文件 = 本需求唯一规划文档。

## 1. 现状(代码事实,HEAD 96b230a)

| 问题 | 现状 |
|---|---|
| ① 平铺按钮 | 影片行右侧是**三段平铺 seg**(必看 / 备选 / 随缘,各一枚按钮)—— 而且**左右两栏各来一遍**,同一屏里同一排按钮出现两次 |
| ② 场次行重复 | 场次行的主操作是**长文案按钮**:`加入` / `已加入 · 点击移除` / `已在 B 方案 · 点击移出` |
| ③ 右栏不"只读" | 右栏和左栏是同一套行(含完整三选),看起来像第二个编辑区 |
| ④ 日期只有 chips | 右栏有日期 chips,但只能"点选某天",不能逐日浏览 |

## 2. 设计决策

1. **档位 = 一枚徽章 + 点击弹出小菜单**(`pick.ts::wishBadge`)—— 取代三段平铺:
   - 常态只显示**当前档位**(= 用户要的那枚「颜色标签」:彩色 soft 底 + 6px 档位色点 + `必看` + `▾`);
   - 未设时显示虚线 `+ 标记`;
   - 点击弹出小菜单(必看 / 备选 / 随缘 / **清除档位**,当前档打 ✓),再点同一枚 = 收起。
   - ⚠ **菜单必须 `position: fixed`**:左右两栏的列表容器都是 `overflow-y-auto`,绝对定位的弹层会被裁掉。
   - ⚠ 菜单挂在 `document.body`(不在 `#modal-root` 内)→ 自己处理「点外面 / 任意滚动 → 收起」;
     **故意不接 Esc** —— `modal.ts` 的 Esc 是模块级单监听且注册更早,这里抢不到,接了反而会连弹层一起关。
2. **场次行主操作图标化**(`modal.ts::actState` 文案 + 内边距):
   `＋ 加入` / `✓ 已加入` / `⇄ 已在 B`(三态语义与 `toggleScreening` 不变,tooltip 讲清"点击先移出、再点才改入")。
3. **右栏回归"展示为主"**:两栏仍共用同一套影片行(一致性是上一轮明确要求),但每行右侧只剩
   **档位徽章 + `N 场` + `已排 N 场` + `ⓘ`(+ 右栏多一枚 `✕`)—— 一整排文字按钮消失,`资料 ⓘ` / `✕ 移除(N 场)` 都收了图标。
4. **右栏加日期导航栏**:`日期 [‹] [全部 N 天] [10/21 周三 3] [10/22 周三 2] … [›]`
   - 位置序列 = `[全部, d1, d2, …]`,`‹` / `›` **逐日步进**,走到头即 `disabled`;
   - 与档位 chips 仍是 **AND** 叠加;只有 ≥2 天时才渲染(含行标);
   - 场次行仍按日期分节(上一轮的 ③ 保留)。

## 4. 边界与风险

- **`buildWishSeg()` 没有删**:影片资料弹层(`modal.ts::buildWishRow`)与行程行(`agenda.ts`)仍在用三段 seg。
  本轮只改**选片弹窗**(用户抱怨的是那里"同一排按钮出现两次");两处不统一是已知取舍,已记在此处。
- **Tailwind v4 只生成源码里完整出现的字面量类**:新增 `disabled:opacity-35` / `disabled:cursor-not-allowed` /
  `z-[250]` / `min-w-[112px]` / `w-[6px]` / `bg-[var(--bg-hover-soft)]` 均为字面量,构建后 `grep` 产物 CSS 核对命中。
- **单一数据源不变**:只动渲染层与筛选态,`store.picks` / `setWish` / `toggleScreening` / `removePick` 一行不改。
- **菜单与弹层栈**:菜单不在 `#modal-root` 内,弹层关闭时若菜单还开着会残留在页面上 —— 滚动/点外面即收,
  且菜单只在有指针交互时才可能出现;若后续发现残留,可在 `closeModal()` 里补一句 `closeWishMenu()`。

## 5. 验收标准

1. `npm run typecheck` + `npm run build` 通过。
2. 影片行右侧只有**一枚**档位徽章:未设 = 虚线「+ 标记」;点击弹出 必看/备选/随缘/清除档位;选完徽章当场变色变字;
   再点同一枚收起菜单;点别处 / 滚动列表菜单收起。
3. 场次行按钮为 `＋ 加入` → 点击变 `✓ 已加入`(再点移出);在另一方案时显示 `⇄ 已在 B`。
4. 右栏每行只剩「档位徽章 + N 场 + 已排 N 场 + ⓘ + ✕」;`ⓘ` 开影片资料,`✕` 整片移除(有已排场次时 confirm)。
5. 已排场次跨 ≥2 天时右栏出现日期导航栏:`‹` 从「全部」进到第一天,再点逐日前进,到最后一天 `›` 禁用;
   `‹` 回到「全部」后禁用;点某天 chip 直接筛选,再点取消。
6. 日期筛选与档位筛选可叠加(AND);叠加无结果时提示「当前筛选下暂无选片」。
