# PLAN 2026-09-11 18:15:00 — 「我的选片」计数可点 → 影片库看全部排期

> 需求(用户原话):「我的选片 点击总 n 场 可以跳转到影片库具体影片 我能看到所有排期」。

## 1. 问题

「我的选片」tab 展开后**只列已排场次**(那是「我的行程」在这部片上的投影,见 `library.ts::pickedShows`)。
想知道「这部片一共还有哪些场」只能去「影片库」tab —— 而影片库**默认全折叠**,
于是「切 tab → 搜索 / 滚动找片 → 展开」是三步;卡片上的 `共 N 场 / 已排 M 场` 明明就是那个入口,却是一枚死标签。

## 2. 改动(`src/library.ts`,单文件)

| 位置 | 改动 |
|---|---|
| `filmRow()` 状态标签 | **仅 `mode === "picks"`**:`共 N 场 …` 由 `<span>` 改为 `<button data-pick-all-shows="<key>">`,文案缀 `▸`;`data-tip` = 「切到「影片库」并展开《片名》,看全部 N 场排期」。影片库 tab 保持纯文本(它本就在该 tab,点击无意义) |
| `jumpToFilmAllShows(key)` | 新函数:清 `kw` / `search.value` / `unit` → 必要时清排片筛选 → `expLib.add(key)` → `setTab("lib")` → `requestAnimationFrame` 里 `scrollIntoView({block:"start"})` + `flash` 闪烁 |
| `panel` 点击委托 | 新分支**放在最前**:该按钮在**卡片头内**(`data-pick-head`),不先判就会冒泡成该卡展开 / 折叠 |

### 2.1 三个「跳过去看不见」的坑

1. **搜索 / 单元筛选必须清掉** —— 否则目标片可能不在结果里,跳过去是一片空白(等于没跳)。
2. **排片筛选(与网格共用,`filters.ts`)只在「会把该片整片滤掉」时才清**:
   用户自己设的筛选不无端抹掉,但筛选生效 → 该片 0 场 → `paintLib` 的 `matched` 里根本没有它,
   不清就是跳空。清时走 `clearFilter` + `ctx.onFilters()`(网格侧与网格筛选条同步),并 `toast` 说明。
3. **滚动要在 `setTab` 之后** —— `setTab` 会 `panel.scrollTop = 0`,同步滚会被复位,
   故走 `requestAnimationFrame`;`flash` 先摘类 + 强制回流再挂,保证同一片连点两次也重播动画。

## 3. 不做的事

* 不动「影片库」tab 的状态标签形态(它已在该 tab,展开只需点卡片头)。
* 不把选片 tab 的展开口径改成「全部场次」—— 「已排场次」是这一 tab 的核心语义,
  看全部场次是**另一个 tab 的职责**,本次只把入口接通。
* 不动 `pickedShows` / `expPick` / 日期筛选。
