# PLAN-20260910120636 · 弹层栈:影片库「详情」后能返回(不再只能关闭)

## 1. 现象 / 需求

影片库(以及「我的选片」)里点某一行的「详情 ⓘ」后,列表**整个被销毁**,只剩详情弹层,
用户只能按 ✕ / Esc / 点遮罩关闭,回到主界面后**得重新打开影片库、重新搜索、重新展开**才能继续看下一部。
即「详情 → 只能关闭,无法返回」。要求:详情之上能一键返回列表,且列表状态(搜索词 / 单元筛选 / 展开项 / 滚动位置)不丢。

## 2. 根因

`src/modal.ts` 的 `openModal()` 是**单弹层覆盖**语义:

```ts
const root = document.getElementById("modal-root");
root.innerHTML = "";          // ← 直接清空:上一层弹层的 DOM + 状态全没
```

`main.ts` 的 `libraryCtx().onFilm` 因此必须显式 `closeModal()` 再开详情:

```ts
onFilm: (code) => { closeModal(); showFilmModal(code, filmModalCtx()); }
```

两层弹层天然无法共存 → 不可能「返回」。

## 3. 方案:把弹层容器改成**栈**(保留 DOM,不重建)

`src/modal.ts`
- 新增 `modalStack: ModalEntry[]`,`ModalEntry = { overlay, dismiss(restore?), onReturn? }`。
- `openModal(title, body, wide?, onReturn?)`:
  - 开新层前把当前栈顶 `overlay.style.display = "none"`(**留在 DOM**,返回时 `display = ""` 原样恢复 → 列表滚动位置 / 展开态 / 搜索框内容全在,零重建);
  - 栈深 > 0(即本次不是栈底)时,头部在 ✕ 左侧加「← 返回」;
  - 关闭(dismiss)时 `overlay.remove()`,出栈,并**恢复下层 + 调用下层 `onReturn?.()`**(刷新被压住列表的「已选 N 场」等计数)。
- `closeModal()` = 关栈顶(有下层则自动恢复);新增 `closeAllModals()` = 整栈关闭(供「定位 ▸」用,`restore=false` 批量关时不触发下层回调)。
- Esc:改成**模块级单一 keydown 监听**只关栈顶 —— 原来是每个弹层各挂一个监听,叠层时一按 Esc 会把所有层一起关掉。

`src/main.ts`
- `jumpToScreening()`:`closeModal()` → `closeAllModals()`(要跳到网格,列表不能还盖着)。
- `libraryCtx().onFilm`:**去掉 `closeModal()`** —— 详情直接压在列表之上,靠「← 返回」回列表。

`src/library.ts`
- `openLibrary` / `openMyPicks`:`openModal(..., true, () => render())` —— 返回时刷新列表(计数 / 已选场次 / 档位);
- 「智能排片」弹层同样传 `onReturn`(采纳方案后返回列表,计数要更新):`openEngineDialog(filmList, ctx, render)`;
- 顺带修一个既有小毛病:两处 `render()` 里 `list.innerHTML = ""` 会把列表滚动位置打回顶部(点行内档位 seg 时列表会跳回顶部)。拆成 `paint()` + 外层 `render()` 保存/恢复 `list.scrollTop`。

## 4. 不改的东西

- 弹层视觉(遮罩 / 卡片 / 标题 / ✕)不动,只多一个「← 返回」按钮,且只在有上层时出现(网格 ⓘ、设置、图例总览等栈底弹层外观零变化)。
- 数据层(`store.picks` / `slotIndex`)不碰,`onReturn` 只做视图刷新。

## 5. 验收

1. 影片库 → 详情 ⓘ →「← 返回」回到列表,**搜索词 / 单元 chip / 展开项 / 滚动位置**全在。
2. 影片库 → 详情 → 在详情里加/减某场 → 返回后该行「A 已选 N」已更新。
3. 「我的选片」→ 详情 → 返回,行内「已排 N 场」已更新。
4. 影片库 → 智能排片 → 采纳 A 方案 → 返回,列表计数已更新。
5. 影片库 → 详情 →「定位 ▸」:整栈关闭并跳到网格对应卡片(列表不能残留遮挡)。
6. 栈底弹层(网格 ⓘ / 设置 / 图例)没有「← 返回」;Esc 只关最上面一层。
