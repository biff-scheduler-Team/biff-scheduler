| 顺序 | 元素 | 说明 |

| 1 | `<div class="flex items-center gap-2 whitespace-nowrap">` | logo 图 + `#sync-dot` |
| 2 | `<div class="flex items-center gap-2">` | 控件群: `#group-switch`(A/B 方案) → `#conflict-badge` → `#library-btn`(影片库) → `#my-picks-btn`(我的选片) → `[data-export-wrap]`(导出 .ics + 菜单) → `#settings-btn`(设置) |

  `PLAN-20260910012009` 把 chips 挪去网格区后,`flex-1` 一起删除 → 控件群失去推挤力,整条 header 变成左侧堆叠,
  右侧留白。该 PLAN 验收第 5 条写的是「header 视觉重心回到 logo + 右侧操作区」,本次即补齐这一条。

  **不依赖 DOM 层级或兄弟顺序** → 重排 + 加一层包裹对 JS 零影响。

## 方案(仅动 `index.html` 的 header 一段)

把 header 拆成「左组(logo + 浏览入口)」与「右组(操作组,`ml-auto` 推右)」两簇:

```
<header id="topbar" class="… flex items-center gap-[14px] flex-wrap …">
  <div class="flex items-center gap-2 whitespace-nowrap">   ← 原样:logo + sync-dot
  <button id="library-btn" …>影片库</button>                 ← 从控件群提出来
  <button id="my-picks-btn" …>我的选片<span id="my-picks-count">…</span></button>  ← 同上

  <div class="flex items-center gap-2 ml-auto">             ← 新增右组容器
    <div id="group-switch" …>A 方案 / B 方案</div>
    <button id="conflict-badge" …>⚠ N</button>
    <div class="relative" data-export-wrap>…导出 .ics + #export-menu…</div>
    <button id="settings-btn" …>设置</button>
  </div>
</header>
```

要点:

1. **靠右机制**:右组容器加 `ml-auto`。单行时把该组顶到 header 右端;窄屏换行时该组整块落到第二行并**右对齐**(比逐个 `ml-auto` 更稳)。
2. **`影片库` / `我的选片` 位置**:提到 header 直接子级,紧接 logo 之后(用户明确要求留在左侧)。间距由 header 自身的 `gap-[14px]`(窄屏 `gap-2`)给出,与 logo↔控件群间距同节奏。
3. **`#conflict-badge` 归属**:它是「当前方案冲突数」角标(`main.ts` `renderBadge()` 写 `#conflict-count`,点击滚到行程),语义从属于当前 A/B 方案 → 放进**右组**,紧跟 `#group-switch` 之后(它默认 `is-hidden`,不影响布局)。
4. **`[data-export-wrap]` 保持 `relative`**,其 `#export-menu` 是 `absolute right-0` 下拉 → 位置随按钮走,`overflow-hidden` 之类不受影响(header 无 `overflow` 裁切)。
5. **不动** `main.ts` / `style.css` / 任何 id / data 属性 / 类名文案;纯结构调整 + 一个 `ml-auto`。
6. `data-page-node-id` 属性原样保留(逐元素搬运,不重写)。

## 验收

1. 宽屏(≥ 1100px):一行内 `logo · 影片库 · 我的选片` 靠左,`A 方案 / B 方案 · ⚠ · 导出 .ics · 设置` 整体贴 header 右端(右组右边界 = header 内容右边界,`px-4` 内边距一致)。
2. 窄屏(720px 附近)换行:右组整块换行并右对齐,不出现溢出 / 重叠 / 半截按钮;`flex-wrap` 兜底生效。
3. 交互回归:`A/B` 切换仍高亮对应按钮并切方案;`影片库`/`我的选片` 弹层正常;`导出 .ics` 下拉菜单仍紧贴按钮下方右对齐、点外部关闭;`设置` 弹层正常;`⚠` 角标计数与点击滚动不变。
4. `npm run typecheck` 零错(本需求不碰 TS),`npm run build` 通过。
5. 不启动 dev server(项目约定:读代码 + build 校验)。
