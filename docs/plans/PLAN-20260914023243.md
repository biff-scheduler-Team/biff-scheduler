# PLAN-20260914023243 — 修复桌面分栏分支剩余 CI E2E

## 目标

CI run 34774345882：105 passed，desktop-chromium 仍红 7 条。对齐新布局契约与 legacy 推广文案，修倒计时 clock 竞态。

## 范围

**做:**
1. `compatibility.spec.ts` / `workflows.spec.ts`：桌面 `#viewing-panel` 不再断言固定 640；改 1:3 比例（或 flex 推导宽），保留 `biff.pickerw.v1` 存储断言。
2. legacy `#modern-version-link` 文案从误改的「返回新版」恢复为「体验新版」（可访问名与 E2E / 推广契约一致）。
3. `ticket-countdown.spec.ts`：`clock.install` 后 `pauseAt`，避免 install 后时钟仍随墙钟走导致边界断言飘到 `00:59:59`。
4. 本地跑指定 6 个 spec（desktop-chromium）+ 若触碰则 floating-panel/desktop；提交推送 PR #8。

**不做:**
- 改 wrangler `account_id`
- 改桌面分栏实现本身（契约已在 `style.css` / floating-panel E2E）
- 全量三浏览器 / 改 API

## 方案取舍

| 备选 | 结论 | 理由 |
|---|---|---|
| 断言改回固定 640 / 恢复 float 宽 | 否决 | 桌面 ≥1100 已是 flex 1:3，宽随视口变 |
| 测例改跟「返回新版」 | 否决 | 产品仍要 legacy 推广进新版；文案是账号桥时误改 |
| 只改测例容忍 01:00:00±1s | 否决 | 根因是 clock 未 pause；pauseAt 才稳 |
| install + pauseAt 同刻 | 采纳 | Playwright 文档推荐模式 |

## 验收标准

1. 指定 6 个 spec + floating-panel + desktop（desktop-chromium）全绿
2. legacy 顶栏链可访问名仍为「体验新版」，点进新版主导航
3. Conventional Commits 中文；push 更新 PR #8
