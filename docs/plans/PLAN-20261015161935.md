# PLAN-20261015161935 — 排行榜弹层改用「分享图皮肤」

## 目标

> 用户原话：「红黑榜排行 排行样式应该参考红黑榜的分享样式」

现状（代码事实）：`apps/web/src/components/rank-board.css` 的文件头**自己写着**「版式参考分享图那一行…
⚠ **颜色不照抄**：那张长图是 canvas 画的深底海报…配色一律走 token」—— 于是弹层是**白底 + 主题 token**，
而分享图是**固定深底 + `poster-brush.ts::COLORS`**（`bg: #101013`）那套海报色。
两者放在一起看确实不像一家人：这一条要把弹层那一块**照着分享图做**。

## 范围

**做：**

- `rank-board.css`：把弹层内容区换成**海报皮肤** ——
  · 深底 `COLORS.bg` + 圆角块；
  · 分节头从「纯文字标题」改成分享图的「**红色小竖条 + 标题 + 行数**」（`drawSection`）；
  · 名次补零两位、**前三名用 `COLORS.red2`**（`drawRow` 里 `rank <= 3 ? C.red2 : C.muted`）；
  · 行内海报**带一圈 `COLORS.line` 描边**（`drawThumb` 的 `roundRectPath` + `stroke`）；
  · 片名 `COLORS.ink` / 英文名 `COLORS.muted`；
  · 红黑数**分段上色**：`红` + 数字用 `COLORS.red2`，`黑` + 数字用 `COLORS.ink2`，
    分隔符与标签用 `COLORS.muted`（`drawCounts` 的 `segs`）。
- `RedBlackRankDialog.tsx`：把 `COLORS` 作为 **CSS 变量**注入（`--rbr-*`），不在 CSS 里抄第二份色值；
  分节头补那根竖条的节点；红黑数拆成 `.rbr-red` / `.rbr-black` 两段。
- E2E：在既有「排行榜弹层」那四条之后补一条，钉住「皮肤真的生效」——
  用 `getComputedStyle` 断到 `COLORS.bg` / `red2` / `ink2`，并断竖条数量与名次补零。
  文案断言（`.rbr-counts` 的 `红 5 · 黑 0`）保持逐字不变。
- 回写 `rank-board.css` 的文件头注释（那份「颜色不照抄」的说明现在与实现**相反**了，
  必须改掉 —— 留着就是第二份口径）。

**不做：**

- **不加评分**：分享图那一行是 `{评分} 分 · 红 N · 黑 N`，但用户 2026-10-15 的原话是
  「只需要显示影片的名称海报 以及红黑贴纸数」—— 这一条只改**样式**，不改行里的**内容**
  （评分 / 单元 / 场次编号 / 我贴的那一色仍然不在榜上）。
- 不改排序 / 门槛 / `RANK_LIMIT` / 两列并排的断点 / 桌面那道上限滚动。
- 不动分享图本身（`redblack-poster.ts` 一行不改）、不动页面卡片 `.rb-card`、不动 `.rb-tally__*`。
- 不把「红 / 黑」两个字色并进 `.rb-tally__*`：那是**浅底**那一对；
  深底上分享图另有一对（`COLORS.red2` / `COLORS.ink2`），`redblack-parity.css` 里已有同一句先例
  （「海报恒为深底、页面卡片底随主题翻，底色不同就该取不同值」）。

## 方案取舍

| 备选 | 结论 | 理由 |
|---|---|---|
| 在 CSS 里写死 `#101013` 等色值 | 否决 | 那就是把 `COLORS` 抄了第二份（§5 红线 5）；改一处忘一处时两处会静默分叉 |
| CSS 里用 `var(--rbr-bg, #101013)` 带默认值兜底 | 否决 | 兜底值同样是第二份色值，且「真出现兜底」时没人会发现 |
| **从 TSX 注入 `COLORS` 为 CSS 变量** | 采纳 | 色值只有一处定义（仍是 JS 那一个对象）；CSS 只表达「用哪一档」 |
| 只改字号 / 间距，保留白底 | 否决 | 用户看过改前的版本才提这一条 —— 那里**已经是**分享图的版式顺序，差的正是深底那套观感 |
| 顺手把评分加进去（更像分享图） | 否决 | 与用户 2026-10-15 原话「只需要…名称海报…红黑贴纸数」冲突；要加得他先改口 |

## 验收标准

1. 单测：`npm run test -w @biff/web` 全绿（本改动不碰纯逻辑，`redblack-rank.ts` 不动）。
2. E2E：`e2e/react/redblack.spec.ts --project=desktop-chromium` 全绿，且新用例满足：
   `.rbr-sheet` 的 `getComputedStyle().backgroundColor === "rgb(16, 16, 19)"`（`COLORS.bg`）；
   前三名 `.rbr-rank` 的颜色 === `COLORS.red2`；`.rbr-red` === `COLORS.red2`、`.rbr-black` === `COLORS.ink2`；
   每列一根 `.rbr-bar`；既有 `.rbr-counts` 文案逐字不变。
3. `npx tsc --noEmit` 与 `eslint` 0 error；`npm run check:repo` 0 违规。
