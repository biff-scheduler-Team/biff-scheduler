## 设计决策

| # | 决策 | 理由 |
|---|---|---|
| D1 | 行标签 = **官方代码 chip 一枚**,整格 `data-tip = venueTip(venue)` | 用户指定。列宽从「装名字」变成「装代码」,再也不会截断,顺带把 148px 压到 ~49px,时间轴多出 ~100px |
| D2 | 影厅列宽 **随缩放一起变**:`labelMetrics(pxPerMin)` 单源导出 `{labelW, chipW, fontPx, padX}` | 「连带影厅」的正解。列宽/chip 宽/chip 字号**同源同比例**,整列真的一起缩/展 |
| D3 | 三者都挂在 **chip 字号** 上(`fontPx = clamp(10·z^0.6, 9, 18)`,`chipW = round(fontPx·2.8)`,`padX = fontPx`) | 若列宽线性跟 `z` 而字号只跟 `z^0.6`,高倍下会只剩空白。同源后 100%→300% 列宽 49→87、字号 10→18,等比 |
| D4 | 列宽走 **内联 `gridTemplateColumns`**,不再用 `grid-cols-[148px_1fr]` 字面量类 | Tailwind v4 只生成源码里完整字面量类,拼不出动态宽度;内联样式是唯一解 |
| D5 | `LABEL_W` 常量 → **`labelMetrics(pxPerMin).labelW`**;`main.ts` 三处锚点换算同步改 | `gridAnchor` / `applyZoom(fromLeft)` / `renderGrid` 都依赖「轨道起点 = 列宽」,不同步会跳 |
| D6 | `fitZoom` 用 **两次迭代**收敛 | 列宽依赖倍率、倍率又依赖列宽,一次算不准(倍率 >1 时列变更宽,会溢出) |
| D7 | 中间百分比从「按钮」降级为**纯读数 `<span>`**,新增独立 **`1:1`** 按钮 | 用户要「一个按钮」;同一排里两个「回 100%」入口会互相打架 |
| D8 | 不动 `legend.ts` / `types.ts` / `venues.json`(另一个会话的短名 WIP) | 本次不需要短名;避免扫掉别人在途改动。`legend.ts` 的「影院与代码」表(代码 ↔ 全名 ↔ 分区)与新行标签口径**天然一致** |

## 改动清单

### `src/grid.ts`

1. 删 `export const LABEL_W = 148` → 新增 `labelMetrics(pxPerMin)`(导出),
   `labelW` 语义 = 粘性影厅列宽 = 轨道起点。
2. `fitZoom` 改两次迭代(`solve(labelW)` 闭包)。
3. 删 `ROW_BASE_CLS` 的 `148px` 字面量 → 退化成只有 `"grid"`,列宽由 `buildGrid` 内联写。
4. `LABEL_BOX_CLS` 去掉 `px-[10px]`(改内联 `padX`)。
5. 行标签块:去掉 `venue.name` 与 `truncate` span → 只放一枚代码 chip
   (内联 `width` / `fontSize` / `lineHeight`,`text-center`,`justify-center`);无 `code` 时回退 `venue.id.toUpperCase()`。
6. `buildGrid` 顶部 `const { labelW, chipW, fontPx, padX } = labelMetrics(pxPerMin);`,
   `totalW` 用它;ruler 与每行都 `style.gridTemplateColumns = \`${labelW}px 1fr\``。
7. 文件头注释更新(「列宽 148px 固定」→「随缩放」)。

### `src/main.ts`

1. import:`LABEL_W` → `labelMetrics`。
2. `gridAnchor`:`const lw = labelMetrics(px).labelW;`,两处 `LABEL_W` → `lw`。
3. `applyZoom` 的 `fromLeft` 分支:`screenX: labelMetrics(PX_PER_MIN * z).labelW`
   (**新**倍率下的列宽,`renderGrid` 用同值回算 ⇒ `scrollLeft` 恰为 0)。
4. `renderGrid`:算出 `newLw = labelMetrics(pxPerMin).labelW` 并用它回写 `scrollLeft`。
5. `renderZoomCtl`:中间改 `<span>` 读数;新增 `1:1` 按钮(`data-zoom="reset"`);四处 tip 文案
   由「时间轴」改为「时间轴与影厅列」。
6. `ZMID_CLS` 去掉 hover 态(不再是按钮),加 `text-center select-none`。

### `docs/CONVENTIONS.md`(blob 手术,只入我的 hunk)

§四「甘特缩放」块:**替换**已过时的 `LABEL_W` / `ROW_BASE_CLS` 字面量 `148px` 子条目,

## 验收(全部无头实测)

1. **影厅列随缩放变宽**:100% 列宽 49px → 300% 87px(`gridTemplateColumns` 首段)。
2. **行标签 = 代码**:29 行文本形如 `B1`/`L10`,**零 `truncate`**(`scrollWidth <= clientWidth+1` 全真)。
3. **hover 出全名 + 简介**:`label.dataset.tip` 首行含全名,且含韩名 / 分区 / 代码行。
4. **1:1 按钮**:控件序列 = `["−","100%","+","适应","1:1"]`;点 `+` 到 140% 后点 `1:1` → 回 `100%` 且 `scrollLeft = 0`。
5. **锚点不跳(不回归)**:Ctrl+滚轮 `deltaY=-120` 走一档 → 140%,`scrollLeft 0 → 306`;`fit` 后 `scrollWidth == clientWidth`(倍率 103%)。
6. **`fitZoom` 不溢出**:点「适应」后零横向滚动(两次迭代生效)。
7. `npm run typecheck` 零错;`npm run build` 零错;线上产物带 cache-buster 核对到新 hash。

实测结果:无头验收 **19 / 19 PASS**,`pageerrors: []`;全量 10 天 / 217 行影厅 chip 溢出 **0 处**;
