# PLAN-20261009152341 — 普通票快速查票

## 目标
> 普通票数量也可快速查看，/general

## 范围
做：新增 `/general` 和 `/api/general`，scheduler 服务端直连官方 WEB 渠道，复用 guest 查询与影片卡片，补齐渠道隔离测试。
不做：购票、锁座、账户登录、自动轮询、修改 biff-http、依赖升级。

## 方案取舍
- 采纳：固定渠道配置复用查询逻辑与页面，避免两份状态和影片信息口径。
- 否决：浏览器跨域直连（官方拒绝 CORS）、依赖 biff-http、将 GUEST 库存当普通票。
- 沿用用户明确要求，直接推送本仓库 main。

## 验收标准
1. `/general` 显示官方 WEB 余票数量、影片资料、日期/搜索/只看有票筛选。
2. `/guest` 行为不变，两个渠道不混用库存；失败及未知不显示为零。
3. API 单测和两个渠道桌面/手机 E2E 通过；部署后实查 API、页面和 asset hash。

## 修订 1（用户追加）
> 页面展示xx人想看

两个查票页展示已有站内影片级「xx 人想看」，复用 want-counts 缓存、filmNodeKey 和 wantCountLabel；不冒充官方购买人数，不改统计权重。未匹配影片或统计未成功加载时显示未知，不捏造零。
