# PLAN-20261007230427 — 我的行程：每场次一个直达红黑榜的入口

## 目标

> 用户原话：**「我的行程需要有一个入口能够直接跳转红黑榜」**
> 追问确认（2026-10-07）：入口放**每场次卡片 / 甘特格子上**（从具体某一场点进红黑榜）；
> 跳过去要**直接定位到某部片**（带上片名 `q=…`）。

「我的行程」(`/agenda`) 现在只剩日程表一种形态（`ScheduleGantt scope="agenda"`），格子上能做
的动作只有「移出行程」（点格子）与「编辑票务」（角标 / 右键），没有通向红黑榜的路 —— 看完一场
想贴一枚红 / 黑贴纸，只能先回导航栏 → 红黑榜 → 再手打片名。

## 范围

**做：**

- 「我的行程」日程表格子（agenda 档）右上加一个常显的「红黑榜」角标，点它跳
  `/redblack?q=<该片片名>`。
- 入口样式与既有 `.gantt-ticket-edit` 同一套角标口径（30×30、常显、触屏放大）。
- 一条 E2E：从格子点入口 → URL 带 `q`，且红黑榜只剩该片。

**不做：**

- **不动排片表那档**（`scope="schedule"`）—— 它画的是全届排片，给每格加「去评分」既挤又无意义。
- **不动红黑榜页**（`RedBlackPage.tsx`）—— 只复用已有的 `q` 搜索参数，不新增参数。
- **不改 `ScreeningCard`**（行程页不用它；用户指的就是甘特格子）。
- **不改 `biff.*` 任何存储结构**。

## 方案取舍

| 备选 | 结论 | 理由 |
|---|---|---|
| 角标放格子右上（与 ⓘ / 票务入口并排） | 采纳 | 与既有两个入口同一套形态，不占画布布局、不改 `.gantt-film` 几何 |
| 入口放进 `ScreeningInfoPopover`（点 ⓘ 的资料弹层） | 否决 | 用户要的是「从某一场**直接**点进」，多一层弹层就不是直达 |
| 传 `q=<片名>` | 采纳 | 红黑榜 `searchFilm` 本就按片名 / 场次编号过滤，`FilmNode.title` 与 `filmInfoOf().title` 同一口径（都是 `bilingualTitle`），无需新增参数 |
| 新增 `film=` 精确参数 | 否决 | 收益（少一次文本匹配）远小于成本（新参数要登记进 `nav-query` 口径、多一份测试面） |

## 验收标准

1. `/agenda` 有行程时，每个格子右上出现 `.gantt-redblack` 角标；排片表那档没有。
2. 点它跳到 `/redblack?q=<片名>`，红黑榜只剩该片。
3. `npm run verify:quick` 绿；`e2e/react/agenda-gantt.spec.ts` 新增用例绿。
