# PLAN 2026-09-11 23:10 — 分享图片(行程图)

> 需求(用户原话):
> 「分享的时候能不能选择分享的类型呢 图片和 图片是好看的行程图呢 比如说截图 HTML 然后你绘制一个好看的」

## 1. 需求定性

导出菜单此前只有**文本类**出口(`.ics` 喂日历 / 分享文案贴微信)。用户要的是**第二个分享类型 = 图片**,
且明确要求它是「**好看的行程图**」而不是把屏幕截下来。

拆成两条:

| 子需求 | 落点 |
|---|---|
| 分享时能**选类型**(文字 / 图片) | 导出菜单并列两项:`分享文案(复制)` / `分享图片(行程图)` |
| 图片要**好看**,是「行程图」 | 新增 canvas 手绘海报(不是截图) |

## 2. 关键决策

### D1. **手绘 canvas,不用 html2canvas / 截图**

用户给了两条路(「截图 HTML」/「你绘制一个好看的」),选后者。三条理由:

1. **零依赖** —— 本站是纯静态 + PWA,刻意无运行时依赖(产物 gzip 53KB),为一张图引 40KB 截图库不划算;
2. **确定性** —— 截图会受应用主题(亮 / 暗)、抽屉宽度、滚动位置影响:同一份行程在别人机器上出图不一样。
   分享图是「对外的成品」,必须每次都长一个样。故海报**固定深色**(不跟随 `data-theme`)。
3. **重排而非缩放** —— 截图只能把屏幕缩小;海报该做的是**按海报重排信息**:左侧贴影片海报缩略图、
   按日期分节、去掉一切界面控件。

### D2. 分层:`poster.ts`(模型 + 绘制)/ `poster-panel.ts`(弹层 + 剪贴板)

与 `backup.ts` / `backup-panel.ts` 同口径。原因是硬的:`modal.ts` **在 import 期就挂
`document.addEventListener`**,node 单测里 import 它就崩 —— 所以 `poster.ts` 一行 DOM 级副作用都不许有,
`modal.ts` 只在 `poster-panel.ts` 里 import。这样 `buildPosterModel` / `posterHeight` 可直接单测(11 条)。

### D3. 口径**全部复用**现有单一来源,不另起一套

`share.ts::orderedPickRows`(排序)/ `shareSummary`(场次 · 影片 · 日期区间)/ `gvMark`(GV 三态)
本轮从 `buildShareText` 里**抽出来**成为导出函数,分享文案与分享图共用 —— 否则两个出口会各印一个数
(「共 12 场」vs「共 13 场」这种)。

单场文案同样走既有口径:`effEndMin`(有效结束,含 / 弃映后谈)、`displayTitle`(英文名 · 中文名)、
`venueShort`(影院短名)。

### D4. 先弹层再生成(异步期给回执)

海报要加载 N 张影片缩略图。点完按钮静默一两秒才弹层 = 用户以为没反应会再点一次,
故**先开弹层**显示「正在生成行程图…」,生成完原地 `replaceWith(canvas)`。

### D5. 大标题 = 「2026 看片计划」,**不用节展全名**

初版直接把 `festival.name` 拼进大标题,实测 2026 版是 `31st Busan International Film Festival`,
52px 排出来**冲出画面被切掉**(首张验收图里 "202…" 断在画布右缘)。现改为:
- 上方 19px 加宽字距小字 = 节展全名(大写,超宽自动收尾);
- 52px 大标题 = 「2026 看片计划」。

### D6. 长图退档(画布单边上限 32767)

一行 168 逻辑 px,190 场 ≈ 32000 逻辑高 → 2× 超采样 = 64000,`toBlob` **静默出空图**(不抛错)。
故 `posterHeight(model) > 8000` 时退回 1×(约可撑到 190 场)。再多的行程本来也不该走分享图。

│  ┌────┐ 08:40–11:20 [GV 含映后谈]      │  缩略图 96×144(2:3)
│  │海报│ You, Like a Star · 宛如星辰的你 │  29px 600
│  └────┘ BCC Cinema 1 · 008              │  22px ink2
│        备注 导演映后 Q&A,提前 20 分钟到  │  21px 琥珀(仅备注行)

- **缺海报是常态**(250 部里 174 部有):占位块 = 中性卡 + CODE 居中,不留空洞;
  图片 `onerror` 静默跳过,不能让一张图挂掉整张海报。
- 逻辑宽 **1080**(微信 / 相册长图常规宽度),`SCALE = 2` 超采样出 2160 宽 PNG。

## 6. 未做 / 后续

- **不做主题跟随**:海报固定深色(见 D1)。若日后要亮色版,应作为「海报皮肤」独立选项,而不是跟随 `data-theme`。
- **不做逐日分页**:一天场次很多时该日会很长(单日 20 场 ≈ 3400 逻辑高),但仍在一张图里。
- 复制图片依赖 `ClipboardItem`(Chrome / Safari 13.1+);不支持时**降级为下载**并 toast 说明,不静默失败。
