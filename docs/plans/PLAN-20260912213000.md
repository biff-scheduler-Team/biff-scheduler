# PLAN 2026-09-12 21:30 — 用 TMDB 海报(对照 piecelet-api-relay)

> 需求:看 Piecelet/piecelet-api-relay 怎么拿豆瓣和 TMDB,改用 TMDB 海报。
> 密钥**不进仓库**(用户原话)。本机只读环境变量 `TMDB_KEY` / `RELAY_TMDB_KEY`。
> relay 源码 clone 在 `/tmp/piecelet-api-relay`,不放进本仓库。

## 1. relay 怎么取数

| 上游 | 路径 | 鉴权 | 我们用不用 |
|---|---|---|---|
| Douban Frodo | `/douban/frodo/*` → `frodo.douban.com/api/*` | query `apiKey` + 微信小程序 UA / Referer / 随机 `bid` cookie | 不用。本仓库已有 HMAC 签名的 `frodo_client.py`,而且会风控 |
| Douban Rexxar | `/douban/rexxar/*` → `m.douban.com/rexxar/api/v2/*` | 无 key,UA + Referer | 可作详情兜底,本轮海报不靠它 |
| TMDB | `/tmdb/*` → `api.themoviedb.org/*` | `Authorization: Bearer <v4 token>` | **用**。海报从 `image.tmdb.org` 下,图床不防盗链 |

TMDB 图:`https://image.tmdb.org/t/p/{size}{poster_path}`
`w185` / `w500` / `original` 对应本站 s / m / l。

## 2. 落地

- `tools/tmdb_client.py`:只从环境变量读 token,缺了就退出
- `tools/fetch_tmdb_posters.py`:按 `films.json` 的英文名 + 年份搜 TMDB → 下载 → 改 `poster` 为 `/posters/tmdb-<id>-m.jpg`
- 映射表 `data/tmdb_map.json`(只有 tmdb_id / 片名 / poster_path,**没有 token**)
- `.gitignore` 明确忽略 `.env`;`.env.example` 只有空占位符

命中口径:年份一致且片名归一后相等才写;年份差 1 且片名精确也可。宁可缺,不配错。

- 不把 relay 仓库嵌进本仓库
- 不删已有豆瓣海报文件(TMDB 没命中时仍用它们)
