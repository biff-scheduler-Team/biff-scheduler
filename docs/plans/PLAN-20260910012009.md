# PLAN 2026-09-10 01:20:09 — 把日期选择 chips 从顶部 header 挪到网格区,改方形圆角

> 需求(用户原话):「顶部时间选择组件放到其他地方吧 不要放到顶部 Banner 里面 最好是方形带圆角 不是纯圆」。
>
  用户口中的「顶部 Banner」= `<header id="topbar">`(顶部整条:logo + 中部选择区 + 右侧按钮群)。
> 用户口中的「顶部时间选择组件」= `#date-chips`(10/8 周四 / 10/9 周五 / 10/10 周六 等排片日期 chips)。截图定位:位于 header 中部、`A 方案`/`影片库` 左侧,长条一排圆胶囊 `rounded-full`(header 内唯一"日程维度"选择控件,与 grep `rounded-full` 在 header 中唯一一处对应)。用户希望:① 挪出 header,放到网格区主体内;② 形状改方形带圆角(参考既有 `rounded-[7px]`/`rounded-[6px]` 之类),**不要**纯圆胶囊。
> 本文件 = 本需求唯一规划文档。

- `<nav id="date-chips">`(index.html:17):`flex gap-[6px] overflow-x-auto flex-1 min-w-[200px] py-[2px]` — 承担 header 中部弹性填充(`flex-1`)。


  标题行下方紧跟 `#grid-scroll`(网格画布)。

## 方案

### 1. 移动位置(从 header 挪到网格区)
- `index.html`:
  - **删除** `<nav id="date-chips" …></nav>` 这一行(整段从 `<header>` 中移除)。
  - 在 `<section id="grid-wrap">` 内的**标题行**上方新增一行日期选择容器:
    ```
    <div id="date-chips" class="flex gap-[6px] flex-wrap mb-[10px]"></div>
    ```
    紧挨 `flex items-baseline justify-between mb-[10px]` 之前(给 chips 一行完整宽度,标题行下移)。注意 header 的 `flex-wrap` 留下逻辑:删掉 `flex-1 min-w-[200px]`(放到网格区后不再需要弹性填充,改成自然宽度 wrap)。
- header 内部去掉 chips 后空缺:无需补位。header 排版变为 logo + group-switch + 按钮群;`flex-wrap` 窄屏自动 stack 即可。
- **`cat.dates` 数据与 `renderChips()` 渲染逻辑不变**(只挪挂载点 + 改 flex 行为),交互 / 选中态 / 计数全部一致。

### 2. 形状:方形带圆角(非纯圆)
- `src/main.ts:93–96`:
  - `rounded-full` → `rounded-[7px]`
  - 其它三个 `bg-biff / border-biff / hover:border-biff / text-on-brand font-semibold` 保持。
- 不动 chip 内的 `px-3 py-1 text-[13px]` 与 `whitespace-nowrap`。
- 选中态继续用品牌红底(`bg-biff text-on-brand`);非选中仍用 `border-line bg-card text-ink`。

### 3. 微调(避免布局塌陷)
- 标题行(`grid-date-title` + `grid-count`)保持原位,日期 chips 独占一行 `mb-[10px]`,间距与原 header 中一致。
- header 失去 chips 后,窄屏 720px 下不再出现 `min-w-[200px]` 撑开,改回默认宽度;不需额外样式。
- `rounded-full px-3 py-1` 的内边距与 `rounded-[7px]` 视觉上接近(原 chips 高 28px,改后方形圆角视觉重量不变)。
