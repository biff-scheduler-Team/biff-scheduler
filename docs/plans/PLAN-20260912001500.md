## 2. 为什么不做成独立一行 / 加图标

- 页脚是 `flex items-center justify-center gap-[14px] flex-wrap` 的单行流:再加一个 `<span>` 即多一「列」,
  窄屏自动换行,**无需改 CSS**;另起一行反而要写额外布局。
- 不放 GitHub 图标:品牌目录无 GitHub 图标资源,引入外链图标图省事但会多一个网络依赖(页脚是纯静态署名,不值当)。
