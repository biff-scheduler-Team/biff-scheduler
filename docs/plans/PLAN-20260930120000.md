# PLAN-20260930120000 — 红黑榜贴纸画布空白太多，降低向心强度

## 目标
> 用户原话：「我感觉空白的地方太多了」（针对红黑榜某片贴纸画布截图，红 165 · 黑 74，
> 画布四周与上下留白明显，贴纸挤在中间一条带里）。

`redblack.ts::SPOT_CENTER_BIAS` 当前是 `0.5`（2026-09-29 两轮修订后定的值），
把落点往中间拉得比较狠，票数不算特别多时（几百枚）就会显出「中间一坨、四周大片空白」。

## 范围
**做：**
- 把 `SPOT_CENTER_BIAS` 调低（`0.5` → `0.22`），让落点分布更接近均匀，减少视觉空白，
  同时仍保留「中间略密、边缘不至于完全均匀撒满」的一点密度渐变（不退回 `0`）。
- 同步更新 `redblack.test.ts` 里跟这个值绑定的注释与阈值断言（"中间密、四周疏，但没有
  椭圆边界"那条用例的 `devs[199]` 阈值，与代码注释里写的"实测 ≈ 0.13"）。

**不做：**
- 不改画布尺寸 / `.rb-canvas` 的 `min-height`、卡片宽度等版式常量（2026-09-30 当天已经
  为它们做过一轮实测校准，不在本次症状范围内）。
- 不改 `SPOT_MARGIN`（画布边距，与"空白太多"的症状无关，且改小它会有贴纸被裁掉一半的风险）。
- 不改极坐标 / 形状（2026-09-29 已经因为"聚成椭圆形"的反馈否决过一次，不重蹈）。

## 方案取舍
| 备选 | 结论 | 理由 |
|---|---|---|
| 降低 `SPOT_CENTER_BIAS`（0.5→0.22） | 采纳 | 唯一决定"密度渐变强弱"的开关，改动最小、口径单一来源不变 |
| 改画布尺寸/卡片宽度 | 否决 | 当天已实测校准过，且与本次症状（空白）无关——空白是分布问题不是面积问题 |
| 改极坐标撒点 | 否决 | 2026-09-29 已被用户否决过（会撒出可见的椭圆边界） |
| 完全归零 bias（纯均匀） | 否决 | 会退回 2026-09-29 之前"铺满四角"被吐槽的版本，矫枉过正 |

## 验收标准
1. `apps/web/tests/redblack.test.ts` 中 `spotOf` 分布相关用例全绿（阈值已按新 bias 更新）。
2. `npm run verify:quick`（或至少该文件的单测）通过。
