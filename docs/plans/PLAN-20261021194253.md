# PLAN-20261021194253 — 红黑榜分享图：去副标题日期、去贴纸数放大片名、红黑两榜各设名次

## 目标

用户原话（2026-10-21）：

> 1.红黑榜分享图 去掉OCT21 ·315部有排期的影片这个
> 2.去掉贴纸数 放大影片名字
> 3.红黑榜单独设置需要的名次

## 范围

**做:**

1. `redblack-poster.ts::buildRbPosterModel` 的 `subtitle` 不再拼「日期 · N 部有排期的影片」；
   只在选了单元时写单元名，否则为空串。`drawHeader` 在副标题为空时**不画那一行**，并把分隔线上提，
   避免标题与分隔线之间留一段无内容的白。⚠ 头部总高 `HEADER_H` 不动（几何只有一处，改它要连带改 E2E）。
2. 分享图**行内**不再印「红 N · 黑 N」（`drawCounts` 加一个 `withCounts` 开关，榜图那一档照旧印）。
   片名字号 29 → 35，英文名 20 → 21。⚠ 评分仍保留（用户只要求去掉贴纸数）。
3. 新增 `RbPosterInput.topNByBoard`（红 / 黑各自一档）；弹层把单个「每榜条数」拆成
   「红榜条数 / 黑榜条数」两个下拉，各自默认 `TOP_N`。

**不做:**

- 不动分享图右侧**贴纸区**（用户说的是"贴纸数"，不是贴纸图）。
- 不动「我贴过的」那一节的条数口径（本来就不限条数）。
- 不动榜图（`mode:"rank"`）的任何版式与数字。
- 不动头部「全站贴纸 / 红 / 黑 / 我的：已贴 N 枚」四组数字。

## 方案取舍

| 备选 | 结论 | 理由 |
|---|---|---|
| 副标题整行连同头部高度一起删（`HEADER_H` 变小） | 否决 | 头部高度是绘制与 `rbPosterHeight` 的共用常量，改它要同步改所有 E2E 尺寸断言，收益只是几十像素 |
| 只删日期、保留「N 部有排期的影片」 | 否决 | 用户指的是**整句**（日期 + 片数） |
| 行内数字整行删（评分一起去） | 否决 | 评分是排序依据，用户只点名"贴纸数"；删多了改不回来 |
| `topN` 改为对象 `{red, black}` | 否决 | 破坏既有调用与 6 条单测；改为**追加**可选 `topNByBoard`，不传时行为与现在逐字一致 |

## 验收标准

1. `npm run test -w @biff/web -- redblack-poster` 全绿，且新增两条：副标题为空 / 红黑条数各自生效。
2. 本地 `localhost:31026/redblack?sort=red` → 生成分享图：副标题不再出现「OCT 21 · … 部有排期的影片」；
   行内只剩片名（更大）+ 英文名 + 评分，没有「红 N · 黑 N」。
3. 弹层里红榜选 5、黑榜选 20 → 图上红榜 5 行、黑榜 20 行（同一张图）。

## 修订 1（2026-10-21，用户「去掉评分」）

**触发**：第 2 条只删了贴纸数，评分仍留在行内；用户看完要求连评分一起去掉。

**改为**：分享图的行内**不再有第三行** —— 只剩片名（38px，`textBase + 10`）与英文名（22px，
