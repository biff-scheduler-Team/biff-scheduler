# PLAN-20261015170310 — 排行榜弹层加「生成分享图」入口

## 目标

> 用户原话（看过改皮肤那一版之后）：「但是还是没有完全和分享一样 因为没有分享按钮吧无法分享结果」

现状（代码事实）：分享图只有**一份实现** —— `RedBlackShareDialog` + `redblack-poster.ts`，
入口是榜单页工具栏那枚「生成分享图」（`RedBlackPage.tsx:1050-1057`）。
而上一轮新加的**排行榜弹层**（`RedBlackRankDialog`）里只有一枚「关闭」——
用户在那个弹层里看到一份 TOP50 读数，却**没有任何往外发的入口**。

## 范围

**做：**

- `RedBlackRankDialog.tsx`：`ButtonGroup` 里加一枚**主操作**「生成分享图」（新增 `onShare` 回调），
  空榜（`boards.length === 0`）时 `isDisabled` —— 没有票就没有排行可分享。
- `RedBlackPage.tsx`：`onShare` = **交接** —— 先 `closeRank()`（与「快速投票 / 排行榜互斥」同一条：
  两张弹层不叠在同一屏），再打开既有的分享图弹层。
  ⚠ **不新画一条出图路径**：分享图仍然只有 `RedBlackShareDialog` 那一份（§5）。
- `RedBlackPage.tsx`：交接那一次传 `initialTopN={RANK_LIMIT}`（50）—— 用户点「分享」时眼前是
  TOP50，图里却按默认档画 10 行的话，分享出去的**不是他看到的那份结果**。
  页头那枚「生成分享图」照旧不传（走默认档 `TOP_N = 10`）。
- `RedBlackShareDialog.tsx`：新增可选 `initialTopN?: number`（`useState(initialTopN ?? TOP_N)`）；
  `TOP_N_CHOICES` 补一档「前 50」—— 否则 Picker 的 `value=50` 落在一个**不存在的选项**上（会显示空白）。
- E2E：在既有「排行榜弹层」那几条后面补一条，钉住交接：排行榜弹层关掉、分享图弹层打开、
  每榜条数 = 前 50、焦点在分享图弹层**里面**、关掉后两个弹层都不在、URL 上不留 `rank`。

**不做：**

- 不在排行榜弹层里内嵌画布预览（那是把 `redblack-poster.ts` 再做一份）。
- 不把排行榜做成「分享图的一种档位」（分享图是长图成品，排行榜是一屏读数，两者形态本来就不同）。
- 不动分享图的排序 / 门槛 / 单元切分 / 头尾开关（`PLAN-20261014150805` 的口径一字不改）。
- 不改 `TOP_N = 10` 这个**默认档**（只有「从排行榜进来」这一条路会 preselected 成 50）。
- 不碰 `hot-poster` / `HotBoardShareDialog`（热门榜那套「TOP3 / TOP10」与这里无关）。

## 方案取舍

| 备选 | 结论 | 理由 |
|---|---|---|
| 排行榜弹层里内嵌出图 / 复制下载按钮 | 否决 | 等于把 `redblack-poster.ts` 的模型、勾选、预览再实现一遍（§5 红线 5） |
| 交接时不 preselected topN（默认 10 行） | 否决 | 用户看的是 TOP50，「分享结果」要发的是**这一份**；差 40 行不是细节 |
| 交接时保留 `rank=1`（分享完自动回到排行） | 否决 | 那要么叠两层弹层，要么让排行榜在分享图关掉后**凭空复现**；用户没要这个，且焦点归还多一条路径 |
| 交接 = `closeRank()` + `setShareOpen(true)` | **采纳** | 与页头那枚「生成分享图」落到同一个终点；`closeRank` 已经带「把自动补的 `vote` 一并清掉」那条被 E2E 钉住的行为 |
| 「前 50」加成独立档位 | **采纳** | `RANK_LIMIT = 50` 是排行榜自己的口径；分享图原来最大只到「前 20 / 全部」，中间缺一档 |

## 已知风险（写清）

- **焦点**：交接那一刻 `BoardPage` 的「排行榜关掉 → 焦点还给那枚按钮」副作用仍会跑，
  而分享图弹层同时挂载。S2 `DialogContainer`（React Aria `FocusScope`，`contain`）会把焦点拉回弹层内 ——
  但这是**推断**，所以 E2E 里直接断言「分享图打开时 `document.activeElement` 落在弹层内」；
  断言不过就改成显式抑制那条焦点归还。

## 验收标准

1. 单测：`npm run test -w @biff/web` 全绿（本改动不新增纯逻辑）。
2. E2E：`e2e/react/redblack.spec.ts --project=desktop-chromium` 全绿，且新用例满足：
   点「生成分享图」后 → `.rbr-row` 计数归 0（排行榜已关）、`dialog[红黑榜分享图]` 可见、
   「每榜条数」按钮文案含「前 50」、焦点在弹层内、URL 不含 `rank`；
   关掉分享图后两个弹层都不在。
3. 空榜时那枚按钮 `isDisabled`。
4. `npm run typecheck`（含 e2e 项目）与 `npm run lint` 0 error；`npm run check:repo` 0 违规。
