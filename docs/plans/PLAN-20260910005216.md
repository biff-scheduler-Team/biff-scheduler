# PLAN 2026-09-10 00:52:16 — 排片卡重排版 + 横向拉宽 + 时间轴平移常态化(D1-D3)

> 需求(用户原话):「一张卡片塞的信息太多了,但都是有用的,重新排排版;把片子的卡片拉长;让时间组件可以左右移动」。
> 澄清(AskUserQuestion 确认):「拉长」= **横向拉宽**(时间刻度加大 → 卡更宽);时间组件移动 = **拖拽平移 + 滚动条都要**。
> 本文件 = 本需求唯一规划文档。只改排期网格(grid.ts / style.css),不动 行程/影片库/弹层。

## 现状(代码事实,src/grid.ts / style.css / main.ts)

- 刻度自适应 `computePxPerMin`(grid.ts:33):默认 `DEFAULT_PX_PER_MIN=1.5`(每小时 90px),放不下压缩至下限 `MIN_PX_PER_MIN=0.7`,仍放不下才 `overflow-x-auto` + `attachPan`。→ 90px 宽的 1 小时卡要塞 CODE/时间/徽章/中英片名,是"信息挤"根源;且各日期刻度不同(0.7~1.5 浮动),视觉比例不稳定。
- 卡片内顺序(appendCard grid.ts:338):`t1(CODE+时间)` → `bdgRow(等级/字幕/GV/页码+片长)` → `ttl(中文名)` → `sub(英文名/片长兜底)`。徽章流横插在时间与片名之间,卡窄时 wrap 成两行,把 80px 卡高(ROW_H 92 − 12)挤爆、最下行被 overflow-hidden 裁。
- 时间轴平移:`attachPan`(grid.ts:231)已实现(拖 >5px 判定拖动并吞 click),但**只在横向放不下时挂载**;滚动条走外层 `overflow-x-auto`,非溢出时不存在。

## 改动方案(全部 src/,无新依赖)

### D1 刻度固定加宽(卡片横向拉长 + 时间轴必然可平移)
- grid.ts:删 `DEFAULT_PX_PER_MIN / MIN_PX_PER_MIN / computePxPerMin`,改固定 `PX_PER_MIN = 2.2`(每小时 132px):
  - 1h 卡 ≈ 132px、1.5h ≈ 198px、2h ≈ 264px —— 信息舒展;
  - 各日期刻度一致 → 甘特比例稳定、拖动/滚动手感统一。
- 时间轴宽度 `totalW = LABEL_W + axisMin*PX_PER_MIN + TRAIL_PAD` 在常规视口必然 > 可用宽 → **横向溢出常态化**,滚动条常驻可用、`attachPan` 恒挂。
- `attachPan` 补守卫:down 时 `scrollWidth <= clientWidth`(超宽屏装得下)→ 不接管拖动,避免"拖了不滚却吞掉卡片点击"。

### D2 卡片内容重排版(信息不减,只换秩序 + 分层)
顺序自上而下改为:**身份行 → 片名 → 英文名 → 徽章沉底**(徽章行 `mt-auto` 顶到底部,与标题区天然分组;宽卡单行放得下,不再 wrap 挤压):

| 行 | 内容 | 视觉调整 |
|----|------|---------|
| 1 t1 | CODE + 时间区间 | 时间升格:`text-ink font-bold text-[12px] tabular-nums`(排片核心信息);CODE 黑粗不变;fitTimeTexts 降级/hover 兜底原样保留 |
| 2 ttl | 中文片名 | `text-[13px] font-bold truncate`(主视觉,提升一档字重;冲突片仍 text-conf) |
| 3 sub | 英文名(或 `${min}min` 兜底) | 原样 11px muted |
| 4 bdgRow | 等级/字幕/GV/页码 + 片长 | 整行移到卡片底部(`mt-auto`),其余不动;ⓘ/⚠/A·B 角标与 in-plan 底色均不触碰 |

> 不做的事:不删任何字段;不加高 ROW_H(92 保持);不改动行程/影片库/详情弹层的徽章流(appendMetaRow 共用,动一处全动)。

### D3 时间轴"拖动 + 滚动条"双通道
- buildGrid:`scroll` 恒 `overflow-x-auto pb-[6px] cursor-grab`,`attachPan(scroll)` 不再以 `overflows` 为条件(装得下的超宽屏内由 D1 守卫自然跳过);
- 拖动吞 click / `panning` grabbing 光标等既有机制全部沿用,滚动条(浏览器原生)同时可用。

## 验收
1. 网格刻度恒 2.2px/min:各日期、无论当天轴多长,卡宽/时间位置比例一致;1h 卡明显比旧版(90px)宽一档,片名/英文名少截断。
2. 卡片内容顺序 = CODE+时间 / 片名 / 英文名 / 徽章贴底;信息零删除;hover 全部 data-tip 仍在;fitTimeTexts 在极端窄卡上依旧降级不截断。
3. 时间轴:常规窗口下(默认也溢出)有原生横向滚动条;**按住鼠标左右拖 = 平移**,位移 >5px 不误触卡片点选/ⓘ;超宽屏(装得下)不挂拖动,卡片点选正常。
4. 整点筛选(点击标尺 hour)/ 现在红线 / 冲突·紧转场底色 / in-plan 染色 等既有交互不回归。
5. `npm run typecheck` 通过;不启动本地 dev server(读代码自查 + 一次性 build 验证)。
