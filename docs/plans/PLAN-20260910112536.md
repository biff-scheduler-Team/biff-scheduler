# PLAN-20260910112536 — 甘特画布灰底 + 未选中卡片「待激活容器」化

## 0. 需求来源(用户原话要点)

> 针对你提到的两个核心痛点——甘特图颜色遮罩与未选中卡片的「白底叠白底」融色问题,这里是具体的改动建议:
> **1. 解决未选中卡片的「白黑不分」**:卡片和页面背景同为纯白,导致未选中时没有边界感,像悬浮在半空的孤立文字。
> 引入极浅灰色底板:将整体大背景改为极浅灰(如 `#F7F8FA` 或 `#F5F5F7`),而未选中的卡片保留纯白(`#FFFFFF`),
> 并叠加极淡的边框(`1px solid #E5E6EB`)。这样无需选择,卡片的轮廓和层级也能清晰凸显。
> **2. 提升未选中状态的交互感知**:未选中的卡片文字可以使用中灰色;hover 时加深边框或稍显投影,
> 让它看起来是一个「待激活」的容器,而不是空落落的区域。

## 1. 定位:根因在「画布底色」,不在卡片本身

- `index.html:39` 的 `#grid-wrap` 面板 = `bg-card`(纯白);`src/grid.ts` 的卡片 = `bg-card`(纯白);
- 而承载卡片的画布(`buildGrid` 的 `scroll` 容器、各行的 `tracks` 泳道)与粘性场馆列(`LABEL_BOX_CLS`)
  **都没有自己的底色** → 直接透出面板白。

于是「白卡 + 极淡白边框(`--border-default #e0e0e0`)+ 白底」三层同色,卡片只剩 1px 灰边当轮廓
→ 正是用户说的「像悬浮在半空的孤立文字」。

**结论:先把画布压成灰底,白卡自然浮起** —— 这是根因修复;文字灰阶是第二步的强化。

## 2. 改动清单(只动 `src/grid.ts`,零新 token)

### 2.1 画布灰底 = 复用 `--bg-page`(#f4f4f5)

| 位置 | 现在 | 改为 |
|---|---|---|
| `scroll`(横向滚动容器 = 画布本体) | `overflow-x-auto pb-[6px] cursor-grab` | **+ `bg-page rounded-[8px]`**(灰底 + 内嵌圆角,外层白面板自然成为「画框」) |
| `LABEL_BOX_CLS`(粘性场馆列 / 标尺左上空格) | `sticky left-0 z-[3] bg-card border-r border-line …` | `bg-card` → **`bg-page`**(整块画布一个面;列分隔交给既有 `border-r border-line`) |

**为什么复用 `--bg-page` 而不新建 `--bg-canvas`**:用户给的两个候选里 `#F5F5F7` 与本项目
`--bg-page #f4f4f5` 基本同色(冷中性极浅灰)→ 复用既有 token,不新增重复色;
且**完全不动 `src/style.css`** —— 该文件此刻正被并行会话(智能排片弹层)写入,避开即零冲突。
想要更冷更浅的 `#F7F8FA` 只需加一个 token + 换一个类名,见 §5。

### 2.2 行分隔线**不动**(灰底后已自解释)

`CARD_INSET_Y = 2` → 相邻两行卡片之间天然留 4px 灰缝,行与行靠灰缝 + 卡片白底分开;
既有 `border-t border-line-soft` 保留作冗余细线。**少动一处少一分回归风险。**

### 2.3 未选中卡片 = 白卡 + 极淡边框 + 中灰文字(新增 `isIdle` 一档)

`isIdle = !isConflict && !inCurrent && !inOther`(即「没选中、也没选在另一方案」的纯待选卡):

| 元素 | 现在 | 改为 |
|---|---|---|
| 描边 | `border border-line` | 同左 **+ `hover:border-line-strong`**(#c9c9c9 加深;hover 另有既有 `shadow-hover` 投影 + `hl-card` 红晕,三层递进) |
| CODE | `text-ink` | `text-muted`(#737373) |
| 起止时间 | `text-ink font-semibold` | `text-ink-2`(#525252,仍加粗 —— 排片锚点信息不过度淡化) |
| 片名 | 继承 `text-ink` | `text-ink-2` |
| 英文名 / 片长(次级行) | `text-muted` | **不动**(#737373 已是对比度下限,再淡会掉到 WCAG 以下) |
| 徽章行 / ⓘ 详情钮 | 各自状态色 | 不动 |
| GV 映后谈块(未选中) | 谈段区间 `text-ink-2` / 标签 `text-ink` | `text-muted` / `text-ink-2`(与正片卡同一「待激活」语言) |

**已选(`in-plan` 绿)/ 另一方案(`in-other` 虚框)/ 冲突(红)一律不动** —— 黑字 + 彩色整卡底,
与「灰字白卡」的待选态形成明确两档。

### 2.4 标尺整点按钮的 hover 底

`hover:bg-hover`(#fafafa)在灰画布上「越 hover 越浅」= 反馈不可见 → 改 **`hover:bg-card`**
(白药丸浮起;与选中态 `bg-biff` 红底不撞)。整点按钮是可点的时间筛选入口,hover 感知不能丢。
