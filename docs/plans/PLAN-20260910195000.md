# PLAN 2026-09-10 19:50:00 — 撤销「行程档」：行程行改回三处统一骨架

> 需求(用户原话):「我选片的 和我的行程中 影片卡片样式不同 请你看看为什么」
> → 确认统一方向后用户选择:**以选片为准**(行程行改回默认骨架:片名退回第二行、元信息回描边章)。
>
> 前置:`PLAN-20260910193000`(场次行三处统一)、`PLAN-20260910194000`(行程档 —— **本 PLAN 撤销其排版部分**)。
> 本文件 = 本需求唯一规划文档。**已实现。**

## 1. 诊断(为什么两处不同)

| # | 差异 | 我的选片(`library.ts::filmRow`) | 我的行程(`agenda.ts::buildRow`) |
|---|---|---|---|
| 1 | 卡片粒度 | 一部片一卡(场次为卡内平铺行) | 一场一卡 |
| 2 | 卡片外观 | 无阴影(仅 hover 有 `shadow-hover`) | 常驻 `shadow-[var(--shadow-card)]` |
| 3 | 片名 | 卡片头 **15px** bold + 副标题 + 状态标签 | 卡内首行 **14px** bold + ★/A |
| 4 | 元信息 | 全部统一描边章 | 只留 CODE + 等级章,其余**中灰纯文本**(`plainMeta`) |
| 5 | 附加 | 无 | 卡间转场连接件 + 冲突行 |

根因:`PLAN-20260910193000` 统一了三处的**场次行骨架**;随后 `PLAN-20260910194000`
在 `row.ts` 里新增 `title` / `titleExtra` / `plainMeta` 分支,**只给行程启用** → 两边再次分叉。

**澄清**:卡间「赶场间隔」连接件(`agenda.ts::gapConnector`)与卡片样式**无关** ——
它在 `buildAgenda` 循环里作为独立节点插在 `buildRow` 之间,只依赖前后两场的时间。
故本次卡片回退**不影响**连接件与冲突行。

## 2. 改动(以选片为准)

### 2.1 `src/row.ts` — 删除「行程档」分支

- 删 `ScreeningRowOpts` 的 `title` / `titleExtra` / `plainMeta`;
- 删片名置顶行、`when` 里的 `plainMeta` 分支、`plainMetaRow()`;
- **新增 `headTitle`**:片名作为**卡片头**置顶(15px 加粗 + `truncate`,与选片卡头完全同款),
  下缘 `border-b border-line-faint` 分隔「这部片是什么 / 这场怎么排」;
  有 `headTitle` 时 `acts` 贴**卡片头右缘**(对齐选片卡「片名行右上角图标组」),场次行不再挂操作;
- `extra` 改 `HTMLElement | null`;
- import 收窄为 `codeTip` + `appendMetaRow` / `uniformChipEl` / `venueTip`。

> 演进说明:第一版曾把片名放「第二行」(`extra`),实测与选片卡形成**倒置**
> (选片 = 片名在上、场次在下;行程 = 场次在上、片名在下)→ 用户仍反馈不统一,
> 故改为「卡片头片名」,让两处阅读顺序一致。

### 2.2 `src/agenda.ts` — 行程卡 = 卡片头片名 + 统一场次行

- `buildRow` 的 `screeningRow(...)` 传 `headTitle: zh`;`acts`(映后 / A / ★ / ✕)随之贴卡片头右缘;
- `extra` = `buildConf(ctx, s, entryConf, conf)` —— **只剩冲突提示**(片名已上卡片头);
- `buildActs` 签名扩为 `(ctx, s, group, priority, slotCount, talk)`,把原 `buildTitleDecor`
  的 **A 方案标 + ★ 档位** 并回操作组;
- 删 `buildTitleDecor()` / `buildConfNote()` / `buildNote()`;
- **不动** `gapConnector()` 与其调用点(转场连接件保留)。

统一后两处卡片同序:

### 2.3 `src/agenda.ts::buildAgenda` — 日期分隔加强(2026-09-10 追加)

> 需求:「我的行程中 每天的分隔更清晰一点 日期大一点 加上分割线」

- 每个「天」的 `section` 加**上分割线** `border-t border-line-strong`(#c9c9c9,比卡片边框
  `--line` #e0e0e0 深一档)+ `pt-[12px]`;**首日不出线**(上方没有要隔开的内容);
- 日期头字号 14px → **16px 加粗**;「N 场」拆成独立字阶(12.5px 次级灰),不再跟着日期一起放大;
- 日期 + 场数仍是**同一枚 button**(`data-jump` 整块可点 = 切网格到这一天),内部两段字阶;
- section 内距 `gap-[6px]` → `gap-[8px]`。
