# PLAN-20260914134700 — 建议反馈留言板（需登录 + emoji 反应）

## 目标
引入留言板样式的「建议反馈」：登录后可发帖；任何人可读；登录用户可用少量热门 emoji 反应。

## 范围

### 做
1. D1 新表（不复用 `festival_document`）：`feedback_post` + `feedback_reaction`
2. 公开读 API + 鉴权写 API（`/api/feedback*`）
3. 新版 UI：`/feedback` 留言板 + 顶栏入口；未登录发帖/反应引导登录
4. Emoji 固定集合：`👍` `❤️` `🎉` `💡` `👀`（每用户每帖每种最多一次，再点取消）
5. 单测 + E2E（mock API）

### 不做
- legacy 留言板
- 富文本 / 图片附件 / 回复楼中楼（本轮仅顶层留言）
- 管理删除后台（可预留 subject 自删本帖）
- 改 wrangler `account_id`

## 方案取舍
| 备选 | 结论 |
|---|---|
| 复用 festival_document 存 UGC | **否**（PLAN §4 硬约束） |
| 仅登录可见留言板 | **否** — 默认可读，写需登录（「登入才能反馈」） |
| 任意 emoji | **否** — 固定 5 个热门，防滥用 |
| 反应计数存 JSON 列 | **否** — 独立 reaction 表，易聚合与去重 |

## API
- `GET /api/feedback?limit=&cursor=` → posts + reactionCounts + myReactions（有会话时）
- `POST /api/feedback` body `{ body }` → 201（需登录；trim 1–2000 字）
- `POST /api/feedback/:id/reactions` body `{ emoji }` → toggle（需登录；emoji ∈ 白名单）
- `DELETE /api/feedback/:id` → 仅作者可删（可选本轮做）

## 验收
1. 未登录：可见列表；发帖/反应按钮触发登录
2. 登录：可发帖、可 toggle 五类 emoji；计数正确
3. `verify:quick` 绿；desktop-chromium E2E 覆盖列表 + 登录门闸 + 反应（mock）
