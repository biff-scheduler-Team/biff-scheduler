# PLAN-20261008225335 — 红黑榜分享图每行带影片海报缩略图

## 目标

红黑榜「生成分享图」出的长图里，每一行左侧加一张影片海报缩略图 —— 与「看片计划海报」
（行程分享图，`poster.ts`）的行内缩略图同一视觉语言。

用户原话：

> 分享图可以带上海报吗? 类似分享行程中一样
>
> 我指的是红黑榜分享也带上类似于行程分享的海报吧

## 范围

**做:**

- `apps/web/src/redblack-poster.ts`：`RbPosterRow` 增 `poster?: string`（源 `FilmNode.poster`）；
  行内左侧画圆角缩略图（59×88），缺图走中性占位块（居中片名首字）。
- `apps/web/src/poster-brush.ts`：把 `loadPosterImages` 从 `poster.ts` 迁来（两张分享图共用，
  §5 口径单一来源）。
- `apps/web/src/poster.ts`：改为 re-export，对外 API 不变（`PosterPreview` 不用改）。
- `apps/web/src/components/RedBlackShareDialog.tsx`：出图前先加载海报图 → `drawRbPoster(canvas, model, images)`；
  canvas 加 `data-poster-count`（与 `PosterPreview` 的 `data-export-codes` 同一手法，给 E2E 一个可断言的锚点）。
- 单测：模型层 `poster` 字段流转 + 「海报不改变行高」。

**不做:**

- 不动 `ROW_H` / `rbPosterHeight`（行高 104 已能容下 88 高缩略图 → 零高度风险）。
- 不动贴纸区 / 榜序 / 勾选节 / 署名等既有口径。
- 不给缺图做豆瓣外链兜底（豆瓣图床有 Referer 防盗链，外链必破图；缺图是常态）。
- 不动 `legacy/`（只读回退件，不接新功能）。

## 方案取舍

| 备选 | 结论 | 理由 |
|---|---|---|
| 左侧海报 + 名次列/文字右移（行高不变） | 采纳 | 与行程图同视觉语言；`ROW_H = 104` 已容得下 88 高缩略图（`FIELD_H` 同高），零高度 / 画布风险 |
| 抬 `ROW_H` 换更大海报 | 否决 | 必须同步改 `rbPosterHeight` 与绘制，错一处就**静默裁图**（本文件已两处注明这个坑），收益不抵风险 |
| 海报替换 / 挤掉右侧贴纸区 | 否决 | 贴纸区是这一节的主角（回答「我贴的那一部长什么样」），不能被挤掉 |
| 新写一份图片加载 | 否决 | `loadPosterImages` 已有「失败即静默跳过 + 同源不污染画布」的语义，必须单一来源 |
| 缺图留纯色空块 | 否决 | 与行程图不一致；居中片名首字可读性更好 |

## 验收标准

1. `npx vitest run apps/web/tests/redblack-poster.test.ts` 全绿（含新增：海报字段流转、海报不改变高度）。
2. `npm run verify:quick` 绿（typecheck + lint + 单测 + `check:repo` / `check:test-map`）。
3. E2E `e2e/react/redblack.spec.ts` 分享图两条用例仍绿，且 `data-poster-count > 0`。
4. 本地起 dev server：红黑榜 →「生成分享图」，每行左侧出现影片海报缩略图，缺图行显示占位块。
