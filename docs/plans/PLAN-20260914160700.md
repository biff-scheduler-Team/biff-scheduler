# PLAN-20260914160700 — 接入 Umami 分析（React Router SPA）

## 目标
接入 `https://anaritikusu.citrons.cc/` Umami，website-id `5e00c94f-0c8a-4990-8ed4-c8499ab84467`。

## 方案（官方 SPA 最佳实践）
Umami 文档 [Track a single-page application](https://docs.umami.is/docs/guides/track-single-page-apps)：
tracker **监听 History API**（`pushState` / `replaceState` / `popstate`），React Router `createBrowserRouter` 的客户端导航会自动记 pageview。

| 做法 | 结论 |
|---|---|
| `index.html` 一次性 `<script defer …>` | **采纳** |
| `useLocation` + `umami.track()` | **否决**（与自动追踪叠成双计） |
| `data-auto-track="false"` + 手写 track | 仅当需要自定义 url/title 时；本站默认 path 已够用 |
| `data-domains` | **采纳** 限 `biff.lcandy.co,biff.iff.day`，本机/preview 不污染 |

## 范围

- 不做：自定义事件、包装 npm 包、改 CSP（当前无）
