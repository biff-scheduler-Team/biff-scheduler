# PLAN 2026-09-10 00:58:11 — 修复右上角标(ⓘ/⚠)遮挡身份行时间文本

> 需求(用户原话):「右上角影片信息的 i 会遮挡影片信息」。
> 本文件 = 本需求唯一规划文档。仅改 src/grid.ts 一行样式;行程/影片库/弹层不受影响。

## 现状(代码事实,src/grid.ts appendCard)

- `infoBtn`(ⓘ 详情钮):`absolute top-[3px] right-[3px]`,卡片 hover 时显现(in-other 卡恒显 opacity-40),宽约 15px → 覆盖卡片右缘 3~18px 区域,垂直 3~18px。
- 冲突标 ⚠:`absolute right-[22px] top-[2px]`,覆盖右缘 22~34px。
- 卡片首行 `t1`(CODE+时间)从卡内左缘排起、文本可延伸至内容区右界 = 卡右缘内缩 7px(`px-[7px]`)。→ 完整时间 `09:00–10:40` 尾部恰落在 ⓘ 的覆盖带内(距右缘 ≤18px),hover 时被 ⓘ 盖住 1~2 个字符;"⚠" 与 ⓘ 悬浮于同一行,同样贴文本。
- 中英文片名(sub 起始 y≈23px)与沉底徽章行 y 均在 ⓘ/⚠(3~18px)之下 → 只身份行被遮。

## 改动方案

### E1 grid.ts:身份行右端让出角标位
- `t1` 类追加 `pr-[20px]`:身份行内容右边界 = 卡右缘内缩 20px,恰在 ⓘ 覆盖带(右 3~18px)之外(留 2px 呼吸),⚠(右 22px 起)也落在空区 → **角标悬浮于预留空白,不再压任何文字**。
- 全行可用宽度同步减 20px:`fitTimeTexts`(挂载后实测量 `clientWidth`)自动适配 —— 放不下完整区间时照旧降级为开始时间并 hover 兜底,无截断、无回归。
- 其余行(ttl/sub/徽章行)不受 padding 影响(与角标 y 无交叠,无需让位)。

> 备选评估:把 ⓘ 改为流内元素会挤压时间文本、导致更多 full 降级,伤害上轮"时间完整性"成果,否决;整体加卡片右 padding 会让中英片名/徽章无谓缩进 20px,否决。

## 验收
1. 卡片 hover:ⓘ 浮现于右上预留空白,不遮挡 CODE/时间任意字符;⚠ 同理。
2. 完整时间显示率不劣化:宽卡(1h≈132px)full 区间仍完整;极端窄卡降级/hover 兜底机制原样。
3. `npm run typecheck` 通过;不启动本地 dev server(读代码自查 + 一次性 build)。
