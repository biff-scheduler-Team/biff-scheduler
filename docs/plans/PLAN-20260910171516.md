# PLAN 2026-09-10 17:15:16 — 「我的选片」按日期区分 + 顶栏两个入口合成一个

> 需求(用户原话):「我的选片中 没有根据日期区分? 还有第二影片库 和 我的选片按钮可以合成一个
> 然后智能选片 需要再在(影片库+我的选片)上再弹一个窗吧」。
> 追问后口径确认:「按日期区分」= **① 日期筛选 chips + ③ 展开场次按日期排序并加日期小标题,两者都要**。
> 本文件 = 本需求唯一规划文档。

## 1. 现状(代码事实,HEAD 3b234d7)

`openFilmPicker`(PLAN-20260910165147 落地的左右双栏弹窗):

| 问题 | 现状 |
|---|---|
| ① 没有日期维度 | 右栏只有一排**档位** chips(全部/必看/备选/随缘/未设);片单按档位排序,展开后每部片的已排场次按**点选先后**排(`rec.picks` 原序),跨天时读起来是乱的 |
| ② 顶栏两个入口 | `#library-btn`(影片库)+ `#my-picks-btn`(我的选片,带 `#my-picks-count` 角标)—— 但两者**开的是同一个弹窗**,按钮重复 |
| ③ 智能排片 | 已经是叠在双栏弹窗上的一层(`openModal` 弹层栈 + 头部「← 返回」),**无需改动** |

## 2. 设计决策

1. **右栏加第二排 chips = 日期**(`data-pdate`),与档位排**并列**:
   - 数据源 = 右栏所有**已排场次**覆盖到的日期(升序),chip 文案 `10/21 周三 3`(当天场次数);
   - 「全部 N 天」= 取消日期筛选;**再点当前天**也取消(与档位 chips 同语义);
   - **只有 ≥2 天时才渲染这一排**(含行标)—— 只有一个选项的筛选没有意义;某天的场次被删光 → 自动回到「全部」;
   - 两排 chips 外观相同,故各配一枚极小**行标**(`日期` / `档位`),否则两个「全部」分不清谁是谁。
2. **日期筛选与档位筛选是 AND**:片单先按档位筛,再按日期筛(该片在这天有已排场次才留下);「未排场」的片在日期筛选下自动隐藏(它没有日期)。
3. **展开的已排场次按 `日期 → 开始时间` 排序,并按日期分节**:
   - 节头 `10/21 周三 · N 场`(浅底小字),节内场次行复用同一份 `showRow()`;
   - 节头已给日期 → 节内行**不再重复印日期**(`showRow(s, withTopBorder, hideDate=true)`,行内只留 `17:00-19:00`);
   - 其余(官方代码章 / 时长 / 特性徽章 / 定位 ▸ / 加入三态)与左栏**逐字一致** —— 一致性只在「日期搬到了节头」这一处让位。
4. **顶栏合成一个按钮**「影片库 · 选片」(`#library-btn` 复用,角标 id `my-picks-count` → `picker-count`),
   删掉 `#my-picks-btn`;`main.ts` 的两条分支合一。`renderPicksBadge()` 只换 id。
5. **智能排片不动**:仍是叠在双栏弹窗之上的第二层(头部「← 返回」,返回后列表状态全在)。

## 4. 边界与风险

- **`groupShowsByDate` 与文件后半的 `groupByDate`(AI 结果卡,吃 `AiPlanPick[]`)同名不同物** → 另起名,避免与既有函数冲突。
- **Tailwind v4 只生成源码里完整出现的字面量类**:本轮新增的 `text-faint` / `bg-[var(--bg-hover-soft)]` /
  `min-w-0 flex-1` 等均为既有高频类,构建后 `grep` 产物 CSS 核对命中。
- **「另有 N 场已不在当前排期里(数据换版)」这条口径只在未按日期筛时成立**(按日期筛时 `rows.length` 已被筛过,
  差值不再等于「换版丢的场次」)→ 加 `dateFilter === null` 条件,不输出误导文案。
- **弹层内改状态必须就地重绘**:日期 chips 点击走本弹窗自己的 `render()`(保存/恢复两栏 `scrollTop`)。
- **单一数据源不变**:本需求只动渲染层与筛选态,`store.picks` / `setWish` / `toggleScreening` / `removePick` 一行不改。

## 5. 验收标准

1. `npm run typecheck` + `npm run build` 通过。
2. 顶栏只剩一个「影片库 · 选片」按钮,角标 = 影片记录数;点开是同一个左右双栏弹窗。
3. 已排场次跨 ≥2 天时,右栏出现「日期」chips 排(全部 N 天 / 10/21 周三 3 / …);点某天 → 片单只剩该天有场的片,
   展开后只列该天的场次;再点该天 / 点「全部」→ 复原。只有 1 天时该排不渲染。
4. 每部片展开后的场次按日期升序、时间升序,且每组前有 `10/21 周三 · N 场` 节头;节内行不再重复印日期。
5. 档位 chips 与日期 chips 可叠加(AND),叠加后无结果时提示「当前筛选下暂无选片」。
6. 智能排片仍是叠在上面的一层(有「← 返回」),返回后双栏的搜索词 / 筛选 / 滚动位置都在。
