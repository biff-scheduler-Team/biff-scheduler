## 2. 决策

1. **死代码直接删**(`displayTitle` 例外 —— 它正是第 3.1 项的落点,保留并接线)。
2. **重复定义一律上提到单一来源**:
   - 片名链 → `util.ts::displayTitle`(补齐 mapping 参数口径);
   - 档位权重 → `pick.ts::PRI_RANK`;
   - 圆角胶囊 chip → 新 `src/chips.ts`(`PILL_BASE/IDLE/ON`);**顶栏日期条 chip 视觉不同
     (7px 圆角 / 13px / 品牌红实底),不并入**,原样留在 `main.ts`(避免任何视觉变化);
   - 日期切段 → `util.ts::groupByDate<T>(list, dateOf)` 泛型;
   - 表单行骨架 → 新 `src/form.ts::fieldBox` / `numInput`;
   - 时间标签 → `grid.ts::clockLabel` 删除,改用 `util.ts::fmtEndClock`(逐字等价:`次日 ` + 24h 折叠);
   - `norm` → `util.ts::normText`。
3. **大文件按职责拆**:
   - `src/ai-panel.ts` ← `library.ts` 的 AI 面板 UI(`openEngineDialog` / `aiPanel` / `optionCard` /
     `resultCard` / `aiPickRow` / `aiRejectSection` / `aiDropSection` / `BTN_*` / `aiField` / `aiInput`)。
     与 `ai.ts`(纯逻辑)配对。**ai-panel 不反向依赖 library** —— 「去影片库打标」落点改为调用方注入
     `onGoTag` 回调;`FilmNode` 由 library 导出、ai-panel 仅 `import type`(类型导入被擦除,无运行时环)。
   - `src/settings.ts` ← `main.ts` 的设置弹层(`openSettings` / `openTalkMinModal` / `settingsField` /
     `settingsInput` / `segmented` / `clampNum`)。
   - `src/picklist.ts` ← `main.ts` 的抢票顺位清单(`copyPicklist` / `copyText`),`cat` / `gvTalkOf` 以参数注入。
   - `src/toast.ts` ← `main.ts::toast`(被 main / settings / picklist 共用,避免反向依赖 main)。
   - `src/ai-prompt.ts` ← `ai.ts::SYSTEM_PROMPT` 常量(纯文本,零逻辑)。
   - `src/engine.ts` → `src/score.ts`(文件内容不变,仅改名 + 更新全部引用与文档)。
4. **补 lint 门禁**:`.editorconfig` + `eslint.config.js`(flat config,typescript-eslint recommended)
   + `npm run lint`。**不引入 prettier 自动重排** —— 本仓库有大量刻意保留的长行/对齐(见 CONVENTIONS),
   `prettier --write` 会产生 8000 行无意义 diff,风险远大于收益(仅在 PLAN 里记录该决策)。

## 4. 边界与风险

- **行为零变化**是唯一红线:所有搬迁都是机械搬运,不改任何类名 / 文案 / 计算。
  唯一的「等价改写」是 `clockLabel` → `fmtEndClock`(逐字等价)与片名链 → `displayTitle`(需确认
  `displayTitle(s, mapping?.title_cn)` 与既有 5 处逐字同序:`title_zh → mapping.title_cn → title_en`)。
- **循环依赖**:`library ↔ ai-panel` 只允许 `ai-panel → library` 的 **type-only** import;
  「去影片库打标」走 `onGoTag` 注入,杜绝运行时环。
- **`engine.ts` 改名**:同步 `README.md` §五模块表 / `PLAN.md` §1 / `CONVENTIONS.md` 全部引用;
  只改文件名与 import 路径,导出符号(`EngineFilm` / `scorePlanRows` / `ScoredRow`)不变。
- **Tailwind v4**:本次不新增任何 utility 类(纯搬运),产物类名集合不变。
- **不动**:`data.ts` / `api.ts` / `ics.ts` / `gv.ts` / `conflict.ts` / `tip.ts` / `badges.ts` /
  `legend.ts` / `row.ts` / `types.ts` / `style.css` / `functions/` / `public/`。
