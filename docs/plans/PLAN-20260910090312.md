# PLAN 2026-09-10 09:03:12 — 「我的选片」总览 + 甘特图打标可见(必看/备选/随缘)

> 需求(用户原话):「加一个我的选片 然后能看到我的所有选片」→ 澄清确认口径 = **影片库打标清单(wish)**;
> 追加:「打标之后 除了能总览我的选片 然后在甘特图能看出来这是我选的 必看 随缘等等 需要想一个交互」。
> 本文件 = 本需求唯一规划文档。

## 现状(代码事实,HEAD 3016a25)

- **wish 已存在但不可总览**:`state.ts` 的 `wish: Map<filmKey, Priority>`(must/maybe/wild),持久化 `biff.wish.v1`,`loadWish()/setWish()`;打标入口只有「影片库」弹层行内三选;消费方只有 `engine.ts` 智能排片。无任何聚合视图,网格卡上也完全看不到打标。
- **节点 key 口径**(`library.ts` openLibrary 内联):目录命中 → `cat:${f.id}`;否则 → `sched:${filmKey(s)}`(`filmKey = (title_zh||title_en).toLowerCase().trim()`)。**只此一处生成**,其它模块要复用需抽出。
- `setWish()` **不触发 notify** → 打标后顶栏/网格/行程不会感知(影片库靠自身 render() 局部刷新)。
- 网格卡现有状态语言(互斥优先级):红 in-conf > 黄 tight > 绿 in-plan(已选) > 灰 in-other;`hour-dim` 淡化。**优先级不染网格卡**(PLAN-20260910010232 已定)。
- 卡片内空位:标题行(中文片名)、副行(英文名/时长)、底部徽章流(mt-auto)。左上 `A/B` 角标(in-other)、右上 `ⓘ`/`⚠` 已占用。

## 方案

### A. 共享 key + 状态广播
- `src/util.ts` 新增 `filmNodeKey(cat, s): string`(type-only import,与 library 同口径:中文名精确命中目录 → `cat:id`;否则 `sched:filmKey(s)`)——网格 / 详情 / 影片库 / 选片总览**单一来源**。
- `src/library.ts` 内联 key 生成改用该函数(消除双份口径)。
- `src/state.ts`:`setWish()` 末尾补 `notify()` —— 打标后顶栏计数、网格、行程、详情即时同步(与 `setGvTalk` 一致)。

### B. 顶栏入口(`index.html` + `src/main.ts`)
- `header` 内「影片库」按钮左侧新增按钮:`我的选片 <span id="my-picks-count">N</span>`(与影片库同族样式,计数 0 时按钮仍可用)。
- `main.ts`:`renderAll()` 增加 `renderPicksBadge()`(写计数);`bindEvents` 增加 `#my-picks-btn` → `openMyPicks(...)`(ctx 与影片库同构,`onLocate` = 现有 `jumpToScreening` 闪卡定位,`onFilm` = 详情弹层)。

### C. 「我的选片」总览弹层(`src/library.ts`)
- 重构:`openLibrary` 内「目录索引 + 排期挂载 + 目录补全 + 排序」抽为模块级 `buildFilmList(ctx)`;`openLibrary` 复用(对外行为零变化)。
- 新增 `export function openMyPicks(ctx: LibraryCtx)`:
  - 头部统计 + 档位筛选 chips:`全部 N / 必看 a / 备选 b / 随缘 c`(点击筛选,再点取消);
  - 列表(排序:must → maybe → wild,组内按目录序):**档位章**(实心色块,可点三档切换)+ 中文名 + 原片名 + 目录 meta + 豆分 + 排期信息(`N 场` / `A 方案已选 x` / `暂无排期`)+ 操作(`详情 ⓘ`、有排期时 `定位 ▸`、`✕ 取消打标`);
  - 空态:引导文案(去影片库点「必看/备选/随缘」);
  - 头部右侧:「智能排片 ▸」(把 `openLibrary` 内的 `openEngine` 提为模块级 `openEngineDialog(ctx, filmList)` 共用)。
  - 交互闭环:切换档位 / 取消打标 → 重渲本弹层 + `notify()` 同步全站。

### D. 甘特图打标可见(`src/grid.ts`)
- `GridCtx` 增 `wishOf: (code: string) => Priority | undefined`(main.ts 注入)。
- `appendCard`:在**标题行前**插入档位色点(7px 圆点,底 `--color-must/maybe/wild`,1px card 描边,`shrink-0`),`data-tip` = 「必看 · 影片库已打标」类文案。
  - 与底色语义**正交**:绿/黄/红是"排期状态",色点是"我的选片打标";已选卡(绿底)上仍可见色点,不冲突、不换底色。
  - 卡窄时不影响(圆点固定 7px,标题仍 truncate)。

### E. 详情弹层打标闭环(`src/modal.ts`)
- `showFilmModal` / `showCatalogFilmModal` 片名区增加一行「我的选片」三选(必看/备选/随缘,再点取消),对象 = `filmNodeKey(cat, anchor)`;点选后更新按钮态 + `notify()`。→ 在网格卡点 ⓘ 即可直接打标,不必绕影片库。

### F. 图例与说明同步
- `index.html` 网格图例:新增一条「● 必看 / 备选 / 随缘 — 影片库打标色点(与底色无关)」。
- `src/legend.ts` §6 网格与行程图例:补一行说明打标色点语义 + 与红绿灯底色的正交关系。

## 验收

1. 影片库点「必看/备选/随缘」→ 顶栏「我的选片」计数即时变化;打开总览可见全部打标影片,可按档筛选、改档、取消、看详情、定位到该片场次。
2. 甘特图:被打标影片的**所有场次卡**标题行前出现对应档位色点(必看红 / 备选琥珀 / 随缘灰);已选绿底卡与色点并存;无打标影片卡零变化。
3. 详情弹层(网格 ⓘ / 影片库详情 / 目录片详情)可直接打标,与影片库、总览三方即时一致。
4. 空态有引导;刷新后 `biff.wish.v1` 偏好仍在。
5. `npm run typecheck` + `npm run build` 通过;不启动 dev server(读代码 + build + 一次性静态服务目检)。
6. 不改 `biff.plan.v1` / D1 契约 / ics 导出。

## 实现纪要(与上文的偏差)

- **共享层另起 `src/pick.ts`**:三档顺序 `WISH_ORDER`、文案 `PRI_LABEL`、章/点/文字色 `PRI_BG_ON`/`PRI_DOT_BG`/`PRI_TEXT`、分段控件 `buildWishSeg()` 收口一处(影片库行内 / 总览 / 详情弹层 / 甘特色点共用),避免三处各写一份 must/maybe/wild 文案与色类(Tailwind v4 只生成源码里完整出现的类)。
- **`wishOf` 签名**:`(s: Screening) => Priority | undefined`(非 code)。网格里本来就有 `s`,main.ts 注入 `(s) => wish.get(filmNodeKey(cat, s))`,省一次 `byCode` 回查。
- **`buildWishSeg` 内 `stopPropagation`**:三选常嵌在可点容器(影片库可展开行 / 甘特卡)里,不拦会顺带触发展开或选中。

- **图例**:`legend.ts` 未并入 §6,而是新增独立一节「我的选片(打标)」——因为要显式区分**两层档位**(影片库打标 = 影片级选片意向;行程行三段 seg = 已排场次级优先级),并附 `note()` 说明二者同色系但互不影响。
- **`openMyPicks` 列表每次 `render()` 重算**:取消打标后就地刷新,计数 / chips / 列表三者始终一致,不做增量维护。
- 验证:`npm run typecheck` + `npm run build` 均通过;`dist` CSS 已确认生成 `bg-must/bg-maybe/bg-wild`、`text-must/text-maybe/text-wild` 六个类。未启动 dev server(按项目约定:读代码 + build 校验)。
