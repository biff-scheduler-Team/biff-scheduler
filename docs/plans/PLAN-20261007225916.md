# PLAN-20261007225916 — 想点 / 拖未解锁的贴纸时，把「标记看过」指给用户

## 目标

> 用户原话：**「标记看过 这个不是很明显 当用户想点击拖动贴纸的的时候 需要提示他点击看过」**

红黑榜每张卡上，红 / 黑两枚贴纸在**没标记「看过」**时是真 `disabled`（2026-09-29，
PLAN-20260929172651 §4）：形态上确实「一眼看得出碰不动」，
但**碰下去什么都不发生** —— 海报左下角那枚 22px 的「＋」角标太安静，用户找不到解锁入口，
读到的只是「点了没反应」。

要在用户**伸手的那一刻**（点 / 拖暂存区那两枚）把这个入口指出来。

## 范围

**做：**

- 未标记时，在 `.rb-tray` 上盖一层**拦截层**（`.rb-tray-lock`），承接 pointerdown / click：
  - 弹一条 `ToastQueue` 提示，把位置说清（「海报左下角的「＋」」）；
  - 让该卡 `.rb-mark`（「标记看过」角标）脉冲一下，当场可寻。
- 键盘同样可达（拦截层是 `<button>`，Enter / 空格走 `click`，`detail === 0` 分支）。

**不做：**

- **不动**那两枚按钮的 `disabled` 形态（E2E 守着 `toBeDisabled()`；2026-09-29
  「不要看着能点、点了被拒的假出口」的口径不变）—— 只拦手势解释一句。
- 不给角标加**常驻**动效 / 文字：近 300 张卡一起动 = 噪音（2026-09-29 已因「重复灰字」收过一轮）。
  提示只在**被触发那一刻**出现，正是本需求要的效果。
- 不动贴纸画布、拖拽、换款轮盘等任何既有交互。

## 方案取舍

| 备选 | 结论 | 理由 |
|---|---|---|
| 拦截层覆盖暂存区 | **采纳** | 按钮保持真 `disabled`（形态与 E2E 契约都不动），手势却被接住 —— 两个口径同时满足 |
| 去掉 `disabled`，改 `aria-disabled` + 点击兜底 | 否决 | 推翻 2026-09-29 的可达性口径，且要重写 E2E 的 `toBeDisabled()`；按钮会被键盘 Tab 到，语义变味 |
| 只把角标做得更显眼（放大 / 加字 / 常驻呼吸） | 否决 | 近 300 张卡同时动 = 噪音；且与「能收起就收起」的既定方向相反 |
| 手势反馈走 React state | 否决 | 会带来一次单卡重渲染；这类**瞬时**反馈在本页一律直接改 DOM（见 `beginDrag` / `setOut`） |

## 验收标准

1. 未标记的卡上，在红 / 黑按钮位置按下（指针或键盘）→ 出现提示条（`role=alertdialog`，
   文案含「标记看过」），且该卡 `.rb-mark` 拿到 `rb-mark--nudge` 类。
2. 标记「看过」后，拦截层消失，红 / 黑两枚按钮恢复原有交互（点 / 拖一切照旧）。
3. 既有 E2E「没标记…是禁态」仍绿（`toBeDisabled()` / `.rb-tray` 的 `title` 不变）。
4. 新增一条回归 E2E 覆盖验收 1；`npx playwright test -c playwright.react.config.ts e2e/react/redblack.spec.ts --project=desktop-chromium` 绿。
