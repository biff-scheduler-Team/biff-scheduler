# PLAN 2026-09-10 19:40:00 — 「我的行程」信息对齐 / 去冗余 / 收拢胶囊

> 需求(用户原话,三段):① 信息对齐与阅读流;② 胶囊标签与图标「瘦身」;③ 跨场次间距提示提级。
> 前置:`PLAN-20260910190916`(行程搬进抽屉)、`PLAN-20260910193000`(场次行三处统一)。
> 本文件 = 本需求唯一规划文档。**已实现。**

## 1. 现状(代码事实,改前)

```
src/row.ts::screeningRow      三处共用骨架(影片库 / 我的选片 / 我的行程)
  └ [CODE][影院章][日期][时间] [片长章 · 等级章 · 字幕章 · GV章 · 页码章] →→ [操作组]
src/agenda.ts::buildRow
  ├ acts  = ⏱ 25′ / ✓含映后 / A / ★ / ✕   ← 五枚平铺在行右
  └ extra = 片名(第二行左下角)+ 冲突 + ↖ 距上一场 119min
```

用户反馈的三类问题:

| # | 问题 | 根因 |
|---|---|---|
| 1 | 片名被挤到第二行左下角,顶部被代码 / 时间占满 | `screeningRow` 把 `when`(CODE+影院+日期+时间)放行首,片名只能落在 `extra` 行 |
| 1 | 卡片内重复日期 | `buildAgenda` 已按日期分节,却没给 `screeningRow` 传 `hideDate` |
| 2 | 全部字段都是同款圆角矩形框 | `when` 的影院章 + `metaChipRow` 的片长 / 字幕 / 页码章全走 `uniformChipEl` |
| 2 | `⏱ 20′` 与 `✓ 含映后` 两枚胶囊重复出镜 | 两者正交(多久 / 去不去)故各占一枚,但视觉上是一件事 |
| 2 | `A` / `★` 与 `✕` 挤在同一排 | 都塞进 `acts` |
| 2 | `✕` 颜色太深易误触 | 实心描边胶囊 |
| 3 | `↖ 距上一场 119min` 在卡片内右下角,易漏 | 挂在 `extra` 行尾部 |

## 2. 设计决策

1. **片名提为行首主视觉**(而非「左片名 / 右标签」两栏):
   `screeningRow` 新增 `title` —— 非空时**独占一行**渲染 `片名(14px 加粗)` + `titleExtra` + `acts(ml-auto)`,
   其后才是身份行。理由:520px 抽屉放不下真正的左右分栏,而「片名单独一行加粗」在任何宽度下都成立。
2. **日期去重**:`buildAgenda` 传 `hideDate: true`(与「我的选片」同口径 —— 它早就传了)。
3. **胶囊瘦身 = 只留两枚框**:CODE(黑块,身份)+ **观影等级**(描边 + 强调色,硬性准入信息)。
   其余 `影院 · 片长 · 字幕 · 页码` 走 `row.ts::plainMetaRow()` —— 中灰纯文本 + `·` 分隔,各带 `data-tip`。
   - 新增 `legend.ts::ratingChipEl(s)`(只出等级章,无等级返回 null)。
   - 导出 `legend.ts::pageTip()`(原为模块私有,灰文本也要 tooltip)。
   - **GV 不再出章**(行程行由「映后 N′」胶囊表达);其余场次特性(首映 / 大师班 / 联映)保留描边章 ——
     它们是「这不是一场普通放映」的主信号,抹平反而丢信息。
4. **`⏱ N′` + `✓含映后` → 一枚「映后 N′」胶囊**:
   - 含 = 浅绿底绿字(`--color-ok` 9% 底,与网格谈段同色);弃 = 中性灰 + 删除线。
   - 点**标签** = 含 / 弃(`data-act="gv-talk"`);点**数字** = 改本场时长(`data-act="gv-talk-min"`)。
     ⚠ 数字是 `<span>` 而非嵌套 `<button>`(HTML 合法),`main.ts` 的 `closest("[data-act]")` 天然命中最内层,
     **无需改事件处理**。tip 里写明这个分工。
5. **`A` / `★` 贴片名**(`titleExtra`),`✕` 留右侧操作组并改**极淡**:
   `text-faint opacity-40` + `group-hover:opacity-100`(行容器加 `group`)。
   刻意**不用** `opacity-0` —— 触屏没有 hover,按钮会永远看不见(与 `library.ts::ICON_BTN` 同一理由)。
6. **转场间隔提级为卡片之间的连接件**:`agenda.ts::gapConnector(prev, s)`,
   浅灰**虚线竖轨**(`border-l border-dashed`) + `赶场间隔 119min · 跨馆缓冲 15min`。
   三态口径不变(余量 = 间隔 − 跨馆缓冲;bad 红 / tight 黄 / ok 灰)。
   当前行自身冲突时不出连接件(冲突提示已占一行,旧口径一致)。

## 4. 边界与风险

- **行程档只影响行程**:`title` / `plainMeta` 是**opt-in**,影片库 / 我的选片不传 → 骨架不变。
- **`✕` 的 hover 显现依赖行容器带 `group`**:`CARD_BASE` / `CARD_CONF` 已补,别再删。
- **嵌套 `data-act`**:数字 span 在标签 button 内,`closest()` 取最内层 —— 若将来给标签加子元素,
  记得不要把 `data-act` 写到非预期层级。
- **`extra` 由 `null` 改传 `undefined`**:`ScreeningRowOpts.extra` 是 `HTMLElement | undefined`。
- **`min-h-[18px]` 等任意值类**必须字面量书写(Tailwind v4 只扫源码字面量),已核对产物 CSS 命中。
