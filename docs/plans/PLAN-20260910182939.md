# PLAN 2026-09-10 18:29:39 — 「影片库 · 我的选片」由弹窗改为独立页面

> 需求(用户原话):「影片库 · 我的选片 这个弹窗太小了 要不你不要做弹窗 做一个单独的页面吧 这样交互会好一点」。
> 本文件 = 本需求唯一规划文档。

## 1. 现状(代码事实,HEAD 5af4e79)

`library.ts::openFilmPicker(ctx)` 把左右双栏 body 交给 `openModal("影片库 · 我的选片", body, "xl", () => render())`:

- 弹层宽 `xl` = **1280px**,但外层还有 `px-4` 与卡片 `p-[18px]`,再减去两栏 gap 12 与右栏固定 480
  → 左栏实际只有 ≈750px;视口 <1312px 时卡片还会被 `max-w-full` 继续压小;
- 两栏列表各自 `max-h-[min(58vh,520px)]` —— 一屏只能看 ~7 行影片,选片要不停滚;
- 弹层还占掉纵向:overlay `py-12` + 卡片头,列表可用高度进一步缩水。

结论:**约束不是「弹窗」本身,而是弹窗的宽度与高度上限**;而选片是一个「要长时间停留、左右对读、频繁筛选」
的主任务,塞进弹窗确实憋屈。

## 2. 设计决策

1. **独立页面**:`index.html` 新增 `<section id="picker-page">`(放在 `<main>` 内、`#grid-wrap` 之前,
   复用 `bg-card border rounded-[8px] p-[14px]` 面板语言 + `<h2>` 方括号标题标记,与「排片总览 / 我的行程」同级)。
   - 打开:隐藏 `#grid-wrap` / `#agenda-wrap` / `#page-foot`,显示 `#picker-page`,滚到顶;
   - 返回:`← 返回排片` 按钮 / `Esc`(仅当没有弹层时),恢复三块并**还原打开前的 `window.scrollY`**。
2. **列表高度放开**:两栏 `max-h` 由 `min(58vh,520px)` → `min(70vh,860px)`(页面里可以放心用高度)。
3. **状态订阅替代弹层 `onReturn`**:弹层栈那套「下层 `display:none` + 关闭时调 `onReturn`」在页面上不成立。
   页面打开期间订阅 `state.subscribe` → 只要 `store` 变更就 `render()`(详情弹层里改档位、网格点选都会同步两栏计数)。
   ⚠ 订阅里必须判「页面是否打开」,否则关页后仍会空转。
4. **打开页面期间跳过网格/行程重建**(`main.ts::renderAll` 早退):`#grid-wrap` 被 `display:none` 后
   `clientWidth = 0`,而 `renderGrid()` 每次 `host.replaceWith(grid)` 都是**新滚动容器**(`scrollLeft` 归零),
   锚点回算在 0 宽度下会算出 `Math.min(left, 0)` → 横向滚动位置被静默重置。
   → 关页时由 `closePickerPage()` 回调一次完整 `renderAll()` 补上(注入式 `setPickerOnClose`)。
5. **影片资料弹层回归普通弹层**:页面不是弹层,详情 `openModal` 天然「压在页面之上」(overlay 半透明,页面可见)。
   故上一轮为「弹窗叠弹窗」加的 `keepBelow`(不隐藏下层 + 20% 浅遮罩 + 居中)在本需求下**已无使用场景**,
   连同 `--overlay-bg-soft` token 一起删除(避免死代码),`showFilmModal` / `showCatalogFilmModal` 回到 `"lg"`。
6. **顶栏按钮语义**:`#library-btn` 变**开关** —— 页面已开时再点 = 返回(而不是重建页面丢状态)。
   按钮 tooltip 文案由「一个弹窗两栏…」改为「独立页面…」。

## 4. 边界与风险

- **`openEngineDialog(filmList, ctx, render, fromLibrary = true)`**:智能排片仍是**弹层**,压在选片页之上;
  `onReturn = render` 语义不变(它现在是「AI 弹层关闭时刷新页面」)。`modeBar` 的
  「← 返回影片库打标」= `closeModal()`,页面本来就在后面,`fromLibrary=true` 分支不动。
- **`jumpToScreening`(定位 ▸)**:必须 `closeAllModals()` + `closePickerPage()` 之后才能量 `#grid-wrap`
  (隐藏元素 `getBoundingClientRect()` 全 0,不先恢复会滚到错位置)。
- **`store.picks` 会被整体替换**(`syncFromCloud` 里 `store.picks = merged`)→ 页面**每次打开都重建**
  (不缓存 DOM / 不缓存 ctx),避免持有旧 Map。
- **Tailwind v4 只生成源码里完整出现的字面量类**:本轮新增的 `min-h-0` / `is-hidden` 均为既有类;
  未引入新的任意值类。
- **不改数据层**:`store.picks` / `setWish` / `toggleScreening` / `removePick` 一行不动。

## 5. 验收标准

1. `npm run typecheck` + `npm run build` 通过。
2. 点顶栏「影片库 · 选片」→ 排片总览 / 我的行程 / 页脚隐藏,选片页面板出现(全宽、无弹窗遮罩);再点该按钮 / 点「← 返回排片」/ 按 Esc → 恢复排片页,且回到打开前的页面滚动位置。
3. 页面里左栏(全部影片)宽 ≈1200px(视口 ≥1280 时),两栏列表可滚动高度 ≈ min(70vh,860px)。
4. 页面里改档位 / 加入移出场次 → 两栏计数与场次行按钮同帧更新;从行尾 `ⓘ` 开「影片资料」弹层(压在页面上、页面可见),改完关闭 → 页面计数已刷新。
5. 展开行点「定位 ▸」→ 页面关闭、跳到网格对应日期与卡片并闪烁高亮。
6. 智能排片仍是压在选片页之上的弹层;采纳后返回,页面「已排 N 场」计数已更新。
