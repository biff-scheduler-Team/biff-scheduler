# PLAN-20261014235720 — 去掉顶栏「重叠 N」按钮

## 目标

> 用户原话：「去掉 重叠模块 所有相关内容」
> （经澄清确认：指顶栏那枚显示冲突数的「重叠 N」按钮，`App.tsx::header-conflict`。）

把顶栏「重叠 N」这枚**冲突提示按钮**整块删掉，连同它专用的样式与派生数据。

## 范围

**做：**
- `apps/web/src/app/App.tsx`：删掉「重叠 N」`ActionButton` 及其大段注释；从 `useCatalog()` 解构里去掉 `conflictCount`。
- `apps/web/src/style.css`：删掉 `.header-actions .header-conflict` 规则块（含其注释）。
- `apps/web/src/app/store.tsx`：删掉 `derive()` 返回里的 `conflictCount`（删除后无消费点，属死数据）。
- 新增一条回归 E2E：行程里存在**真实重叠对**（`conflictCount > 0`）时，顶栏**不再**出现该按钮。

**不做：**
- **不动「时间重叠」冲突体系本身** —— `conflict.ts` 检测、甘特图红卡、图例「时间重叠」、卡片「时间重叠，需择一观看」、`conflicts` / `plans` 派生、`--conflict` / `--conflict-line` token 全部保留（它们与顶栏按钮不是同一个东西）。
- 不删 `store.tsx` 的 `conflicts` / `plans`（其它视图仍在用）。
- 不删 `/rush-analysis` 等页面里对「重叠」的其它表述。
- 不改 legacy（只读回退件）。

## 方案取舍

| 备选 | 结论 | 理由 |
|---|---|---|
| 只删 JSX，留着 `.header-conflict` 样式与 `conflictCount` | 否决 | 死样式 / 死数据正是 §5「口径单一来源 / 禁止定义未使用变量」要清的东西 |
| 连「时间重叠」冲突体系一起删 | 否决 | 用户澄清只指顶栏按钮；冲突体系是排片核心，删它属另一档需求 |
| 保留按钮但改文案 / 藏进菜单 | 否决 | 用户要的是「去掉」，不是改形态 |

## 验收标准

1. 顶栏在 `conflictCount > 0` 时也不再渲染 `.header-conflict` 按钮；页面无「重叠 N」字样。
2. 新增回归 E2E「header 不再显示重叠按钮」在改动前为红、改动后为绿。
3. `typecheck` / `lint` 无新增问题（无未使用变量 / 导入）。
4. 冲突体系行为不变：甘特图红卡、图例、卡片冲突提示仍在。
