# PLAN 2026-09-11 14:03:42 — 选片抽屉:向左滑出动画 + 可拖拽调宽 + 行程非空自动常驻

> 需求(用户原话)：「能不能刚进界面 在甘特图点击选了行程后以 就从右向左弹出抽屉呢 以及行程不为空的时候
> 抽屉常驻 然后也可以点击收起 抽屉的长度是可变的 (注意组件大小适配)」
> 澄清(用户答问):① 抽屉**仍在左侧**,「弹出方向是向右」(先前我把方向说反了);
> ② 「长度可变」= **用户拖拽调宽,并记住上次宽度**;③ 自动滑出时机 = **进界面行程非空 + 甘特图点选场次后**;
> ④ 与网格关系 = **挤压式(不遮挡)**,与现状同口径。
> 前置：`PLAN-20260910184745`(左侧挤压抽屉)、`PLAN-20260910190916`(行程搬进第三 tab)、
> `PLAN-20260910235000`(断点 768 / 1099)。
> 本文件 = 本轮唯一规划文档。

## 1. 目标

1. **滑出动画**：抽屉不再「瞬间出现 / 瞬间消失」——从**左缘向右**长出来(宽度 0 → `--picker-w`)，
   收起时反向缩回。因为是挤压式，网格随宽度变化同步变窄，卡片始终可见可点。
2. **可拖拽调宽**：抽屉右缘一枚竖向手柄，拖动即改宽，落盘 `biff.pickerw.v1`，下次打开保持。
3. **自动常驻**：① 进界面时 `store.picks` 非空 → 抽屉自动滑出到「我的行程」tab；
   ② 甘特图点选某场(加入，而非移出) → 抽屉自动滑出。
4. **手动收起**：`收起 ✕` / Esc / 顶栏按钮仍可收起；收起后**不再被同一次操作反复弹开**
   (只在「新加入场次」或「下次进入界面」时再滑出)。
5. **尺寸适配**：宽度上下限钳制；≤1099px 维持既有「全宽面板」退化(宽度不再由 `--picker-w` 决定，
   拖拽手柄隐藏)。

## 2. 现状(改前)

```
<main class="flex items-start gap-4">          ← 挤压式 flex 行
  <aside id="picker-drawer"                    ← 左,520px,sticky top-[64px]
         class="is-hidden … w-[520px] … max-[1099px]:w-full">   ← 开关 = is-hidden(display:none)
  <div id="main-col" class="flex-1 min-w-0">   ← 网格
```

- 开关：`library.ts::showPickerDrawer()` / `closePickerDrawer()` 切 `is-hidden`；
  `isPickerDrawerOpen()` 读它。**`display:none` 无法过渡**，所以没有任何动画。
- 宽度：写死在 markup 的 `w-[520px]`，无持久化、不可拖。
- 打开时机：仅顶栏按钮 / 冲突角标 / 窄屏 boot。

## 3. 设计决策

| # | 决策 | 理由 |
|---|---|---|
| D1 | 折叠态由 `is-hidden`(display:none)改为 **`is-collapsed`(width:0 + 透明度)** | `display:none` 不可过渡；宽度过渡天然产生「向右长出」的观感，且**不需要**额外的 translateX(挤压式布局下 translateX 不会推网格) |
| D2 | 宽度经 **`--picker-w`** 单一变量驱动(`#picker-drawer { width: var(--picker-w, 520px) }`)，宽度相关的 Tailwind 类(`w-[520px]` / `max-[1099px]:w-full`)从 markup 移入 `style.css` | ID 选择器(1,0,0)权重高于 Tailwind 的单类(0,1,0)，markup 上的 `w-[…]` 会被 CSS 压死 → 必须收口到一处，否则出现「CSS 生效了但 markup 写着别的值」的假象 |
| D3 | 折叠态用 `margin-right: -16px` 抵消 `<main>` 的 `gap-4`(16px) | 否则 0 宽抽屉仍占一条 16px 空隙，收起后网格左边留白 |
| D4 | 宽度钳制 **360 ~ 800px**，默认 520 | 下限 360：`filmRow` 的场次行 `[CODE][时间][影院…] → [定位 ▸]` 再窄就折成多行；上限 800：再宽就比网格还宽，挤压式失去意义 |
| D5 | 宽度存 **独立 LS 键 `biff.pickerw.v1`** | 与 `biff.ai.v1` / `biff.gvtalk.v1` 同口径：视图偏好不混进 `biff.settings.v1` 的设置序列化 |
| D6 | 自动滑出 = **`ensurePickerOpen(ctx, tab = "agenda")`**：已开则**原样返回**(不切 tab、不重建) | 用户可能正在「影片库」打标，每次点选都把他弹到「我的行程」会很烦；只在「关着 → 打开」这一次切到 agenda |
| D7 | **不做**「行程清空后自动收起」 | 「常驻」只在「非空」时成立，但自动收起会打断「点错一场 → 移出 → 想再点另一场」的节奏；收起入口始终在(✕ / Esc / 顶栏) |
| D8 | 拖拽中加 `.is-resizing`(`transition: none`) | 否则宽度过渡会「追不上」指针，手感发飘 |
| D9 | 拖拽**只在 pointerup 时**回调 `pickerToggleHandler()` 重绘网格 | 逐帧重绘网格代价高；拖拽期间网格内部画布是定宽(只有外层 `overflow-x-auto` 视口在变)，无需重排 |

## 5. 行为矩阵(改后)

| 场景 | 结果 |
|---|---|
| 进界面，`store.picks` 为空 | 抽屉收起(0 宽，无占位) |
| 进界面，`store.picks` 非空 | 抽屉**滑出**并停在「我的行程」tab |
| 进界面，≤768px | 维持既有「列表优先」：默认打开(优先于上面两条) |
| 甘特图点一张**未选**卡 | 加入当前方案 → 抽屉滑出(已开则不切 tab) |
| 甘特图再点同一张卡(移出) | 不弹；抽屉维持当前开合态 |
| 点 GV 谈块的「未在当前方案」分支 | 同「加入」→ 滑出 |
| 拖动右缘手柄 | 宽度实时跟手，松手落盘 + 网格重绘一次 |
| 双击手柄 | 宽度复位 520px |
| 点 `收起 ✕` / Esc / 顶栏按钮 | 缩回；行程仍非空，但**不会**立刻被弹开 |
| ≤1099px | 抽屉全宽面板，手柄隐藏，宽度不受 `--picker-w` 影响 |
| `prefers-reduced-motion` | 见 §7 未做项 |

## 6. 验收

1. `npm run build` 全绿(typecheck + eslint + 单测 + vite build)。
2. 产物 CSS 含 `#picker-drawer` 的 `var(--picker-w` 与 `.is-collapsed` / `#picker-resizer` 规则；
   产物 JS 含 `biff.pickerw.v1`、`ensurePickerOpen`。
3. `dist/index.html` 里 `#picker-drawer` 为 `is-collapsed`，且**不再**含 `w-[520px]` / `max-[1099px]:w-full`。
4. 人工核对：进界面(有选片)→ 抽屉从左侧向右滑出停在「我的行程」；拖手柄改宽 → 刷新后宽度保持；
   ≤1099px 视口下抽屉全宽且手柄不显示。
5. `npm run deploy` 上线 Cloudflare Pages production。

## 7. 不在本轮

- `prefers-reduced-motion` 降级(动画 240ms，属短时位移；如需再补一条媒体查询关过渡)。
- 抽屉内**内容**宽度自适应重排(卡片行已用 `flex-wrap` 天然降级，本轮不额外做容器查询)。
- 把断点常量(1099 / 768)在 CSS ↔ TS 之间共享(历史遗留，收益低于成本)。
