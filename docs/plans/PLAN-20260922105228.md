## 方案取舍

| 备选 | 结论 | 理由 |
|---|---|---|
| **D1** 导出范围留一个「只有当前行程」的单选 Picker | **否决** | 单选项下拉是个点了没变化的死控件，比一行静态说明更差 |
| **D2** 顺便把 `biff.savedplans.v1` 也删掉 | **否决** | 数据契约只增不改；`compatibility.spec.ts` 的字节级断言与备份前缀快照都要求「加载旧数据不丢键」 |
| **D3** 顶部用自绘 Popover 塞三个原样 `DialogTrigger` | **备选（兜底）** | 零弹层管线改动的风险，但要手搓 a11y；只在 `ActionMenu + DialogContainer` 实测不过时启用 |
| **D4** 画布与侧栏用 flex 而不是 grid | **否决** | 侧栏要能折叠（宽度 0 ↔ 320px），grid 的两列模板一处改、动画不抖；flex 的 `flex-basis` 会在折叠时留残宽 |
| **D5** 提高 `VENUE_COLUMN_STRETCH_LIMIT` 让 1–2 个厅铺满 | **否决** | `vertical-schedule.ts:8-12` 已论证：无上限时卡片宽逾千像素、剧照按 100% 等比放大被裁成一条、片名被挤出卡外。收窄画布（侧栏）才是正解，且它同时满足第 3 条的「不留白」诉求 |
| **D6** 侧栏「场次详情」用**点击**选中 | **否决** | 甘特格上的点击语义是「加入 / 移出行程」（`toggle(s)`），复用它当「查看详情」会把用户已选场次点掉。改用既有 `useHighlight`（hover）+ 键盘 focus，零新交互口径 |
| **D7** 全局加深 `--muted` 提升可读性 | **否决** | `--muted` 同时是分隔线 / 图例 / 大量非说明文案的颜色，全局加深会连带改掉排片表与影片库的观感；改为新增 `--muted-strong` 只给说明文案 |
| **D8** 日期条保持上一轮的独立一行 | **否决**（用户本轮要求合并） | 本轮第 2 条明确要求与视图/过滤 Tag 同一 Toolbar；上一轮 PLAN 保留作历史 |

   菜单里三项都能打开对应弹层，弹层的「关闭」可用；「售票中」提示在头部下方的独立通知条里，可访问名不变。
3. **纵向**：1512×760 下 `header + toolbar + panel-heading(含概览) + 一条工具栏` 的高度 **≤ 250px**（改前 ~404px），
   画布起点 `y ≤ 250`。
4. **横向 / 侧栏**：`/agenda` 宽屏是两栏（画布 + 侧栏）；侧栏可折叠且状态在会话内保留；
   侧栏里有「当天冲突组顺位」卡，hover 甘特格时侧栏出现该场次详情。
5. **视觉**：圆角/描边/灰阶读 token（`--radius-*` / `--muted-strong`）；排片表 / 影片库 / 我的选片三页目视无回归。
6. `npm run verify:quick` 全绿；`specs:affected` 算出的受影响 spec（含全量桌面 + 移动两档）全绿。
7. 提交按「一次提交只做一件事」拆成 W1/W2/W3/W4 四个原子提交，**推一次**；推送前经用户确认。
