## 版面模型(踩过的坑)

排期表在 p9–p16(8 页),本质是**「旋转 90° 的表格」**:

| 维度 | 含义 | 位置 |
| --- | --- | --- |
| 行 | 时间档 1..5(早/日/下午/晚/午夜) | 档位数字竖排在最左缘 x≈30 |
| 列 | 场馆 | 场馆代码竖排在页面**底部**表头 y≈556–580 |
| 单元格 | 一场放映 | 竖窄条,文字旋转 90°,阅读顺序 = **y 递减** |

11 条陷阱(详见 `tools/extract_schedule.py` 模块 docstring):

1. 坐标**已是**显示坐标系,不要再乘 `rotation_matrix`(否则行列互换)。
2. 单元格文字旋转 90°(`dir == (0,-1)`),阅读顺序 = y 递减。
3. line 会把整个单元格粘成一行(高约 92pt)→ 必须下沉到 span 级。
4. 网格 = 行(时间档)× 列(场馆)。
5. **双日页**(p9 = 17+18,p16 = 25+26):底部表头出现两个日标签,日标签 x = 该日区域起点
   → 判天规则 `day = 最后一个 x <= 场次 x 的日标签`。
6. 场次编号按页连续递增(p9:001-076,p10:077-159,…)是极好的交叉校验;001/002 是**预留号**。
7. **★ 单元格归属靠 line 的 `y1`,不靠 y 窗口**。META line 与其标题 line **共享同一个
   line-bbox 下边缘 y1**(实测完全相等),标题 x0 比 META x0 大 6~12pt。
   早期用 y 窗口切单元格 → **206 场 title_en 为空**(标题在旋转文本流里排在时间之前,
   y 更大,落在窗口外)。改用「同 y1 + x 间距 (2,18]」后归零。
8. **同一个数字会被 PDF 拆成多个 span**(页码 191 = `'1'`+`'91'`),但**只能对末尾页码回拼** ——
   通用合并会把 `'101'`+`'32'` 粘成 `'10132'`(code 重复 10 个、rating 掉 68 个 None)。
9. BD / C7 两列在 p9–p14 上**原 PDF 就不印编号** → 用 `X<页号2位><序号2位>` 兜底,
   保证 `code` 唯一(前端 `byCode`/`slots`/`cardEls` 全以 code 为键)。
10. 场次特性 token 不止 GV:`GV`(347)/`Talk`(6)/`Commentary`(3)/`Event`(1)。
    前端 `badges.ts` 对未注册键**安全忽略**。
11. 少数特别场(002 闭幕式、BAFA 毕展)**不印片长** → 若留 0,前端
    `gvTalkMin = (end-start) - duration_min` 会凭空算出 240 分钟映后谈;
    改为回退成「整段占用时长」。
