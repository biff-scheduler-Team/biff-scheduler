## 1. 现状(代码事实,均为实测)

**暗黑可行性的证据**:
- 唯一色源 `:root`(~90 token)→ `@theme` 全量映射 → utility 与组件同源。
- **TS 源码零裸 hex**(全站 4 处 `#` 命中全在注释里);**全站仅 1 处 Tailwind 原生调色板类**(`tip.ts::border-white/20`,画在深色 toast 上,两种模式都成立)。
- 大量状态色走 `color-mix(..., var(--color-card))` → 覆盖 `--bg-card` 后自动跟随。
- 无 `prefers-color-scheme` / `.dark` / `color-scheme`。

**移动端现状**:
- 已有两档断点:顶栏 `max-[720px]:`(`index.html`)、抽屉 `max-[1099px]:w-full` + `style.css @media (max-width:1099px)` 隐藏 `#main-col`。
- 手机(≤480px)问题:① 默认视图是**网格**(二维密集,缩放下限 0.55 时影厅列 ~27px、卡内字 6~7px);② `#picker-drawer` 的 `sticky top-[64px]` 在顶栏折行后错位;③ 弹层靠 `max-w-full` 兜到 ~358px,设置弹层「标题 + 控件同行」会挤;④ 触屏无 hover:卡片图标组 `opacity-45 group-hover:opacity-100` 只显 45%,`data-tip` 悬停提示完全失效。

**样式债**:
- 字阶 token(`--text-2xs/xs/sm/md` = 11/12/13/14)**零消费**;实测全站用 `text-[Npx]` **192 处 / 14 个取值**(8.5 / 9 / 9.5 / 10 / 10.5 / 11 / 11.5 / 12 / 12.5 / 13 / 13.5 / 15 / 16 / 18)。
- 圆角 token(`--radius-sm/md/lg` = 6/8/12,`--radius`)**零消费**;实测 `rounded-[Npx]` **90 处 / 11 个取值**(1.5 / 2 / 3 / 4 / 5 / 6 / 7 / 8 / 9 / 10 / 12)。
- 按钮 / 卡片 / chip 类名串散落 5 个文件(`ai-panel.ts` `BTN_*`、`library.ts` `ICON_BTN`/`BTN_GO`/`TAB_*`、`main.ts` `ZBTN_CLS`/`ZMID_CLS`/`ZFIT_CLS`/`CHIP_DATE_*`、`chips.ts` `PILL_*`、`settings.ts` 表单密度)。

## 2. 决策

### 2.1 字阶 / 圆角 token:按**值命名**,不做「4 档归一」

Tailwind v4 的 `@theme` 键会成为 `:root` 上的 CSS 变量,而 **CSS 自定义属性名不允许 `.`** → 半像素无法做成 token(`--text-9.5` 非法)。

故采用**值命名**阶梯(自解释、与 Tailwind 默认字号名 `xs/sm/lg` **零碰撞**、不附带 `--text-*--line-height` 的隐式行高):

```
--text-9/10/11/12/13/14/15/16/18      → text-9 … text-18
--radius-2/3/4/5/6/7/8/9/10/12        → rounded-2 … rounded-12
```

**取舍(唯一一处刻意放宽「零视觉变化」)**:
- 圆角:**逐值 1:1**,零漂移(仅 `rounded-[1.5px]` 1 处 → `rounded-2`,+0.5px,是 6px 装饰圆点)。
- 字阶:**半像素归一**到相邻整数档,漂移 ≤ 0.5px,共 68/192 处(9.5→10 / 10.5→11 / 11.5→12 / 12.5→13 / 13.5→14 / 8.5→9)。
  理由:① 0.5px 在 1x DPR 下被取整、2x 下为 1 物理像素,不可感知;② 14 档的「阶梯」不是阶梯,而 9 档整数阶梯是;③ 甘特卡的**布局常量全在 JS**(`rowH`/`pxPerMin`/`scaleText(basePx)`),且 `fitTimeTexts()` 运行时实测降级 → 文字宽度变化自愈。
  配套:甘特谈块 `text-[8.5px]` 归一到 `text-9` 时,**同步改 `grid.ts::scaleText(rng, 8.5, …)` → `9`**(类名与 JS basePx 必须同源,否则 100% 档与缩放档口径不一致)。
- 删除 `:root` 里零消费的 `--text-2xs/xs/sm/md` 与 `--radius-sm/md/lg`/`--radius`,避免两套阶梯并存。

### 2.2 暗黑:跟随系统

- `@media (prefers-color-scheme: dark)` 覆盖 `:root` 的**中性面 / 描边 / 文本 / 阴影 / 品牌浅底族 / 语义浅底族 / 前景强调色**,并加 `color-scheme: dark`(原生 number spinner / select / 滚动条)。
- **拆分品牌红的「实底」与「文字」两种用途**(暗底上 `#ce1e36` 文字对比度只有 ~3.6:1,压在 `bg-biff-soft` 上仅 ~2.4:1):
  - 新增 `--biff-red-ink`(浅色 = `#ce1e36` 与今天**逐字相同**;暗色 = `#ff6b7d`)→ `@theme --color-biff-ink`;
  - `text-biff` → `text-biff-ink`(全站 sed,`(?![-\w])` 边界,不碰 `text-biff-soft/-line/-hover/-muted/-2`);
  - `bg-biff` / `border-biff` / 渐变 / `bg-biff-muted` **不动**(白字实底按钮对比度保持)。
- `@theme --color-conf` 由 `var(--biff-red)` 改 `var(--conf)`(=`--status-danger`),暗色下覆写 `--status-danger` 即可让 `text-conf`/`border-conf`/`in-conf` 一起提亮。
- 语义色(ok / tight / pri-* / rate-* / ev-teal)暗色下**前景提亮 + 浅底转深**。

### 2.3 ui.ts:类名收敛 + 微组件工厂(不引组件库)

`PLAN.md` §2 已拍板「外部组件库全不引」;本次只把**重复类名串**收口到新模块 `src/ui.ts`:
- 常量:`BTN_PRIMARY` / `BTN_ABORT` / `BTN_MINI` / `BTN_DISABLED` / `BTN_GO` / `ICON_BTN` / `TAB_ON` / `TAB_OFF` / `ZBTN` / `ZMID` / `ZFIT`;
- 工厂:`buttonEl({ variant, label, tip?, tag? })` / `iconButton(label, tip, extraCls?)` / `segTab(label, on)`。
- `chips.ts` 的 `PILL_*` 保留(chip 语义独立),但类名来源统一由 `ui.ts` 再导出。

### 2.4 移动端:列表优先(≤768px)

- **新增断点 `768px`**(与现有 720/1099 并存,`index.html` 与 `style.css` 逐字一致):
  - `style.css`:≤768px 时 `#picker-drawer` 取消 `sticky`(改 `position: static`)、`#grid-wrap` 内距收窄;`main` 的 `gap` 收窄。
  - `library.ts::openFilmPicker` 增加 `isMobile()` 判定:**≤768px 首次加载默认打开抽屉**(列表优先),网格作为次级入口(顶栏「时间轴」按钮 = 现有抽屉开关,文案在窄屏改为「时间轴 / 列表」)。
  - `boot()`:`matchMedia("(max-width: 768px)")` 为真时默认 `openFilmPicker(libraryCtx())` 且 `pickerTab = "lib"`。
- **触屏补偿**:`@media (hover: none)` 下把卡片图标组 `opacity-45` 提到 `1`(`style.css` 一条规则,不改 markup);`data-tip` 的关键信息在窄屏已有非 hover 出口(卡片底色 / 徽章本身),不额外做长按提示。
- **吸顶错位**:`#picker-drawer` 的 `top-[64px]` 改为 `style.css` 里按断点给 `top`(≤768px 不 sticky,问题自然消失)。

## 4. 边界与风险

- **零视觉变化是默认红线**,唯一放宽处 = §2.1 的半像素字阶归一(≤0.5px × 68 处)+ 1 处 1.5px 圆角,已在 PLAN 量化;其余全部逐字等价。
- **Tailwind 键碰撞**:`--text-9…18` / `--radius-2…12` 均为**新增数值键**,与 Tailwind 默认字号名(`xs/sm/base/lg/xl/2xl`)与圆角名(`xs/sm/md/lg/xl/2xl`)零重叠 —— 实测全站**无**任何裸 `rounded-sm/md/lg/xl` 用法,也无裸 `text-xs/sm/lg` 用法。
- **不引入 `--text-*--line-height`**:值命名键不带默认行高,故 `text-12` 只写 `font-size`,行高仍继承(与今天 `text-[12px]` 完全一致)。
- **暗色调色是主观项**:对比度按 WCAG AA(小字 4.5:1)选取,但需人眼终审;`--biff-red`(实底)在暗色下**保持不变**以保证白字按钮对比度。
- **移动端不改数据层**:仅初始 tab / 断点 / 触屏透明度三类改动,`state.ts` 零改动。
