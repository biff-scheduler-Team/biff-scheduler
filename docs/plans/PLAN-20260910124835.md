# PLAN-20260910124835 · 甘特图时间轴缩放

## 1. 需求

「甘特图要支持缩放」—— 选片网格（`src/grid.ts`）的时间轴目前刻度写死 `PX_PER_MIN = 3.0`
（每小时 180px，见 grid.ts 顶部 D1 注释），宽屏也一律横向溢出、只能滚动/拖拽平移。
要求：**刻度可调**，既能缩到「整天一眼看完」，也能放大到「单场细节 + 更密的时间刻度」。

## 2. 设计决策

| 项 | 决策 | 理由 |
|---|---|---|
| 缩放维度 | **只缩放时间轴（横向）**，行高 `ROW_H` 不动 | 甘特的行 = 影厅（固定 29 行），纵向缩放只是改字号，没有信息增量 |
| 档位 | 离散阶梯 `0.35 / 0.5 / 0.7 / 1 / 1.4 / 2 / 3`（100% = 3.0px/min） | 每档都能落在一个「好读」的刻度上；连续缩放会让卡片文字一直在截断/恢复间抖动 |
| 入口 | ① 网格标题行右侧 `− 100% + 适应`；② `Ctrl/⌘ + 滚轮`（触控板双指捏合同为 ctrl+wheel） | 按钮可发现、可精确；滚轮是熟练用户的快路径 |
| 锚点 | 缩放前后**保持锚点时刻不动**：滚轮锚定光标下的时刻，按钮锚定视口中心，「适应」锚定轴起点贴左 | 否则一缩放视口就跳回开头，用户丢失上下文 |
| 持久化 | `Settings.zoom`（localStorage `biff.settings.v1`），**不进设置弹层** | 视图偏好，跨会话保留；不动弹层 UI 就不动既有测试面 |
| 高倍细节 | 放大后标尺补 **半点（≥240px/h）/ 刻钟（≥480px/h）** 标签，标尺行加高；网格补刻钟竖线（≥300px/h） | 3.0× 时整点标签间距 540px，一屏只剩一个标签 —— 不给细刻度等于没放大 |

## 3. 改动清单

### `src/types.ts`
- `Settings` 加可选 `zoom?: number`（可选 → 存量 localStorage 记录仍合法）。

### `src/state.ts`
- 加 `setZoom(z)`：写 `store.settings.zoom` + `saveSettingsLocal()`，**不 notify**。
  缩放只影响网格，让 `notify → renderAll` 去重建行程/角标是白干（且会把缩放锚点算错，见下）。

### `src/grid.ts`
- `PX_PER_MIN` / `LABEL_W` 改为 `export`（main 侧换算锚点要用）。
- 新增 `ZOOM_LEVELS` / `ZOOM_MIN` / `ZOOM_MAX` / `clampZoom()` / `stepZoom(z, dir)` /
  `fitZoom(cat, date, availW)` / `axisStartFor(cat, date)`。
- `GridCtx` 加 `pxPerMin: number` —— 刻度由 main 侧算好传入，grid 内部不再持有刻度常量。
- `buildGrid` 内 `const pxPerMin = ctx.pxPerMin`。
- `buildRulerTicks`：抽出 `clockLabel(min)`（与既有整点标签**逐字节同输出**，含 24+ 时制的「次日」前缀），
  整点标签改由它生成；按 `hourPx` 决定是否补半点/刻钟标签 + 标尺 `min-h`。
- 行内背景：`hourPx >= 300` 时叠第三层刻钟竖线（ink 2.5%）。
- `ROW_BASE_CLS` 的 `148px` 与 `LABEL_W` 必须同值（Tailwind v4 不能拼类名）→ 加注释锁死。

### `src/main.ts`
- 模块级 `let zoom = 1` + `let pendingAnchor`。
- `gridAnchor(scroll, clientX?)` / `applyZoom(next, {clientX?, fromLeft?})` / `renderZoomCtl()`。
- `renderGrid()`：把原 `lastGridLeft`（裸 scrollLeft 记忆）换成**锚点记忆**
  `{min, screenX}`，重建后按新刻度回算 `scrollLeft` —— 同一套逻辑同时覆盖
  「同日期重建」与「缩放」，且缩放前后不跳。
- `renderAll()` 末尾加 `renderZoomCtl()`；boot 里 `zoom = clampZoom(store.settings.zoom ?? 1)`。
- 事件：`#zoom-ctl [data-zoom]` 点击（in/out/reset/fit）；文档级 `wheel`（`passive:false`）
  只接管 `ctrlKey || metaKey` 且落在 `#grid-scroll` 内的，`preventDefault()` 掉浏览器整页缩放；
  deltaY 累加到 60 才走一档（否则触控板一次捏合会连跳 7 档直接到底）。

### `index.html`
- 网格标题行右侧包一层容器：`#grid-count` + `#zoom-ctl`（静态容器类在 HTML，按钮由 JS 渲染）。

### `docs/CONVENTIONS.md`
- §四 补一条缩放不变量（刻度来源、锚点换算依赖 `LABEL_W`、grid 内不再持常量）。

## 4. 验收

1. `npm run typecheck` 通过；`npm run build` 产物里 `min-h-[44px]` / `min-w-[46px]` / `disabled:opacity-30`
   等新类名确实命中（Tailwind v4 只生成源码里出现过的完整字面量）。
2. 点 `+` / `−`：刻度按档位变，**视口中心那一刻不动**；到两端按钮置灰。
3. 点中间百分比 → 回 100%；点「适应」→ 当天整条轴塞进视口、左缘贴轴起点、无横向滚动。
4. `Ctrl/⌘ + 滚轮` 在网格上：以光标下时刻为锚点缩放；一次捏合只走 1–2 档，不到底。
5. 缩放后再点选场次 / 切方案（触发重建）：视口不跳、缩放保持。
6. 切日期：回最左、缩放保持；刷新页面：缩放从 localStorage 恢复。
7. 3.0× 下标尺出现刻钟标签（`09:15 / 09:30 / 09:45`），跨午夜轴仍带「次日」前缀；行内出现刻钟竖线。

## 5. 不在本次范围

- 纵向（行高）缩放。
- 缩放级别写进设置弹层（做成可选项）。
- 「双指捏合」以外的触屏手势（触摸走原生滚动，未接管）。
