# PLAN-20260910103258 · 「排片表说明 · 图例总览」字段元素图标化 + 全量可悬停

## 1. 需求

> 排片表说明 · 图例总览:我发现只有 GV 有悬停,其他的 KE 100' 之类既没有图标化,也没有 hover tooltip。

即:总览弹层里应当「每一枚字段元素都是真章」——hover 出即时说明,而不是一行行纯文本。

## 2. 现状(根因)

`src/legend.ts` → `buildGuideBody()`:

| 位置 | 现状 | 问题 |
| --- | --- | --- |
| §1「一格怎么读」表格「元素」列 | 只有 GV 用 `badgeEl("gv")`;`09:00–10:40` / `004` / `15` / `KE` / `100'` / `P.167` 全是**纯文本字符串** | 无 `data-tip` → `tip.ts` 的文档级委托 `closest("[data-tip]")` 命不中 → 无 tooltip;也没有章的外形 → 「没图标化」 |
| §1 demo 行 | 已是真章(`chipEl` / `pageChip` / `durChip`),但时间 / CODE 是裸 `<b>` 无说明 | 同一节内两套口径 |
| §3 字幕表「(空白)」行 | 纯文本 | 同上 |
| §4 徽章表「묶」行 | 纯文本(该键未在 `BADGE_DEFS` 注册,故渲染不出来) | 同上 |
| §6 网格图例 | 绿底 / 黄底 / 红底 / 「豆 x.x」全是纯文本(只有 GV 是真章) | 同上 |

**根因单一**:总览里凡是「能对应到一枚真实章/色块」的元素,只有 GV 一处接上了真节点,其余都退化成字符串。`tip.ts` 本身没问题(文档级委托,弹层内同样生效,`z-[300]` 高于 overlay `z-100`)。

## 3. 方案

### 3.1 `src/legend.ts`(主改动)

新增/扩展一组「示例字段节点」,全部带 `data-tip`:

1. `timeField(range)` — 加墨 + 等宽数字 + 起止/GV 映后说明(与网格卡身份行同款)。
2. `codeField(code)` — 红字 + `codeTip(code)`(与网格卡身份行同款)。
3. `durChip(min, { boxed })` — **新增 boxed 选项**:默认分支一字不动(网格卡上仍是透明贴徽章流末尾),`boxed` 时用与 `P.167` 同款中性描边章 —— 说明里要「看得出是一枚章」。
4. `doubanChip(rating, extraCls?)` — 豆瓣章**单一来源**(原本在 library.ts ×2 / modal.ts ×2 各写一份 markup)。
5. `blankChip()` — 虚线空框「(空白)」= 格内没有这枚标识。
6. `swatch(bg, borderCls)` — 10px 圆角色块,与顶栏图例条同款。

再把这些节点铺回总览:

- §1:demo 行时间 / CODE 换 `timeField` / `codeField`;表格「元素」列 `时间 / CODE / 等级 / 字幕 / GV / 片长 / 页码` 全部换真节点(片长用 `boxed`)。
- §3:「(空白)」→ `blankChip()`。
- §4:删掉手写的「묶」纯文本行,改为注册徽章后由 `BADGE_DEFS.forEach` 统一渲染。
- §6:绿 / 黄 / 红改真色块(色值直接取网格卡口径:`--color-ok` 14% / `--color-tight` 24% / `--color-conf` 14%);「豆 x.x」→ 真豆瓣章;GV 行去掉「GV — GV 映后」的重复前缀。

### 3.2 `src/badges.ts`

`BADGE_DEFS` 增一枚 `batch`(`label: "묶"`,虚线中性描边,`title` 保留原「官方偶用」口径)。理由:总览本来就把 묶 当作一枚徽章在解释,注册后它才能被渲染成真章;数据侧无 `tags: ["batch"]`,当前不影响任何卡片。

### 3.3 `src/library.ts` / `src/modal.ts`

4 处豆瓣章(影片库 ×2、详情弹层 ×2)改为调用 `doubanChip()`,消掉第 5 份复制。输出 markup 与现状一致(弹层的 `mt-2` 走 `extraCls`),另补 `cursor-help`(它们本来就有 `data-tip`)。

## 4. 不做

- **不动网格卡 / 行程行外观**:`durChip` 默认分支不变,卡片上 `100'` 仍是透明尾注。
- 不动顶栏图例条(已是真色块 + `data-tip`)。
- 不动 `badgeEl` 既有四枚徽章的样式。
- 不给「片名」造章(它在卡片上本来就是片名文字,不是标记)。
