# PLAN-20260922164728 — 红黑榜「生成分享图」

## 目标

用户 2026-09-22：

> 请你给这个我贴过的页面做一个分享按钮 然后弄成分享图片的形式 黑榜红榜默认 TOP10 我贴过的不限场数样式
> 弄好看点吧 底部署名网站 by gaaiyeoi 和 cit忘记怎么拼了 你找找就行

澄清后（同日问答）确定：

1. **署名**：照现网页脚 —— `by @gaaiyeoi 和 by @citron` + 网站 `biff.lcandy.co`。
2. **榜单**：「取**总数 / 红榜 / 黑榜**那三个按钮的口径，各取 TOP10」——
   即逐字复用页面三档排序，不另立一套排名规则。
3. **「我贴过的」**：每行给「我贴的那一色 + 全站红黑数」，**不限条数**。

## 范围

**做：**

1. **模型层** `apps/web/src/redblack-poster.ts`（纯逻辑、import 期不碰 DOM、可 node 单测）：
   三榜各 TOP10（走 `redblack.ts::sortByCounts`）+ 我贴过的全部（按全站总数降序，与页面默认档同口径）
   + 头部（届次 / 日期 / 影片数 / 全站三格 / 我的一行小字）+ 底部署名。日期**注入**，不读时钟。
2. **绘制**：1080 宽、`SCALE=2` 超采样、长图过 `SCALE_DOWN_H` 退 1×；深底 + 品牌红条 + 每行一条
   红黑比例条；「我贴过的」行用**贴纸形状**的小圆片当左侧标记（复用 `sticker-shape.ts`）。
3. **共用笔刷** `apps/web/src/poster-brush.ts`：把配色 / 字体 / 圆角 / 超采样 / 退档阈值 / 页脚高 /
   品牌红条从 `poster.ts` 搬出来 —— 两张分享图必须**同一套**（§5 口径单一来源）。
   `apps/web/src/sticker-shape.ts` 同理：贴纸形状（CSS `border-radius` ↔ sprite ↔ 分享图）三处表达里，
   后两处共用同一条 canvas 路径。
4. **复制 / 下载出口** `apps/web/src/components/share-image.ts`：先试复制、失败退化下载并如实提示。
   `PosterPreview.tsx` 改为调用它（原来那份逻辑是内联的）。
5. **弹层** `apps/web/src/components/RedBlackShareDialog.tsx`：复用 S2 `Dialog`（role=dialog / focus trap /
   Esc），只在打开时挂载；预览画布 + 下载 PNG + 复制图片。**焦点归还**由页面负责。
6. **入口**：红黑榜控制行加「生成分享图」按钮（与「只看我贴过」同排 —— 它既不是排序也不是筛选）。
7. **出图是快照**：弹层打开那一刻的数据就是图的内容（打开后再贴一枚不该让图变来变去）。

**不做：**

- **不动页面上的排序 / 筛选 / 卡片呈现**：分享图只是把已有的口径再画一遍。
- **不新造配色**：深底海报配色沿用 `poster.ts` 那套（`COLORS`），只有「黑贴纸在深底上的填充色」
  是新加的一个 token —— 因为页面的 `--rb-black` 是给**浅底画布**配的深色，直接搬进深底海报会变成
  「一枚看不见的黑点」。这一点在 `poster-brush.ts` 里写明了原因。
- **不做 `navigator.share` 系统分享**：仓库至今没有这个能力，也没有需求。
- **不做可配置的 TOP N**：默认 10（常量 `TOP_N`），要改时改一处。
- **不动持久化契约**（`biff.*` 一字未改）。

## 方案取舍

| 备选 | 结论 | 理由 |
|---|---|---|
| 新写一套配色 / 圆角 / 字体 | 否决 | 同一个应用出的两张分享图必须像一家人；抽 `poster-brush.ts` 后两张图共用同一份笔刷 |
| 三榜判据另写一套 | 否决 | 顺序与页面对不上就是 bug；逐字复用 `sortByCounts` + `sortMetric` |
| 榜里列出「该榜为 0」的片 | 否决 | 黑榜里列一堆「黑 0」毫无意义。按**每榜各自的指标**筛（`sortMetric`），不是笼统的「有没有票」 |
| 「我贴过的」也截断到 10 | 否决 | 用户明确「不限场数」 |
| 每行带海报缩略图 | 否决 | 40+ 行要几十张图，出图慢且长；榜单靠数字与比例条就够读 |
| 弹层与页面共享一个弹出组件 | 否决（本轮） | 看片计划海报的预览要加载几十张缩略图，两边的准备步骤不同；只把**复制/下载**这一处抽出来共用 |
| 分享图上手写 focus trap / `role=dialog` | 否决 | 仓库已有 S2 `Dialog` 自带全套（§5） |

## 验收标准

1. 红黑榜控制行出现「生成分享图」→ 打开弹层即出图（预览可见 + 「下载 PNG 图片 / 复制图片」可用）。
2. 图里**三榜各 TOP10**，顺序与页面上点同档位时**一致**；**该榜指标为 0 的片不进该榜**；
   某榜一条都没有时**整节不出现**（不留空节）。
3. 「我贴过的」**不限条数**；每行有「我贴的那一色」（贴纸形状的小圆片）与「全站红黑数」；
   中英名相同时不重复画两行（与页面卡片同一条展示规则）。
4. 底部署名两行：`biff.lcandy.co` 与 `by @gaaiyeoi 和 by @citron`。
5. a11y：`role=dialog` + Esc 关闭 + **焦点归还**给「生成分享图」按钮。
6. 收口：`npm run verify:quick` + 三浏览器跑 `redblack` / `share-export` / `parity-dialogs` 全绿
   （后两个是 `poster-brush.ts` / `share-image.ts` 抽公共层后的回归网）。
