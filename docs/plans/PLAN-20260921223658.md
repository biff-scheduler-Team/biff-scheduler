# PLAN-20260921223658 — 「我的行程」新增日程表视图（仅我的场次 / 仅我有影片的影院）

## 目标

> 把我的行程也重构日程表显示吧 只显示我的行程 而且 X 轴只显示我有影片的影院 感觉比较好看一点

把排片表那套「纵向日程表」（X 轴 = 影厅列，Y 轴 = 韩国时间 KST 的甘特画布）搬到「我的行程」：

1. 画布上**只有我的场次**，不再铺当日全部排片；
2. **X 轴只列我有影片的影厅**（当天没有我的场次的影厅不出列）；
3. 时间轴范围跟着我的场次收（第一场之前 / 最后一场之后不留大片空白）。

### 口径确认（2026-09-21，用户逐项选择）

| 问题 | 用户选择 |
|---|---|
| 视图形态 | **加切换，默认日程表**；旧卡片列表保留为回退路径 |
| 多天排布 | **顶部日期条切单日**（像排片表那样，只列「我有行程的日期」） |
| 顺位卡 / 已保存方案 | 「冲突就像日程表一样连线」—— 冲突在画布上画连线；顺位卡按日保留在画布下方（见 §方案取舍 D2） |

## 范围

**做：**

- 把 `SchedulePage.tsx` 里的甘特图（`Gantt` / `GanttViewport` / `ScheduleArtwork` / 定位闪烁 / 平移缩放）**原样搬**到 `apps/web/src/components/ScheduleGantt.tsx`，新增两个入参：
  - `shows?: Screening[]` —— 画布只画这些场次（缺省 = 当日全部排片）；
  - `scope?: "schedule" | "agenda"` —— 画布口径：日程表那一档隐藏「排片筛选」、不画「已选」图例、时间刻度不可点、不画上下边界文案。
- `apps/web/src/app/vertical-schedule.ts` 的 `verticalGeometry` 增加 `shows` 入参（缺省仍是当日全部排片），轴范围与列宽口径仍只此一处。
- `apps/web/src/grid.ts` 抽出 `axisRangeOf(shows)`（`axisRangeFor(cat, date)` 改为调它），供「按给定场次算轴范围」复用。
- `AgendaPage` 加「卡片 / 日程表」视图切换（默认日程表）+ 只列行程日的日期条；日程表视图 = 单日甘特（仅我的场次、仅我有影片的影厅、冲突连线）+ 当天冲突组的顺位卡。
- `schedule-parity.css` 的 `.schedule-page .calendar-strip` 选择器去掉 `.schedule-page` 前缀（日历条样式仍只此一份实现）。
- 受影响的 E2E / 单测同步更新（默认视图变了，旧卡片断言要显式切到卡片视图）。

**不做：**

- 不改 `/agenda` 路由、不改导航文案与顺序。
- 不动 `biff.*` 任何既有键：视图选择是**页面内 state**（默认日程表），不落 localStorage —— `e2e/react/helpers.ts::legacyData` 有字节级快照断言，新增键会连带打红一批无关 spec（见 §方案取舍 D1）。
- 不改卡片视图的任何行为（顺位拖动 / 按日折叠 / 间隔提示 / 已保存方案），它仍是回退路径。
- 不动冲突判定、GV 时长、有效结束时间、缩放偏好（`biff.settings.v1.zoom`）的任何口径。
- 不新增依赖。

## 方案取舍

| 备选 | 结论 | 理由 |
|---|---|---|
| **D1** 视图选择落 localStorage（新键 `biff.agendaview.v1`） | **否决** | `biff.*` 键的读写会被 `helpers.ts::legacyData` / `review-state-export` / `compatibility` 那批字节级快照断言看见；为「记住一次切换」换一批无关 spec 打红不划算。默认日程表已满足用户诉求，刷新回落默认可接受。 |
| **D2** 日程表视图里顺位卡的去留 | **保留**（画布下方，仅当天有冲突组时出现） | 顺位是 `/rush` 抢票顺序的唯一来源，且只能靠拖动设置。默认视图若把它拿掉，等于默认路径丧失功能。用户要的是「冲突用连线表达」——连线照画，顺位卡只是收在画布下方。 |
| **D3** 行程日程表另写一套甘特容器 / 另起类名 | **否决** | 会变成同一口径的第二份实现（轴范围 / 分栏 / 有效结束 / GV 谈段 / 冲突连线 / 定位闪烁都要抄一遍），且视觉语言会漂。改为「搬走 + 加两个入参」，排片表与行程共用同一个组件。 |
| **D4** 日程表里保留「排片筛选」与整点筛选 | **否决** | 画布只剩我的场次，「字幕 / 影厅 / GV」三道筛选与整点筛选都失去意义；整点刻度在行程页点了会往 URL 写 `hour` 却没任何视图消费它（死控件）→ 日程表档渲染成不可点的刻度。 |
| **D5** 用 URL 参数 `?view=cards` 承载视图 | **否决** | 视图是**会话内视觉偏好**，不是可分享的书签状态；写进 URL 会污染 `navSearch` 的跨页跳转口径。 |

## 验收标准

1. `/agenda` 默认落**日程表**：X 轴只出现「当天我有场次」的影厅列，画布上只有我的场次；切到「卡片」后与改动前逐像素一致（含顺位拖动、按日折叠、间隔提示、已保存方案）。
2. 顶部日期条只列我有行程的日期，选中日切换画布；「仅看实际行程」开启时画布与日期条同步只留「已抢到」的场次。
3. 同日两个我的场次时间重叠时，画布上出现连接两条影厅列的连线，卡片为冲突配色。
4. `npm run verify:quick`（typecheck + lint + 单测）全绿；`npx playwright test -c playwright.react.config.ts e2e/react/parity-agenda.spec.ts e2e/react/agenda-gantt.spec.ts --project=desktop-chromium` 全绿。
5. 排片表（`parity-schedule` / `vertical-schedule` / `time-axis` / `night-axis` / `schedule-size` / `schedule-toolbar`）行为不变。
