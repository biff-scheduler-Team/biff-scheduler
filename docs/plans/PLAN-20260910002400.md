# PLAN 2026-09-10 00:24:00 — 甘特化改造(时间显示/选择/联动)

> 需求(用户原话):时间组件更加甘特图一点,比如时间显示、选择、联动;同时修复「00:00 被截断成 00」。
> 本文件 = 本需求唯一规划文档;PLAN.md(活文档)不在本需求中通读。

## 背景与现状(代码事实)

- `src/grid.ts` 自研 CSS 网格:行=影厅,列=当日时间轴;卡片绝对定位(分钟换算 px)。
- 上一轮(并行/先前)已落:自适应 `pxPerMin`(computePxPerMin,视口够宽用 1.5、压缩至多 0.7)、首根小时标签(9:00)移入粘性列内、`LAST_TICK_BUMP=14` 给最末 tick 半宽留位。
- 遗留问题:
  1. 窄卡片上 `t1` 行(CODE + `09:00–10:40`)是 `whitespace-nowrap`,内容超出卡片 `overflow-hidden` 时**尾部被裁**,长结束时间会显示成 `00:0…` / 视觉截断。
  2. 时间轴小时刻度只是文本,不可点 —— 没有「时间选择」交互。
  3. 没有「现在时刻」参考线 —— 排片缺少时间"锚点"。

## 改动方案(全部在 src/,无新依赖)

### A. 卡片时间显示永不截断(grid.ts `appendCard`)
- `t1` 行结构改为 DOM 构造:`<b>CODE</b> <span class="time-range">09:00–10:40</span>`。
- 卡片渲染后(此时已在 DOM,可同步量 `scrollWidth`):当 `t1.scrollWidth > 可用宽度` 时降级:
  1. 完整 `09:00–10:40` → 只显示 `start_time`(`09:00`);
  2. 若仍放不下 → 空串,**完整时间放入元素 `title`/`data-tip`(hover 仍可看)**。
- CODE 行保留 `codeTip` tooltip。
- 实施位置:appendCard 尾部(卡已 append 到 tracks 后)一次性量测;不行则量测放 buildGrid 末尾统一处理,以真实 DOM 布局为准。

### B. 时间轴整点可点 = 时间筛选(时间选择)
- `GridCtx` 增 `hourFilter?: number | null`(0-23)。
- ruler 的每个整点 tick(`[data-hour]`)可点击:点击某小时 → 该小时为选中态(视觉高亮 tick),**其他时段的卡片 `hour-dim` 淡化**;再次点击同小时取消;切日期/重置时清空。
- 淡化卡仍可 hover/点选(只是视觉降噪)。
- 实现:`style.css` 加 `@utility hour-dim`(opacity 0.35)+ tick 选中态类;`main.ts` 全局 click 委托先拦 `[data-hour]`。

### C. 现在时刻参考线(联动锚点)
- 仅当 `todayIsoLocal() === 当前 date` 且当前分钟落在 [AXIS_START, AXIS_END] 内时,在网格时间轴上画一条竖参考线 + 顶部「现在 HH:MM」小标。
- 参考线颜色用 `--color-biff`(红)低透明度;位置 `left = (nowMin - AXIS_START) * pxPerMin`。

## 验收
1. 卡片无论多窄,时间文本不截断(降级为 start 或空 + hover title),CODE 始终可见。
2. 点击标尺整点 → 仅该小时场次实显,其余淡化;再点取消。
3. 当天日期下出现「现在」红线;非当天不出现。
4. `npm run typecheck` 通过;不启动本地 dev server 验证(读代码自查 + 必要时一次性构建)。
