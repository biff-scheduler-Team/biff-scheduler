# PLAN 2026-09-11 21:30 — 下线「抢票顺位清单(复制)」

> 需求(用户原话)：「分享 抢票顺位清单不需要了」;追问确认 → **只移除抢票顺位清单,保留「分享文案(复制)」**,
> 并**一并删除不再使用的源码文件**(`src/picklist.ts`)。

## 1. 为什么下线

导出菜单原有的两个「人读」出口里,「抢票顺位清单」是**排票用**的紧凑清单(单行塞满
`序号 / 档位 / CODE / 片名 / 日期 / 时段 / 场馆 / GV`),而「分享文案」才是**给人看**的
「两行一场 + 日期分节」纯文本。9/11 上线分享文案后,抢票清单与之定位重叠、且排版在手机上本就难读,
用户明确不再需要 —— 于是收掉它,导出菜单只留 `.ics` 三项 + 分享文案。
