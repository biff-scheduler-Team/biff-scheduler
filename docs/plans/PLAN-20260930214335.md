# PLAN-20260930214335 — 红黑榜黑贴纸补一档暗色覆盖

## 目标

> 用户原话：「红黑榜的黑色贴纸在深色环境下不是很明显 怎么办呢」

暗色主题下，红黑榜画布上的**黑贴纸**与卡片底色几乎同亮度，糊成一片；尤其是别人贴的
**群点**（canvas 画的 sprite，没有「我贴的那一枚」那圈纸白边），在暗色下基本读不出是一枚贴纸。

**根因**：黑贴纸的填充色 `--rb-black: #2f2f36` 是照**浅底画布**配的深色，而暗色主题会把
它脚下的底色换掉（`.rb-card` 用 `var(--surface)`）—— 贴纸色不跟主题走，底色跟着走，两者在
暗色下亮度撞车。这不是配色没调好，是**缺一档暗色覆盖**。

**这个问题海报侧已经解决过**：`poster-brush.ts` 的 `stickerBlack: "#3a3a45"` 注释即为此而写
（「不能照搬页面的 `--rb-black`……会变成一枚看不见的黑点」）。页面侧当时被显式记为「下一步」：
`sticker-sprite.ts` 的诚实记录里写着「给贴纸补一档是很自然的下一步，届时这里一行都不用再改」。

## 范围

**做：**

1. 在 `apps/web/src/pages/redblack-parity.css` 补 `:root[data-theme="dark"]` 覆盖
   `--rb-black` / `--rb-icon-black`（不动全站 `style.css`）。
2. 订正因这次改动而**过期**的四处注释（`sticker-sprite.ts` / `StickerCanvas.tsx` /
   `sticker-sprite.test.ts` / `redblack-parity.css` 自身），它们目前都写着「尚无暗色覆盖」。

**不做：**

- **不动** `--rb-red`：红贴纸 `#cf3b52` 落在 `#252528` 上有足够辨识度，用户只报了黑色。
- **不动** `.rb-dot` 的常驻纸白边（`redblack-parity.css:940-941`）：它是 E2E `redblack.spec.ts`
  断言的那条 `/1.5px/`，且是「我贴的那一枚」独有的识别标记。
- **不补亮描边**（备选方案 B）：提亮 token 后群点自身对比已够，补边会推翻「群点刻意无白边」的设计。
- **不动** `.rb-canvas` 底色（备选方案 C）：会让画布与卡片底脱层，300 张卡观感变化过大。
- **不动** `--rb-gloss` 的 10% 黑贴高光：属质感、非识别问题，本轮保持克制。
- **不动** `poster-brush.ts` / 分享图：海报恒为深底（`bg: #101013`），走自己的 `stickerBlack`，
  与本轮 token 无关。

## 方案取舍

| 备选 | 结论 | 理由 |
|---|---|---|
| A：`redblack-parity.css` 补 `:root[data-theme="dark"]` 覆盖 `--rb-black` | **采纳** | 三处共用同一 token（`.rb-src` 暂存区 / `.rb-dot` 贴纸 / `.rb-ghost` 浮标），一处生效；`sticker-sprite.ts::readPalette` 已经从同一 token 读色且 `MutationObserver(data-theme)` + `spriteEpoch()` + `sticker-canvas-guard.ts` 的 `epoch` 判据全部就位 —— canvas 群点会跟着重绘 |
| B：本体色不动，暗色下给贴纸补一圈亮描边 | 否决 | 缺口在 sprite 侧（群点本来就没有白边），要改 sprite 绘制 + CSS 两处口径；且推翻既有「群点刻意无白边」设计 |
| C：暗色下把 `.rb-canvas` 压暗成深底 | 否决 | 画布与卡片底脱层，300 张卡观感变化过大；A 已足够 |
| D：覆盖全站 `style.css` 的 `--rb-black` | 否决 | 该文件命中 TEST-MAP 的 allOn，会触发三浏览器全量 E2E；且贴纸 token 属于红黑榜自己的口径 |

**取值**（用户拍板：「明显一点也无妨，优先看清楚」）：

- `--rb-black: #70707c`（亮底 `#2f2f36` → 暗色 `#70707c`）。与卡片底 `--surface: #252528` 的
  对比度约 **3:1**（满足非文本图形元素的 WCAG 下限），且仍保 `#2f2f36` 那点「B 比 R 高」的冷灰倾向。
- `--rb-icon-black: rgb(255 255 255 / 80%)`（亮底 72% → 暗色 80%）。纸面提亮后，原 72% 的白
  压在纸上会显得图案发灰，需提回来；但**不与 `--rb-icon-red` 的 92% 合并** —— 黑纸上仍要比红纸上的
  墨色收敛一档，否则又回到「贴纸破了个洞」的观感。

## 验收标准

1. 暗色主题下，红黑榜画布上的黑贴纸与群点一眼可辨（与卡片底不再是同亮度）；亮色主题**逐像素不变**。
2. `redblack-parity.css` 中 `--rb-black` 的暗色覆盖是**唯一**新增的口径表达，无第二份硬编码色值。
3. `npm run build -w @biff/web`（typecheck + lint + 单测 + 构建）全绿。
4. 切换主题时，canvas 群点会重绘为新色（`spriteEpoch` 链路仍成立，单测守住）。
