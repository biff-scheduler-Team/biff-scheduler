## 2. 数据管线（新增 `tools/scrape_biff_web.py`）

### 2.1 为什么不用 Catalogue PDF 了

PDF 是**付印版**，付印后到开幕前的加场 / 改时间 / 换厅它看不到；官网 `date.asp` 是活的。
2025 那套（`extract_schedule.py` + `import_schedule_2025.py`）保留不动，作为历史路径。

### 2.2 抓什么 / 怎么补

| 字段 | 来源 |
|---|---|
| 场次编号 / 时间 / 片名 / 分级 / 字幕 / GV | `date.asp?day1=6..15` 的 `div.sch_it` 格子 |
| 韩文片名 / 片长 / 单元 / 国家 / 年份 | 影片详情页 `prog_view.asp?idx=..`（eng 拿元信息，kor 拿韩文名） |
| 活动场次时长 | `addon/10000001/page.asp` 里印的 `18:50 - 19:50` 区间 |
| 场馆 id / 官方代码 | 静态表 `VENUE_TABLE`（表外的新厅**报错退出**，逼你补表而不是静默丢数据） |
| 中文片名 `title_zh` | `--films-json public/films.json`：官网英文 / 韩文名 ↔ 目录 `title_orig` / `title_zh` 归一化精确匹配 |

### 2.3 三类特殊格子（官网真实存在、结构不同）

1. **联映块**（`묶`，`div.pack` 挂成员）：时长 = 块内成员片长之和，成员名进 `midnight_members`。
2. **活动场次**（Actors' House / Master Class / Special Talk）：链接指向 `addon`，页内有时间区间 → 直接算。
3. **开闭幕式 / 获奖片重映 / 未编号场**：既无详情页也无区间 → `duration_min` 用 120min 兜底，
   **在自检里逐条点名**（本轮 9 条），绝不混进真实数据里。

### 2.4 两个已知缺口（自检打印，README 也写明）

- **9 条估算片长**（开闭幕式 + 6 场获奖片重映 + BAFA 毕业典礼 + 1 场 Special Talk）。
- **片名桥接 55%**：`title_en` 命中 233 / `title_kr` 命中 159 / 任一 385（共 750 场）。
  对不上的场次 `title_zh` 留空 → 前端按「纯排期片」单独成条（**不串片**，但影片库会出现
  「中文条目无排期 + 英文条目有排期」的一对）。
  自动手段已试尽：标题归一（NFKC + 弯引号）、韩文名、**导演罗马字**（xlsx 部分行含罗马字，如
  `김병수 KIM Byoungsoo`，仅多补 8 条）。再往上需要一份双语别名表 —— 留作后续。

## 3. 筛选（字幕 / 影厅 / GV）

### 3.1 交互

日期条下方三行「浅灰轨道」筛选条（与日期条同一视觉语言）：

- **字幕**：`KE / KN / KK / NO / 未标注` —— 多选；`未标注` 是特殊键（官方缺省 = 英字 + 韩语对白）。
- **影厅**：26 个厅逐厅多选，标签走 `venueShort()` 短名（`BCC Cinema 1` / `CGV 3` / `LOTTE 10`）。
- **场次**：`全部 / 仅 GV / 非 GV` —— 三态单选，再点同一档 = 取消。
- 任一筛选生效时出现「清除筛选」；标题右侧显示 `命中/总数 场（已筛选）`。

### 3.2 语义

- 三道之间是**与**，每道内部是**或**。
- **只淡出不隐藏**：复用 `hourFilter` 的 `hour-dim` 机制 —— 几何与 DOM 都不动，过滤前后**不跳版**。
- **不随切日期清空**：筛的是「我想看什么样的场」，跨日有效（与 `hourFilter` 的「切日期即清」刻意相反）。
- 判定收敛在 `grid.ts::matchesFilters()`（纯函数，`Pick<GridCtx, ...>` 只吃三个筛选字段），
  `cardStateOf()` 与 `main.ts` 的计数**共用同一函数**，口径不会漂。

## 4. 样式对齐官方新版

### 4.1 徽章：浅底描边 → 彩底白字实心胶囊

新增 `--*-solid` token（**两套主题同值**，白字对比度靠它保证；与 `--rate-*` 那组「文字色」严格分开 ——
后者暗色下会提亮，拿去当底会吃掉白字）：

| 组 | 配色 |
|---|---|
| 等级 | ALL 绿 `#2f9e44` / 12 琥珀 `#c07a00` / 15 橙 `#e8590c` / 19 红 `#c92a2a` |
| 字幕 | KE 藏青 `#233b8f` / KN 紫 `#5b21b6` / KK 棕 `#8b5e34` / NO 近黑 `#3f3f46` |
| 特性 | GV 紫 `#7c3aed` / 联映块 묶 近黑 `#18181b` |

⚠ 12 档官方是亮黄（白字对比度 ≈2:1）→ 压深一档到 `#c07a00`（≈3.6:1），同色相、小字号可读。

⚠ `CHIP_BASE` **只放尺寸 / 排版，不放颜色**：Tailwind 里同族 utility 谁生效取决于产物 CSS 里的先后，
不是 class 属性里的先后；基底带色会让变体覆盖变成「碰运气」。颜色由各变体自己写全。

### 4.2 说明弹层：三栏 Schedule Guide + Notice

- 原「观影等级」「字幕 / 对白标识」两张独立表 → 合并成官方「**Ratings | Subtitle | Information**」三栏
  （`grid-cols-[repeat(auto-fit,minmax(230px,1fr))]`，窄屏自动折成一栏）。
- 末尾「特别提示」→ 官方 **Notice** 块：素圆点条目（原来是红方块），文案换成 2026 官网 Notice 原文口径。
- 「按影院归并的代码总表」由写死的 2025 表 → **从 `cat.venues` 按 `group` 推导**（换版本自动跟着变，
  不会像写死表那样悄悄列出已停用的 M1–M4 / BD / C7）。
- `RATING_ORDER` 显式列出展示顺序 —— JS 对象会把「整数样」键（`"12"/"15"/"19"`）排到最前，
  直接 `Object.keys(RATING_DEFS)` 会渲染成 12/15/19/ALL，与官方 ALL 打头不符。

### 4.3 日期条：官方「Schedule by Date」

- `#date-chips` 容器 = 浅灰圆角轨道（`bg-raised` + `rounded-full` + 内边距）。
- 日期钮 = 无边框文字钮；选中 = 浮起的**白底胶囊 + 品牌红粗体字**（官方同款）。
- 标签改官方写法 `OCT 6`（新增 `dateInfo().en`）；中文 `10/6 周二` 与场次数进 tooltip。
