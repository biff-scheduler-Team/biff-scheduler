## 3. 设计语言基准（Linear/Vercel/Notion/Apple Calendar → 本项目落地口径）

一句话基准：**灰白底、白卡、细边、小圆角、红点缀、琥珀警告、绿仅状态点、黑字三阶灰度、时间数字等宽**。

| 来源 | 借鉴点 | 本项目落地 |
|---|---|---|
| Linear/Vercel | 低装饰、高信息密度、克制阴影 | 现 UI 已接近；本轮收口：shadow 仅 card/hover 两档（0 1px 2px / 0 4px 12px） |
| Vercel | 状态色极简、边界 1px 细线 | border 三档 `#e0e0e0 / #c9c9c9 / #f4f4f4` |
| Notion | 字阶克制、留白节奏 | 字阶收敛 `--text-2xs~md` = 11/12/13/14px；正文 14px |
| Apple Calendar | 时间数字 tabular-nums 对齐、刻度干净贯穿 | 已落地（1c + tabular-nums），保留 |
| BIFF 官方（底色） | 黑白编辑风 + 红 #ce1e36 唯一点缀 | 品牌 token 主色源，外部 #d71920 不采 |
